# 第17至23集导演地图

> 这是项目内部的大局观，不复制进单次Seedance提示词。具体时长以用户剪辑点位为准；镜头数从本项目约3秒一切的基线出发，再按本段连续动作与素材风险调整。

## 第17集：求助却再次被否定

- 剧情任务：交代Alice的创伤为什么如此深。她曾鼓起全部勇气求助，却被母亲亲手撤销了控诉。
- 情绪起点：发抖但坚持把霸凌说清楚。
- 主要伤害：母亲不断拉她后退、替Tamara解释，并要求她握手和解。
- Tamara表演：坐在桌边漫不经心；公开假道歉；无人注意时用吐舌或微笑确认自己获胜。
- Alice落点：看母亲像看陌生人，不是立刻嚎哭，而是信任突然断裂后的失神。
- 钩子：Tamara在人群后露出只有Alice看见的挑衅。
- 素材重点：高中时期Alice、Tamara、母亲、老师、办公室。

## 第18集：积压多年的反抗爆发

- 剧情任务：从高中回忆硬切回庄园现在，Alice不再忍耐，直接攻击Tamara。
- 爽点：长期被动的人第一次抢回身体主动权。
- 动作因果：Tamara的笑声或当前挑衅触发 -> Alice上前抓住头发 -> 两次巴掌 -> Tamara失衡 -> 扭打和物件散落 -> 众人拉开。
- 表演重点：Alice不是享受暴力，而是愤怒、委屈和失控一起爆发；Tamara先震惊，再暴怒反击。
- 风险：多人扭打、头发抓握、倒地和群演拉架属于高风险动作，需要按稳定因果节点拆分，不能把完整打斗塞进一个长镜头。
- 结束状态：Alice被按在墙边、头发散乱、手中有金发；Tamara脸部红肿；清洁用品散落。
- 钩子：“The Don’s here.”之后给环境瞬间安静的反应时间。

## 第19集：所有人选Tamara，Nico选Alice

- 剧情任务：完成最重要的公开权力反转。
- 前半压力：佣人围向Tamara并指责Alice；Tamara迅速切换成无声落泪的受害者。
- 关键爽点链：Tamara伸手抓Nico裤脚 -> Nico低头、用脚轻轻拨开她的手 -> 穿过佣人 -> 在Alice面前停下 -> 轻轻掰开Alice捂住伤口的手。
- Nico表演：脸色冷，不急着宣布立场；真正的选择通过行走方向、视线和触碰对象完成。
- Alice表演：已经预备接受惩罚，因此Nico停在面前时先困惑，不敢相信是关心。
- 群演：从一致指责逐渐失声，不整齐做同一种震惊表情。
- 重台词：“Let go. Let me see.”声音低哑，温柔动作与冷肃权力形成反差。

## 第20集：公开牵走与失控坦白

- 剧情任务：Nico在所有人面前牵走Alice；Alice一路把压抑的真心说出来。
- 爽点：Nico不解释、不回头，直接用行动公开站队。
- 跨集开场：第20集明确承接第19集最后一刻，使用第19集实际尾帧作为本集首帧状态参考；首镜确认Nico、Alice伤手与周围佣人关系后，再按本集节奏硬切新机位。
- 动作连续性：接住受伤的手 -> 牵住 -> 穿过大厅或走廊前往书房。主要方向保持一致。
- Alice表演：最开始忘记挣扎，随后看着Nico背影鼻酸；坦白不是流利演讲，而是呼吸乱、句子断、越说越控制不住。
- 声音调度：用户旁白承担大部分内容；若有现场台词，必须从旁白中切出独立窗口。
- 结束状态：两人到达书房门口或进入书房，取决于用户本次剪辑停点。

## 第21集：压抑后的欲望释放与照片钩子

- 剧情任务：用强烈亲吻回答Alice“你会不会嫌弃我”的恐惧，并抛出照片根本不存在的新疑问。
- 情绪曲线：Alice仍在坦白 -> Nico关门或抵近 -> 突然亲吻 -> Alice由震惊到回应 -> 吻从强烈转为缠绵 -> 两人恢复呼吸 -> Nico带着满足和委屈说话。
- 表演重点：不能只有接触。需要呼吸、抓握、身体距离和Alice从僵住到回应的清楚变化，避免画成冷脸强制动作。
- 手部：Nico的手落在Alice腰侧软肉，是“终于确认真实的她”的动作，不以嘲笑或嫌弃方式拍摄。
- 风险：强吻、门板受力、腰侧抓握和露骨描述可能触发模型或平台边界；保留关系与情绪强度，减少不必要的图形化细节。
- 钩子：“When did you ever send me Tamara’s photos?”必须给Alice反应，不立刻跳到下一集。

## 第22集：他从未爱过那张脸

- 剧情任务：揭开核心误会，证明Nico认出的是Alice本人。
- 道具链：Nico递手机 -> Alice接住 -> 手指发抖并向上翻聊天记录 -> 没有照片 -> 她僵住 -> 抬头质问。
- 文字风险：不依赖模型生成长聊天记录。手机只需让观众理解“不断翻找却没有照片”；精确界面由专项状态图或后期完成。
- Nico表演：捧住Alice的脸并直视她，不把答案说成霸总宣言，而像陈述一个自己也无法解释的事实。
- 关键主题：声音让他安心；他被她吸引在见到外貌之前就已发生。
- Alice落点：把脸埋进他怀里仍要再次确认体型问题，说明一次告白不能立刻治愈多年自卑。
- Nico落点：短暂愣住，不理解她为何会这样想，然后给出不以外貌为条件的回答。

## 第23集：改变身体，但爱情不以身体为条件

- 剧情任务：半年训练蒙太奇、Alice新形象、Nico的确认与关系兑现。
- 时间跳跃：明确“半年后”或半年过程；新任务硬切建立，不延续第22集站位。
- 蒙太奇任务：饮食、运动、训练和镜中变化各自只承担一个清楚动作，不把半年变化压成混乱变形特效。
- Alice表演：看到镜中自己首先是不敢相信，随后是因掌控生活而产生的自信；不能拍成“瘦了才终于有价值”。
- Nico表演：从身后拥抱；听到别人索要联系方式后有克制占有欲，但对Alice胖瘦的态度始终一致。
- 关键台词：支持她变瘦的前提是她因此快乐。该句后的Alice反应需要停留。
- 结尾亲密：可通过抬下巴、亲吻、倒向床面和衣物落地做含蓄转场，不需要图形化表现性行为。

## 跨集视觉母题

- 手：母亲把Alice拉回去；Alice抓住Tamara头发；Tamara伸手抓Nico裤脚；Nico掰开Alice捂伤口的手并牵走她；Nico捧脸；Alice翻手机。手的归属和力度反复表现“谁控制、谁拒绝、谁保护”。
- 视线：Alice长期低头或躲避；Tamara确认旁人是否在看；Nico越过人群只看Alice。故事核心是从“没人看见她”到“他在人群中只看见她”。
- 声音：Nico最终确认自己被Alice的声音与存在吸引。第22集需要让他真正听她说话、在声音后出现安定反应，而不是只用台词解释。
- 身体：摄影机尊重Alice胖与瘦两个阶段的身体。她的羞耻来自人物经历，不能成为镜头本身的评价。
