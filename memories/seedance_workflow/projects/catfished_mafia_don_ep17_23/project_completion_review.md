## 本项目形成的稳定工作流

```text
阅读完整剧本
-> 用户确认负责集数
-> 先拆整集自然片段
-> 标注片段时长与现场对白区间
-> 确定每段情绪任务、动作因果和结束状态
-> 按约3秒一次真实硬切设计提示词
-> 顺序生成并利用等待时间处理下一集音频
-> 根据实际成片反馈局部重做
```

## 最重要的成片经验

- 快节奏来自真实硬切和信息换手，不来自单镜推拉、变焦或人物慢慢移动。普通镜头原则上不超过3秒。
- 旁白进入新信息时，画面要及时提供对应证据、人物反应或关系变化，不能停留在上一句动作。
- 强情绪至少同时落在面部、身体和关系后果上；对手受痛、旁观者震惊和主角的委屈爆发都需要独立观看入口。
- 打斗镜头按进攻、承受、反抗、失衡和环境后果快切。玻璃破碎、伤口和道具位移必须具备可见因果，并在后续持续存在。
- 过肩镜头写清肩膀属于谁、拍摄对象是谁以及俯仰角度；高低机位可以直接改变压迫感和观众立场。
- 手机画面采用“持机者肩后看屏幕、正面反应只看手机背壳”的几何规则，跨镜锁定持有人、手、高度和朝向。
- 同集后续片段需要继承亲吻、牵手、拉架等连续身体动作时，完整视频延长比单张尾帧更容易保持动作轨迹和情绪。
- 参考素材按语义职责各绑定一次。站位图很有用，但必须包含当前持续参与动作的所有角色，否则会导致人物消失或构图被锁死。
- 环境或道具空镜不用于凑镜头数量，应承担动作后果、状态确认、空间转换或情绪缓冲。

## 带入新项目的方法

新项目只继承上述方法，不继承本项目的角色、剧情、空间、伤势、图片编号和具体提示词。开工时重新阅读完整剧本，等待用户确认负责范围，再开始拆段与时间轴设计。
