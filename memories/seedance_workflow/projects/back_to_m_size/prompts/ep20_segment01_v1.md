【生成任务】

生成14秒、9:16竖屏、海外真人旁白短剧风格的视频，共6个真实镜头，默认真实硬切，每镜不超过3秒。画廊长椅区，Sarah坐在画面左侧，Sophie坐在画面右侧；两人的手已经分开，Sophie脸上留着上一场谈话形成的一条自然泪痕。Sarah平静说出自己过去不发火是因为害怕。她说话期间，一名画展来宾从镜头近前经过并完全遮满画面，遮挡中切到旧公司：过去的Sarah想表达不满，却攥紧文件、把话咽回去并低头接受。另一名旧公司人物再次完全遮挡镜头，切回现在的Sarah完成台词。Sophie嘴唇动了一下想回应，Sarah看见后没有让她继续掌控话题，目光变得更清醒，片尾停在她准备提出新问题的稳定状态。

【空间与道具状态】

时间：当下为七月中旬下午，画廊由暖色轨道灯和走廊远端的柔和自然光照明；旧公司回忆为过去的工作日下午，室内由窗外自然光与顶灯共同照明。

长椅走廊：Sarah坐在长椅左侧，Sophie坐在右侧，始终保持Sarah在画面左、Sophie在画面右。白色手提包直立在画面最左下方、紧贴Sarah右小腿外侧，由Sarah右手握住包柄。双方双手分开；Sophie一侧脸颊保留一条自然泪痕，双手放在自己的膝上。

原公司办公区：过去的Sarah位于会议桌近侧座位，手里拿着一份薄文件。旧公司同事把另一份薄文件推到她面前，随后经过镜头近前完成返回当下的遮挡；不说话。

【声音时序】

2.5—9.5秒，Sarah直视Sophie说：
“The old Sarah never got angry. But that wasn’t because I didn’t care. It was because I was afraid to.”

`I said`是叙述，不进入现场对白和口型。Sarah前半句平稳，`didn’t care`开始更认真，`afraid to`声音略低但不躲开Sophie。对白跨当下与回忆连续播放，不因遮挡切换而重新开始。全段没有其他人物对白。

【镜头设计】

镜头01｜0—2.5秒｜被上一问钉住的两人
从Sophie肩后平视Sarah，建立Sarah在左、Sophie在右的关系。Sophie仍带泪痕，嘴唇微张却没有接上话；Sarah右手握着外侧白包，左手在自己膝上轻轻收紧，随后抬眼稳稳看回Sophie，准备说明自己过去为何沉默。

镜头02｜2.5—4.5秒｜Sarah开口与第一次遮挡
Sarah三分之四近景开始说第一句。她说到`old Sarah`时短暂看向自己收紧的左手，随即重新看向Sophie。4.2秒左右，一名深色外套的画展来宾沿走廊从镜头右侧近前走向左侧，身体完全遮满画面；脚步自然经过，不看向两位主角。

镜头03｜4.5—7.2秒｜遮挡切到过去的Sarah
画面从同方向移动的深色同事背影后揭开，已经进入原公司办公区。Sarah的声音连续。一名同事从画外把另一份薄文件推到过去Sarah面前；她眉心短促收紧，握住原文件的手指明显用力，刚想抬头拒绝，又停住呼吸，把新增文件也接到怀里、垂下目光并轻轻点头。她不说话。镜尾这名深色着装的同事从镜头左侧近前走向右侧，再次完全遮满画面。

镜头04｜7.2—9.5秒｜遮挡切回现在
从同方向掠过的画展来宾背影后重新揭开当下Sarah近景。她已经抬起目光，直视Sophie完成`It was because I was afraid to.`。说到最后两个词时，她原本收紧的左手在膝上慢慢松开，脸上没有自怜，只有终于说清事实后的清醒。

镜头05｜9.5—11.5秒｜Sophie想接管解释
Sarah肩后拍Sophie。Sophie听完先眨眼一次，嘴唇动了动、胸口吸入一小口气，身体准备向前，像要立刻替自己解释；她双手仍停在自己膝上，脸上原有泪痕保持不变。

镜头06｜11.5—14秒｜Sarah决定追问
切回Sarah近景。她看见Sophie即将开口，左手在膝上轻抬半寸后落稳，目光从Sophie嘴唇回到她的眼睛；下颌收紧一点，身体略微前倾，明确形成“这次由我来问”的状态。片尾Sarah仍在左、Sophie仍在右，Sophie没有开始新的对白，为片段02开口留出稳定接点。
