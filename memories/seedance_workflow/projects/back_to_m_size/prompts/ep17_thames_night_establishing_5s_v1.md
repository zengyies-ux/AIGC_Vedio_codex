# EP17 泰晤士河夜景空镜 V1

## 制作设置（不复制进提示词）

- 模型：Seedance 2.5
- 生成方式：独立原生生成
- 正文与生成时长：5秒
- 并发依赖：无
- 主要画面任务：用一艘从左向右驶过泰晤士河的游船，快速建立伦敦夜晚与时间气氛
- 视觉记忆点：在游船持续向右行驶的动作中，从完整河面硬切到低机位近景；航向与速度不断裂

【生成任务】

根据参考图生成一段5秒、9:16竖屏、真人电影质感的伦敦夜间空镜，共2个真实镜头。泰晤士河水面占主要画面，塔桥与伦敦夜景保持稳定。一艘亮着暖色舱灯的小型游船从画面左下方向右平稳航行；在游船运动中切换一次机位，第二镜继续同一艘船的同一航向和速度，留下自然尾流与被打散的城市倒影。

【人物与场景参考】

泰晤士河夜景：【@图片1】

场景参考负责泰晤士河、塔桥、伦敦天际线、夜空、城市灯光、河面倒影和唯一一艘游船的外观与空间关系。

【空间与道具状态】

时间：深夜，天空深蓝近黑，城市与塔桥灯光温暖克制，河面保留深色细节。

泰晤士河夜景：塔桥和建筑固定不动，同一艘游船始终朝画面右侧航行。游船不掉头、不停止、不复制；第二镜从第一镜结束位置继续运动。

【声音时序】

全段没有对白、旁白和背景音乐。只保留低量河水声、游船发动机远声、船身划水与尾流声、很轻的伦敦城市远声。声音连续穿过切镜，不使用鸣笛。

【镜头设计】

镜头01｜0—2.3秒｜泰晤士河夜景大全景，稳定机位轻微推近
严格保持参考图中的塔桥、天际线和灯光位置。唯一一艘游船从画面左下方完整进入，匀速驶向画面中下部；船头推开细小水浪，暖色舱灯在河面形成短促倒影，宽阔河面为右侧航向保留足够空间。

镜头02｜2.3—5秒｜动作匹配硬切，贴近河面的侧向近景
在游船持续向右行驶的动作中切到更低、更近的同侧机位，同一艘船从画面左中部继续驶向右下方，航向和速度与前镜一致。摄影机只向右轻摇跟随约十度，船尾自然拉出一条扩散尾流；尾流依次打散金色灯光倒影，塔桥在后景稳定柔焦。游船接近右侧但仍完整留在画面内时结束。
