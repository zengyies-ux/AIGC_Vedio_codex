# EP15—EP16阶段小结

## 结论

EP15多数片段一次成立，是因为剧本信息、功能场景、人物行动和镜头趣味同时被落实。EP16不够优秀，核心不是电话戏天然无聊，而是设计时只写了人物怎样想、怎样看，没有先规定他们在空间里从哪里出发、要去哪里、途中做什么、最后停在哪里。

原生生成不等于取消连续性设计。模型面对大场景和多次切镜时，如果没有清楚的场景参照物、行动路线与结束落点，就会自行让人物换位置、守在错误地点或重复相似表情。一次合格的视频延长可以解决相邻段的实际状态接力；使用视频延长时，源视频和本段需要的角色、场景、道具资产必须同时提供。

## EP15为什么顺

1. **场景按功能拆开。** Director办公室、会议区、工位、餐厅内、餐厅外和公寓楼下各自承担明确事件，人物进入空间后马上知道能和什么互动。
2. **角色始终在做事。** Director说完放手、Sarah放下电脑、松开衣摆、碰杯、Nathan递伞、Sarah接伞，都把态度变成了可见动作。
3. **动作来自场景与剧情。** 会议屏幕反光、电脑合盖、雨滴和伞面既提供画面趣味，也承担情绪或转场任务，没有另塞无意义表演。
4. **生成方式服从实际接力。** 换场和稳定新状态用原生生成；持伞手位与运动方向需要继承时，只延长一次。
5. **用户批注和Codex补充形成互补。** 用户先指出重点情绪与画面方向，Codex再从空间、道具和镜头中补出动作，因此没有把“主动发挥”理解成擅自增加剧情。

## EP16为什么退步

1. **低估了双场景电话的空间难度。** 电话两端不断交叉剪辑，虽然没有人物接触，却同时存在两套站位、两部手机、雨伞、门厅、树、窗和行李箱。原稿没有先为每个空间确定固定锚点，Luke因此在卧室不同位置来回漂移。
2. **把情绪词当成了表演。** “等待、迟疑、看清、失落”写得很多，实际动作却不足。Sarah长时间站在门口淋雨，Luke则靠换机位和换位置制造变化，人物没有清楚任务。
3. **没有充分使用场景参照物。** 公寓图已经明确“大树在左、门厅在右”，卧室图也明确“大窗与行李箱”。若一开始就指定Sarah从右侧门厅走向左侧树下、Luke固定在窗边行李箱旁，模型的自由漂移空间会小很多。
4. **过早把全部片段判为原生并发。** 片段02到03属于同一通电话，实际成片已经建立人物、持物和空间状态。此处使用一次延长更适合接住现有结果；片段04从树下开始，单人完成返回门厅的动作链，则可以独立原生。
5. **动作链没有拍完。** 片段04只写“向门厅走”，没有把回家拆成抵达屋檐、收起手机、完整收伞、开门、跨入室内，结果模型让Sarah撑伞直接进门。
6. **延长素材意识出现遗漏。** 视频只能继承源片中已经出现的状态，角色身份、服装、场景结构和关键道具仍需要原始资产共同约束。延长任务也必须绑定完整角色图、场景图与道具图。

## EP17开始前的执行方法

每个原生片段先完成一张内部空间卡，再写逐镜：

| 项目 | 必须回答 |
|---|---|
| 开场锚点 | 角色紧邻场景中的哪个固定参照物？ |
| 当前任务 | 角色这段时间具体要完成什么，而不只是“感到什么”？ |
| 行动路线 | 是否移动；若移动，从哪个参照物走向哪个参照物，画面方向是什么？ |
| 可用互动 | 当前场景中已有的手机、桌椅、窗、门、杯子、文件或衣物能否承接情绪？ |
| 结束落点 | 人物、手机、随身物和门窗在片尾分别处于什么状态？ |
| 接力方式 | 下一段需要继承持物、接触、运动方向或复杂站位吗？需要则等待合格源片并延长一次。 |

电话或长对白不允许只靠正反打维持：

- 说话者在台词重音处完成一个有目的的动作，例如走向树下、放下文件、握紧又松开拉杆。
- 听者必须出现及时回应，可以是停止动作、改变距离、放下物件、转身或压住想说的话。
- 每个空间只允许一条主要移动路线；另一个角色可以固定在场景锚点，用道具和身体重心完成表演。
- “让人物动起来”不等于让人物乱走。动作必须改变信息、关系或下一段状态。

## 原生与延长的当前尺度

- **优先原生：** 换时间、换地点、人物已经完成上一动作、可以从稳定状态重新建立；原生时必须写清开场锚点、路线和落点。
- **使用一次延长：** 相邻段仍在同一事件中，且已有成片的持物、手位、站位、运动方向或环境状态值得继承。
- **延长输入：** 合格源视频 + 本段所有必要角色图 + 场景图 + 道具图。不能只上传视频，也不能依靠源视频记住完整设定。
- **避免继续延长：** 一次延长已经完成动作、下一段出现换场或稳定新状态时，回到原生生成，避免画质继续下降。

## EP17的工作重点

EP17时长较长，先按剧情任务与空间变化拆段，再判断哪些段真正可以并发。用户批注负责指出情绪高点和想要的画面方向；Codex必须主动补齐每段的空间锚点、行为路线、场景互动、直接听者反应和一个有意义的视觉落点，不能等用户逐条提醒人物应该做什么。
