## 版本状态

- 中文原稿、中文批注版、英文版以及EP15—EP21拆解稿均已归档；EP15—EP21正式总时长与对白时码已经提供。
- 两份新版均未发现Word批注部件或修订记录；可见“批注”均以内嵌文字、青色高亮、红／橙色文字、下划线或分隔符存在。
- 英文版负责最终剧情措辞、现场对白和屏幕文字；中文批注版负责用户的分段、表演、镜头、转场和资产意图。
- 两者出现差异时，先判断是翻译差异还是用户主动导演改编，不让导演建议覆盖原稿事实。
