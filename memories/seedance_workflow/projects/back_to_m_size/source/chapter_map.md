# 我穿回M码那天章节地图

## 卡点前与离开

| 章节 | 核心事件 | 关系与情绪变化 |
|---|---|---|
| 第1章 | 办公室、团建、客户宴和车内的羞辱蒙太奇；Sarah提交辞职并独自驾车离开 | “亲昵称呼”被揭示为长期贬低，女主第一次主动结束承受 |
| 第2章 | Sarah边收行李边与Luke通话，宣布去伦敦 | Luke仍把她的决定当作闹情绪，女主开始拒绝解释 |
| 第3章 | 回忆伤害；挂断Luke；看到Sophie嘲讽消息并丢掉发卡；Sophie突然上门 | 女主意识到两人的共同模式，旧友开始试探她是否真的会离开 |
| 第4章 | Sophie用眼泪与“最好朋友”身份挽留，Luke发来“我不同意” | Sophie的脆弱是一种控制；女主第一次不再顺从两人决定 |
| 第5章 | 铁盒、手链和合照唤起八年记忆；女主办离职并在大厅反问Luke；把向日葵扔进垃圾桶 | 她从怀旧走向清醒，明确指出Luke对Sophie和对自己的双重标准 |

## 离开与付费卡点

| 章节 | 核心事件 | 关系与情绪变化 |
|---|---|---|
| 第6章 | Sophie和Luke送Sarah去机场；纸袋中藏着继续羞辱她的便利贴；Sarah抵达伦敦 | 送别表面温情、实质仍是轻视；Emma用正常欢迎打开新生活 |
| 第7章 | Sarah适应工作、健身并穿回M码；事业开始获得认可；Luke的消息越来越控制；他在伦敦公司楼下看见她 | 身体变化与主体性恢复并行；Luke第一次因失去掌控和外貌变化真正震动 |

第7章末“Sarah？！”之后，最新版原文明确合并标有“【付费卡点】————————卡点后————————”；因此当前卡点后正文从第8章开始。

## 付费卡点后的主要推进

| 章节 | 核心事件 | 关系与情绪变化 |
|---|---|---|
| 第8章 | Luke说Sophie向他表白；Sarah纠正“Fatty”为“Sarah”，宣布不再回来 | 她最后的期待碎掉，同时第一次要求他尊重自己的名字 |
| 第9章 | Sarah说再见并投入新项目；与Nathan重逢；Sophie和Luke因动态追问 | 新关系提供尊重对照，旧关系开始因失去她而不安 |
| 第10章 | Luke解释自己没有接受Sophie；Sarah拒绝继续猜他的沉默 | 她不再需要他的答案，也不再替含糊关系承担理解成本 |
| 第11章 | Sarah获得季度最佳，看到Sophie在旧公司群里继续嘲笑她 | 认可与背刺并置；她停止替Sophie找“没有恶意”的借口 |
| 第12章 | Nathan带她参加行业交流，Sarah获得新机会；Luke预告来伦敦 | 事业空间扩大，Emma提醒她别回头 |
| 第13章 | Luke提前出现在公寓门口，带柠檬挞、薯片和Sophie的信 | 他仍用旧习惯靠近；Sarah拒绝突袭式关心并建立访问边界 |
| 第14章 | Sophie冒充代理联系人打给Sarah的客户；Sarah直接制止 | Sophie从语言羞辱升级为工作越界；女主第一次明确说“不需要你帮” |
| 第15章 | Luke先替Sophie辩解，得知实情后沉默；Sarah拿下项目并与Nathan吃饭 | 旧同盟第一次松动；正常认可开始替代贬低标签 |
| 第16章 | 雨中电话里Luke继续为Sophie解释，又不肯承认来伦敦是为了Sarah | 女主听懂沉默背后的逃避，拒绝见面并独自走回去 |
| 第17章 | 项目第二阶段金额翻倍；Emma和Nathan分别肯定她 | Sarah事业稳定，核心缺口变成“仍不敢相信自己值得被认可” |
| 第18章 | 画展入口遇见Sophie；Sophie震惊于她的变化，并挤进她和Nathan之间 | 旧关系模式重演，但女主主动换位，不再把空间让出去 |
| 第19章 | Sophie靠近Nathan，随后用眼泪诉说自己难熬；Sarah逐条说出伤害 | 女主不再被脆弱表演带走，首次正面对账 |
| 第20章 | Sarah揭穿Sophie通过社交媒体追踪私人活动；Sophie彻底卸下伪装 | 友情面具破裂；女主指出瘦不瘦都不该被羞辱 |
| 第21章 | Sophie威胁离开；Sarah删除她与Luke的联系方式 | 删除象征不再需要，旧关系完成心理断开 |
| 第22章 | Sarah收到窃取机密的举报，整理定位、订单与门禁证据 | Sophie报复升级；女主用专业能力守住自己，不再陷入恐慌 |
| 第23章 | 法务确认举报不成立；Luke仍劝她别把事情闹大 | Luke的模式没有改变；Sarah再次删除新号码，选择不再耗费精力 |
| 第24章 | 三年合同签署；Nathan表达“我乐意”在她身边；Sarah主动问他是否在追自己 | 平等欣赏取代拯救，女主掌握感情关系的提问权 |
| 第25章 | Nathan正式追求；Luke在楼下迟到地道歉；Sarah说自己已经不需要 | 她拒绝迟到的补偿，最终以名字、工作和自我选择定义自己 |

## 选集时优先关注的连续高点

- 第7章末至第9章：外貌震动、Sophie表白信息、Sarah纠正名字并说再见。
- 第13—16章：Luke追到公寓、Sophie越界联系客户、Sarah在雨中拒绝替他们继续解释。
- 第18—21章：画展重逢、Sophie抢位、友情对账、面具脱落与删除联系方式。
- 第22—23章：栽赃、证据反击以及Luke再次暴露纵容模式。
- 第24—25章：事业签约、平等感情线与迟到道歉的最终拒绝。

这些只是整本结构入口，不代表已经确定制作集数或分段。
