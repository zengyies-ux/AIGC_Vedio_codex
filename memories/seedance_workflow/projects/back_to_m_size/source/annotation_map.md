# 前六章标注与画面理解

## 标注形式

原始DOCX没有Word批注或修订记录。用户的导演意见直接存在于正文中，主要有四种：

1. “转场／分段／回忆／卡点”等分隔文字。
2. 蓝色突出显示，Word内部记录为cyan highlight。
3. 红色文字。
4. 破折号后直接追加的镜头、表演或机位想法。

最新版共有26个蓝色高亮运行，分布在19个段落位置；红字共有21个运行，同样分布在19个段落位置。蓝色与红色集中在第1—6章，第7章末另有卡点文字。第6章既有行内文字，也新增了蓝底、红字与下划线标记。

从标注分布推断，红色主要用于提前识别场景、造型、道具和素材；蓝色主要用于锁定必须拍清的动作、情绪、切镜与视觉落点。这是当前工作解释，正式制作时仍以用户对具体集数的最新说明为准。

## 红色文字对应的素材意识

- 地点与空间：办公室、团建、客户答谢宴、车里、伦敦、公司、工位、电梯。
- 角色造型：Sophie的S码连衣裙、奶白针织裙和大波浪发型。
- 关键道具：亮晶晶蝴蝶结发卡、铁盒、三人合照。
- 第6章新增：Sophie的粉色卫衣、丸子头、素颜与眼底发青；登机牌、便利贴；Emma与伦敦到达空间。

这些标记不是让一张场景图包办整段，而是在提醒开工前先数清具体空间和可复用资产。例如“公司”至少包含工位、电梯厅和大厅三个动作功能区；“Sarah家”至少包含收拾行李的卧室、放发卡和水果的客厅、Sophie上门的玄关。实际选到对应集数时应按功能区准备简单场景资产。

| 第6章送别 | “车”被蓝色突出并带下划线 | 提醒车外装行李、车内座位与后视镜关系是连续空间，后续场景资产要区分车外和车内职责 |

## 第6章最新版新增导演备注

- Luke把行李箱放入后备厢、动作落稳后，明确“分段，转场直接到车内”。这里同时结束车外道具动作并重建车内座位，边界稳定。
- 车内后视镜视线结束后，备注提出用Luke打开后备箱形成遮挡，再硬切机场室内。它利用深色实体遮满画面隐藏剪辑，前后都必须先拍清动作落点，不能让“开后备箱”与已结束的车内行驶顺序冲突；正式制作时应根据英文成片时间重新整理为合理到达动作。
- Luke说“待不下去随时回来”后单独分段，让下一段从Sarah无回应、走入安检开始，保护她拒绝旧关系的情绪落点。
- Sarah回头看到Sophie雀跃、Luke低头看手机，确认二人并不难过后再分段；下一段转回登机口和纸袋，信息焦点清楚改变。
- 抵达伦敦后备注提出“大运镜，或者快速变焦，快切模糊场景来到Emma”。其目的不是单纯炫技，而是把十二小时旅程压缩成一次强烈的世界切换，并以Emma举牌欢迎作为清晰落点。正式采用时只选一种运动，并保证模糊中存在真实切点。

最新版把原先第5章后的“卡点后”移到第7章末，与“【付费卡点】”合并。当前卡点后正文从第8章开始。

## 分段线为什么集中出现在这些位置

- **地点已经改变**：办公室→团建→宴会→车内，或卧室→客厅→玄关，分开可防止多个空间在一段中互相污染。
- **动作已经落稳**：拉链合上、手抽开、发卡入垃圾桶、手停在半空、女主绕过Luke，下一段可以从明确状态开始。
- **情绪已经兑现**：女主说出“至于”、Sophie短暂露出真实眼神、Luke被双重标准问题问住，切点不会把前摇和结果拆开。
- **道具形成视觉句号**：纸巾、发卡、铁盒、合照、向日葵都在替关系变化落画；切在处置完成后便于接续。
- **生成风险得到隔离**：蒙太奇、电话双空间、回忆、手机消息和多人公司大厅各自成为可独立返抽的任务，不让一个局部失败拖累整段。

## 已经形成的前期画面母题

- **边缘到中心**：三人合照中Sarah永远站最边上；机场最后一次她站在中间；伦敦后她主动决定自己站在哪里。
- **别人替她命名到她纠正名字**：Fatty／Piggy等外号反复压住Sarah，付费卡点后她第一次明确说“Sarah”。
- **关闭与离开**：行李箱拉链、车窗、手机屏幕、玻璃门、电梯门都可以成为关系被关闭的可见动作。
- **丢弃与保留**：发卡和向日葵被丢弃；铁盒没有带走也没有扔，体现她并非抹除过去，而是不再让过去支配自己。
- **手部边界**：揉头、拉手、摸头、递纸巾看似亲密，却长期替她做决定；扔回、抽手、后退和绕过是女主夺回身体边界的动作线。
- **反射与未来自我**：镜子、车窗、玻璃门和Sophie眼中一闪而过的瘦身形象，可以连接旧自我、他人凝视与未来变化，但只能在剧情真正需要时使用。

这些母题用于形成画面感，不是要求每集重复同一种转场。正式选集后再从该段已有动作和空间中选一个最合适的记忆设计。
