# 我穿回M码那天

## 类型与当前阶段

- 类型：女频成长、友情背叛、青梅关系清算、职场逆袭与轻爱情线。
- 当前文本：中文版25章、中文版批注版与英文版均已归档；EP15—EP21正式拆解稿及对白时码已经提供。
- 当前阶段：EP15—EP21全部制作完成并进入收官归档；用户整体满意，预计仅保留很少的后续局部修改机会。
- 画幅、目标市场与正式模型：待进入具体集数时确认；当前工作流按海外9:16旁白短剧和Seedance 2.5预备，不提前写入正式提示词。

## 核心表达

Sarah长期被青梅Luke和“最好朋友”Sophie用体重外号、公开取笑与替她做主的方式困住。她辞职去伦敦后，真正完成的变化不是单纯瘦身，而是停止替伤害者找借口、重新相信自己的工作能力，并学会主动决定谁可以进入自己的生活。

全剧必须守住这一点：Sarah的价值不由M码、外貌或男性选择证明。瘦身是她重新掌握身体和生活的可见过程；核心落点仍是“我瘦不瘦，都不该被你叫Fatty”以及“不需要谁来道歉或追求，才能证明自己值得”。Nathan的作用是提供平等、尊重和欣赏的关系对照，不能拍成拯救女主的人。

## 主要人物

- Sarah：女主。前期习惯退让、替他人解释，离开后逐步建立边界、自信和职业能力。需要明确区分离开前、伦敦适应期和稳定成长后的造型状态。
- Luke：Sarah的青梅竹马。习惯把轻视包装成关心，把沉默和替她决定当成亲密；直到失去她后才逐渐意识到依赖与感情，但道歉来得太晚。
- Sophie：Sarah从小的朋友。用玩笑、脆弱和“为你好”维持优越感；Sarah离开后从试探、嫉妒升级到越界联系客户、跟踪活动与栽赃。
- Emma：伦敦室友与支持者。提供正常、直接、不过度替Sarah做决定的友谊。
- Nathan：高中同学，后来成为商业与感情线的重要人物。欣赏Sarah的能力，保持尊重与分寸，不以怜悯定义她。
- Director、HR、同事、客户与活动来宾：按具体集数的剧情职责选择，不提前建立全部资产。

## 结构节点

- 第1—5章：离职与离开前的关系清算，文档中有大量分段、转场、情绪和资产标注。
- 第6章：机场送别与抵达伦敦，最新版新增多处分段、遮挡转场和快速运镜备注。
- 第8章前：Luke在伦敦第一次看见已经改变的Sarah，并惊艳地叫出她的名字；最新版在这里合并标为“【付费卡点】————————卡点后————————”。
- 第8—25章：旧关系追来、事业获得认可、Sophie逐步暴露、Sarah完成边界建立，最终拒绝迟到的道歉。

## 场景资产规划原则

进入具体集数前，先把对应剧情拆成简单功能区资产。一张图只承担一个主要空间职责；同一大地点若包含入口、工作区、会谈区、观众区或关键道具区，按实际动作分别准备。不可逆状态只在会反复入镜时建立变体。

目前只建立候选清单，不要求一次生成全剧所有场景：Sarah原住处的卧室／客厅／玄关，原公司工位／电梯厅／大厅，车内与机场，伦敦公寓／办公室／公司外台阶，餐厅／交流活动／画展入口与展厅／廊道，河边与公寓楼外。实际制作范围确定后再裁减。

## 固定制作偏好

- 用户会尽量提供对白时码、分段想法与情绪点；这些是优先导演依据。未标注处仍需从剧本主动推导表演。
- 情绪标签必须翻译成脸、视线、呼吸、声线、身体距离、重心和手部行为，并安排直接对象与关键关系人的回应。
- 不使用无任务的多人中景覆盖旁白。每镜必须新增信息、动作结果、人物选择、关系变化、空间证据、节奏冲击或视觉趣味。
- 分段主动比较3段与4段，以情绪闭环、稳定终态和返抽影响选择，不机械追求段数少。
- 场景资产保持简单、职责单一，优先为选定集数准备真正会反复使用的区域。
- 全段禁止BGM；关键刺激、高点和余波应设计少量有因果的现场声音。
- 提示词采用最小充分描述，导演分析、备选动作与失败推理不投喂Seedance。
