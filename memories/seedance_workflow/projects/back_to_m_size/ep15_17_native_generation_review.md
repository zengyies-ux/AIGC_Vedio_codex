# EP15—EP17原生生成小结

> 2026-09-13：其中可复用的“可拍事件、功能场景、人物来路、关系轴、道具交接与屏幕减载”已小重构进核心工作流；本文件继续保留项目证据与具体案例，不作为另一套提示词模板。

## 核心结论

EP15—EP17证明，原生生成本身并不难。与宴会厅长场景相比，本轮返工明显减少，关键不在于给Seedance更多限制，而在于前期把三件事处理正确：

1. 场景图按功能区拆开，而且每张图结构简单、参照物清楚。
2. 分段停在换时、换场、完整动作结束或情绪落稳的位置，使每段可以独立完成一个任务。
3. 提示词明确人物从哪里来、要做什么、对谁做、怎样回应和最后停在哪里。

当这些条件成立时，换时间、换地点或进入稳定新状态的片段都可以优先独立原生并发。视频延长只保留给持物、接触、运动方向或真实站位必须继承的接缝。

## 本轮为什么基本一次成立

### 1. 场景多，但每个场景不杂

Director办公室、会议室、开放办公区、住宅、餐厅、雨街、阳台和公司门口各自承担一种主要剧情功能。人物进入后，桌、门、窗、屏幕、杯子、雨伞或通道都能直接提供动作，不需要模型在一张复杂大场景里自行寻找站位。

场景数量增加没有提高复杂度，反而隔离了任务。真正危险的是一张场景图同时包含多个功能区、多人关系和多条行动路线。

### 2. 分段减少了每次抽卡的失败范围

本轮多数段落只承担一个主要情绪兑现：正式认可、同事祝贺、朋友谈心、雨中等待、商业尽调或被Nathan说中。每段的动作链可以在片尾完整落稳，因此下一段能够原生重建，不必为了表面连续反复延长。

### 3. 人物一直在完成具体事情

有效动作包括Director说完后放手、Sarah合上电脑、放下杯子、收伞进门、Emma拍肩和碰杯、Nathan结束电话、审阅文件、带汽水走到工位。它们既防止人物罚站，也把态度转化成观众能看见的证据。

### 4. 镜头技巧都有剧情职责

会议室快速横移最后落到Sarah，负责把群体认可集中到她身上；电脑合盖、玻璃门框与黑色遮挡承担换时或换场；雨伞、水洼、河面尾流和屏幕倒影承担情绪或视觉接力。技巧服务信息与情绪，所以不会显得为了炫技强行加入。

## 这三集实际返工集中在哪里

### 1. 手机与电脑屏幕

屏幕是最稳定的高风险项。问题不是原生生成，而是提示词要求模型同时完成手机几何、手指操作、复杂界面和可读文字。

后续规则：

- 剧情不依赖可读内容时，不给屏幕特写，只从正确肩后交代持有者和一次操作。
- 必须显示文字时，界面保持极简，只出现必要短句，并让载体、屏幕朝向和可读时间固定。
- 电脑更适合用停笔、合盖、反光或人物视线表达结果，不让复杂表格成为镜头主角。

### 2. 提示词有时只有信息，没有画面行为

当角色只是走来、站定、说话、切正反打，成片即使不穿帮也会无聊。EP17片段07 V1的Nathan没有明确来路，也没有与Sarah共同操作的东西，结果人物像突然刷新在工位旁。

后续规则：每段至少为主关系设计一次简单、有因果的互动。优先从现有道具与场景寻找，例如递汽水、放文件、碰杯、敲桌提醒、拉开椅子、收伞或把电脑合上。先交代道具从哪里来，再完成递出、放下、接住或收回的完整归属变化。

### 3. 双人轴线与站位

同一场对话先建立一条固定主轴。例如主双人构图中Sarah在画面右、Nathan在画面左，那么这一场的双人镜头保持这个左右关系；Sarah近景朝画面左看，Nathan近景朝画面右看。过肩反打只更换观看对象，不把摄影机跨到两人连线另一侧。

后续每场内部空间卡固定记录：

| 项目 | 记录方式 |
|---|---|
| 主双人构图 | 谁在画面左，谁在画面右 |
| 场景锚点 | 每个人紧邻哪张桌、哪扇门、哪条通道或哪把椅子 |
| 视线方向 | 左侧人物看右，右侧人物看左 |
| 接近路线 | 从哪个参照物走向哪个参照物，最终停在对方哪一侧 |
| 摄影机侧 | 所有正反打保持在人物主轴同一侧 |

同一场对话默认不交换左右位置。若剧情确实需要换边，必须用一个连续镜头拍清人物完整走位，再用新的双人总构图重新建立主轴；不能在硬切后直接让人物出现在另一侧。

### 4. 出现、造型与道具缺少前因

人物突然出现、凭空换衣或突然持有道具，都会让画面产生梦境感。Nathan从尽调会议回到工位，应通过会议室门框、中央通道和手中的汽水建立来路；外套、雨伞、手机与饮料也遵循同一原则。

### 5. 主事件连续，不等于表面动作一直不变

EP16的长通话提醒我们：改变机位可以更新观看角度，却不能独自解决叙事单一。通话、亲密、等待或工作跨过多个旁白意义与情绪阶段时，应让信息、关系、人物行为、空间或环境结果随阶段变化；也可以使用剧本已经支持的通话对端、回忆、平行场面或真实空间迁移。新增人物、小插曲、第二场景或道具必须有用户意图和素材依据，不能为热闹临时改写主线。

## 下一集直接执行的顺序

```text
确认剧本事件与对白窗口
→ 按完整动作、换场与情绪落点拆段
→ 给每段选择一张简单功能场景
→ 固定人物左右、锚点、视线与路线
→ 为说话者和听者各设计一个有目的的动作
→ 从现有道具或环境中选一个互动或视觉记忆点
→ 单独检查手机、电脑、手部与持物归属
→ 决定原生并发或一次延长
```

## 当前生成判断

- **默认原生：** 新时间、新地点、稳定动作落点、没有复杂接触关系。
- **原生也能维持连续性：** 使用相同角色资产，写清场景锚点、主轴、进场路线和片尾落点。
- **一次延长：** 必须继承实际源片的手位、持物、接触、遮挡或运动方向。
- **不连续延长：** 延长完成后若已换场或动作落稳，下一段重新原生，保护画质。

本轮需要继续保持的不是增加提示词长度，而是让每一句描述都对应可见的动作、空间关系、情绪回应或镜头目的。
