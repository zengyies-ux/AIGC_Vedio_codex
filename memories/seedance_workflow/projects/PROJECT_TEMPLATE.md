# 新项目模板

只为当前项目建立目录；既有作品不为套模板迁移。此页用于首次建立，不是每轮必填导演卡。

## 推荐目录与职责

```text
project_slug/
├── project_overview.md      # 稳定故事事实与本项目偏好
├── production_state.md     # 当前任务、决定、采用依据、必要真实末态、未决
├── assets/README.md        # 真实素材与可用／停用／待补状态
├── source/                 # 原剧本、用户拆解及本次输入
├── prompts/
│   ├── INDEX.md            # 当前文字与实际采用关系
│   └── ep01_segment01_v1.md
└── reviews/                # 用户反馈、成片证据和项目复盘
```

小项目用扁平分集命名。只有过程已有保留需要时才用`production_history.md`或已有复盘承载；不每轮另建快照、交接文件或多层目录。

## 概览示例

```markdown
# 项目名

## 固定依据
- 制作范围、画幅、目标语言、类型与模型：
- 原剧本及已确认解释边界：
- 核心关系、人物不可变事实、观看目标与视觉基调：

## 本项目固定偏好
- 用户明确确认的审美、摄影、声音与权限边界：
- 需要持续使用的空间结构及道具归属：

## 入口
- 当前制作状态：production_state.md
- 素材：assets/README.md
- 文本与实际采用：prompts/INDEX.md
```

概览不维护进度，不逐人固定表情，不复述全局流程；通读后的必要稳定事实与原文链接留此页，不每集重读全剧。素材规划服务已设计画面；按[素材必需性](../execution_rules.md#references)实际核看后列最低需求与用途，解读规划继续。创意权限见[导演流程](../director_os.md#creative-boundaries)，不把可选未采用创意资产列为整集必需。

## 当前状态示例

```markdown
# 当前制作状态

## 当前任务与阶段
- 用户当前范围与阶段：连续前置设计／集中方案待审／提示词／局部返修；继续或明确独立重测：
- 工作模式：验证（默认）／常规；常规启用须链接用户实际认可流程与效果的记录：

## 已确认决定与采用依据
- 当前输入：完整剧本及目标集原文、实际音轨与内容指纹／原点、已核看资产链接：
- 本次仍有效的决定、当前解读／分段／提示词与整集预算链接：
- 音频候选、内部核查和采用来源；集中方案认可记录与未解阻断分别链接：
- 生成方式与实际源片依赖；计划和用户实际操作分别标注：

## 必要真实末态
- 只记录本次接续必须知道的实际空间、接触、持物、认知与情绪落点：
- 证据为用户反馈／实际源检查／仅文字设计；未知明确写未知：

## 未决
- 真正必要的素材／源片缺口及本次待办：
- 真实状态：仅文字完成、音频位置采用、是否实际听检、方案认可、实际生成及成片评价分别写；未知保持未知：

## 入口
- 概览、资产、提示索引；确需追溯的历史／复盘链接：
```

上述信息由GPT按实际工作维护，不要求用户填表或JSON；按当前任务使用需要的几项，不补空表、不填整集多层导演卡。拆解和分段结论留在采用文件，状态只链接；复杂接续需要的具体状态才写本页。输入改变与派生段首变化按[声音规则](../execution_rules.md#sound-and-time)重校，任务继承按[恢复范围](../continuity_and_review.md#task-recovery)执行。下一段认知、情绪与实际落点可归入必要末态，制作目的不进入可复制提示词。旧决定被新决定覆盖时直接替换，旧过程移入已有历史／复盘；不能只在长文顶部再叠一段“最新”。项目结束写“当前无活动任务”，总索引移入已完成区，只链接状态页。

## 资产与提示索引

- 资产按语义名记录职责与可用性，区分已核看、用户确认已备、待补、停用、临时路径；按[素材规则](../execution_rules.md#references)只阻断受影响正式绑定，不把未核验存在写成可用。每次生成图号在当段重新分配。
- 提示索引列当前文字、实际生成／采用证据及评价；分别保留仅文字完成、已生成、满意、止损可用、未知。最新文字或最大版本号不自动是可用基线。
- 单段、合辑与仅命名／格式修改分别标注。原剧本、旧提示词、素材和失败结果不覆盖；历史入口只按具体问题查询，不恢复当时“等待”为当前任务。

## 工作与复盘入口

剧本解读／分段见[导演流程](../director_os.md)；正式落稿使用[既有提示词模板](../prompt_template.md)；具体动作、声音与摄影查[执行规则](../execution_rules.md)；接续及实片证据查[接续与审片](../continuity_and_review.md)。本模板不复制完整方法，不改变提示词栏目及逐镜粒度。

真实反馈按“预期→实际→成立部分／偏差→原因假设→最小修正→验证结果”记录。只有实际反馈才下成片结论；项目偏好留本项目，可推广经验才更新唯一核心处，明确用户新决定立即按范围执行。细则见[反馈维护](../continuity_and_review.md#feedback-maintenance)。
