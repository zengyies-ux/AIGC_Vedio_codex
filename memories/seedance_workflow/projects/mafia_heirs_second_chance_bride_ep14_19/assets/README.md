## 使用边界

- 未经用户明确允许，不主动打开项目图片或视频；聊天已展示的画面可用于当次分析。
- “已展示/已提供”记录来源，不保证临时附件路径仍可用；“用户确认已备”不等于本轮已收到文件；待补项单列，不由制作完成推断资产齐备。
