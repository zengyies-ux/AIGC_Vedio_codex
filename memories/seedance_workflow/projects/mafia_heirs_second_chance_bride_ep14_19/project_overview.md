# The Mafia Heir's Second-Chance Bride

中文项目名：相爱的人总会相逢黑手党

## 类型与目标市场

- 制作范围：第14集至第19集，共6集
- 画幅：9:16竖屏
- 语言：英语现场对白；旁白由用户提供的成品音频承担
- 主要模型：Seedance 2.5
- 叙事类型：海外真人旁白短剧，黑手党爱情、双重生、养女替罪、家族背叛与第二次相爱
- 节奏基线：按海外旁白短剧执行，普通编号镜头原则上不超过3秒；最低真实镜头数按片段时长除以3后向上取整，只有真实硬切计为新镜头
- 剧本依据：英文版负责现场对白原文，中文版辅助确认人物心理与情绪方向
- 当前进度、审核与待修项只在[制作状态](./production_state.md)维护；按[提示词版本索引](./prompts/INDEX.md)查找适用文本，不从旧合辑推断最终采用版本。

## 当前故事目标

- 观众代入点：Evelyn前世替养妹坐牢、被家族抛弃，直到Adrian死后才知道他早已爱她；重生后，她拒绝再次牺牲自己，也决定在爱人仍活着时主动回应。
- 核心关系：Evelyn带着失去Adrian的记忆重新靠近23岁的他；Adrian表面危险冷静，实际早已爱她，也在暗中观察她为何熟悉自己与公寓。
- 第14至19集关系弧线：异常熟悉暴露 -> Adrian为她分析危险 -> 失败意面证明未来的爱 -> Evelyn主动承认丈夫与爱意 -> 深夜呼唤得到即时回应 -> 两周日常补回错过的人生 -> Moretti家族反扑。
- 主要爽点：被家族牺牲的女主不再独自忍耐；强势黑手党继承人在她面前笨拙做饭、随叫随到；女主主动补上前世没说出口的爱；外部威胁出现后男主立即以家族力量护住她。
- 主要情绪：不是单纯复仇，而是“这一次我要先救自己，也要让所爱的人活下来”。甜蜜越真实，第19集的危险回归越有拉力。

## 第14至18集甜感原则

- 这一阶段不是靠连续拥抱、亲吻或直白情话发糖，而是让观众不断发现Adrian早已把Evelyn放在第一位。
- Adrian的爱优先表现为“先行动、后克制、从不邀功”：发现她熟悉公寓时不逼问；听见顶罪计划后先判断危险；她说饿便立刻去做饭；把贴身银牌交给她；收到午夜消息后立即出现。
- 每段甜戏至少寻找一个具体证据，例如视线先确认她是否安全、手先替她处理生活细节、身体自然挡在威胁方向、离开后仍停在门外、失败后悄悄重新学会。
- Evelyn的情绪不是单纯害羞。她会把当前的小动作与前世失去的爱连接起来，从戒备、难以置信到终于确认“原来他这么早就爱我”，让甜中始终带一点迟来的心疼。
- 甜蜜镜头仍按海外旁白短剧快节奏执行。用眼神、手部、距离、动作结果和正反反应快速兑现，不用长时间静态对望或同角度慢镜头消耗情绪。
- 第19集危机越冷、越系统，前五集建立的日常安全感被打破时越有效；开场应主动利用暖日常与冷威胁的强反差。

## 重要信息差

- Evelyn明确带着前世记忆重生。
- Adrian也已重生，但观众直到第22集Adrian视角才得到完整确认。
- 第14至19集只允许表现Adrian对Evelyn异常熟悉自己的疑惑、试探或隐约期待，不能提前明确演成他已经承认重生。
- Evelyn并不追求血腥复仇。她拒绝让Adrian发动战争，是因为前世失去他的创伤，而不是因为她仍想保护Moretti家。

## 主要角色

### Evelyn Moretti

- 当前时间线约22岁，Moretti家养女，聪明、克制、重感情，刚刚拒绝替Bianca顶罪并离开家族。
- 她比前世更主动，但创伤仍会通过失眠、害怕醒来后一切消失、突然含泪和紧抓Adrian衣袖表现。
- 在Adrian面前的变化是本段核心：最初小心确认现实，随后逐渐松弛、开玩笑、主动亲吻并说出爱。

### Adrian DeLuca

- 当前时间线23岁，DeLuca家族继承人，黑色衬衫与腰间配枪体现危险身份；按用户确认使用腰间枪套，不恢复旧肩套方案。
- 已有保护欲和行动力，但尚未成为前世34岁时完全克制、令谈判桌鸦雀无声的成熟掌权者。
- 家庭反差是重要魅力：能召集黑手党家族谈判，却会把意大利面煮成一团；会在门外整夜守候，却装作一切理所当然。

### Vincent Moretti

- Moretti家族掌权者，以家族利益和亲生女儿Bianca为先。
- 第19集通过收买证人、闭门谈判、宣布Evelyn被逐出家族来操纵地下世界判断。

### Bianca Moretti

- Moretti家亲生女儿，Sofia坠楼案的真正责任方。
- 第14至19集不是主要现场角色，但她是Vincent反扑和Evelyn再次被栽赃的利益核心。

### Melissa

- Sofia的助理，第19集被Vincent收买后改变证词，声称亲眼看见Evelyn威胁Sofia。
- 她的表演重点是动摇、回避视线和接受利益后的不安，不演成主动掌控局势的反派。

## 时间与造型连续性

- 第14至16集大体发生在Evelyn抵达公寓后的同一天，Evelyn与Adrian的基础服装连续；Adrian可在厨房卷起袖口。
- 第17集进入当晚睡前与午夜。Evelyn更换得体睡衣；Adrian仍穿白天的黑衬衫并保留腰间武器，证明他一直没有休息。
- 第18集覆盖随后两周，通过日夜光线、有限服装变化和重复做饭动作表现时间流逝，人物身份与核心发型保持稳定。
- 第19集回到一次明确的当下事件。Adrian匆忙回家，脱下外套但腰间枪仍在。
- 每段在【空间与道具状态】开头单列“时间：”，分别写清当前场景与回忆的时段、窗外明暗和室内主光源。用户当次指定及剧本时间优先于参考图；图中下午或黄昏不得自动覆盖故事夜间。保留建筑陈设，只调整天空、照明和相应反射，门外背景也必须符合当前时间与空间。
- 若出现前世34岁的Adrian，必须与当前23岁版本在年龄、气场和服装上清楚区分；只在剧情真正需要时使用。

## 固定制作方式

- 先完整拆分单集并由用户确认片段时长、现场对白全局区间，再写单段提示词。
- 时间信息统一使用`timing_intake_template.md`收集。用户只需填写整集总时长、各片段时长、片段结束句、现场对白全局区间及衔接方式；Codex负责换算局部时间并优先锁定对白口型与声音连续性。
- 成片时长通常在旁白音频基础上多约1秒，放在动作结果或情绪反应后，不用于慢开场。
- 完整提示词文件顶部单列“制作设置（不复制进提示词）”，记录模型、独立生成或视频延长、源片、正文及生成时长、并发或等待关系。计划与实际操作分开记，实际操作以用户确认覆盖计划。
- 可复制正文的【生成任务】从“生成X秒、9:16竖屏、电影级真人短剧视频……”开始，保留镜头数、真实切点及画面任务；不写模型名、“正常生成”“不使用视频延长”或延长操作命令。视频对站位、接触和动作状态的参考职责仍保留在正文。
- 旁白只由后期音频承担；Seedance生成指定英文现场对白、口型、动作声和环境声。
- 旁白原文、旁白时间轴及“画面对应该句旁白”等校准说明只供Codex内部拆镜使用，不写入Seedance执行提示词；执行提示词直接呈现已经换算好的镜头时间、画面、动作和表演。
- 台词开始时先让说话者面部和口型可读，长台词可继续切听者、道具或关系反应，声音不中断。
- 每段主动寻找一个主要观看刺激，按“迅速进入 -> 情绪升级 -> 兑现 -> 反应或钩子”组织镜头。
- 未经用户明确允许，不主动打开项目中的任何图片或视频。用户在聊天中展示的画面可以直接用于当次分析。
- 素材引用只写固定简名，例如“办公室：【@图片5】”；下方必须以“办公室：……”对应。参考区不堆服装、家具或门窗职责，详细空间、群像分配和道具状态写入下方同名段。需要区分多个场景时使用短而唯一的名称，不在两处换简称。

## 本项目已验证的镜头执行规则

- 空间方向优先于连续炫技。人物需要跨越大厅、电梯、公寓、走廊或不同房间时，先明确入口、出口、人物左右、摄影机所在侧、运动方向和固定空间锚点。不要强迫人物用一个长镜头连续穿越多个空间；优先在动作落稳的因果节点硬切，并在每个新镜头中重新说清空间关系，降低方向翻转、人物瞬移和场景变形风险。
- 默认不使用大远景、超远景或俯瞰全局式空旷构图。人物原则上占9:16画面高度约三分之二，优先采用半身近景、过肩、局部特写、贴近人物的全身关系镜头和前后景遮挡。只有确有叙事价值时才短暂破例使用较宽镜头，时间原则上不超过2秒，只交代一个必要空间信息，随后立即回到人物。
- 剧本没有明确强调哭泣或泪水落下时，不默认用流泪代替复杂情绪。优先将感动、委屈、憋笑、迟疑和心疼拆成可见微表情，例如眨眼频率、鼻翼、吞咽、抿嘴、呼吸、手指和肩线变化；自然眼角湿润或泛起泪光可以保留，但不能自动升级为持续落泪。
- 回忆优先由当前时空中的物件、触感、声音或小动作触发，再通过动作匹配、方向匹配或道具匹配进入过去。回忆内部也必须有“起点 -> 选择或变化 -> 结果”的行为链，不能连续播放静态空房、背影和摆姿。纯场景空镜只可作为不超过2秒的情绪标点，并且必须承担清楚信息。
- 素材采用“角色轻绑定、场景强锚定、风险道具精确控制”。角色图只锁定身份、外貌与当前服装；场景图重点锁定入口、出口、门窗、家具、固定物品和路线；手机、餐叉、门把、眼镜等高风险道具明确数量、归属、正反面、初始手位和最终去向。每张素材在提示词中只`@`一次，后文使用角色、场景或道具的语义名称。
- 每段应有可读的情绪变化或记忆点，并通过自然动作、互动与微反应避免画面单调。优先在主动作中设计迟疑、力度、视线、距离及对方回应，让动作真正改变关系或情绪；不强制额外增加小动作，也不为丰富而添无动机的递物、换手或走位。关键事件后保留可读反应，不退化为静态对望。
- 画面不必逐字复刻旁白，但必须让观众得到与旁白相同或更强的剧情含义。旁白负责陈述时，画面优先补充行为证据、人物反应、信息差、反差或未说出口的欲望；不能因为追求“对应”而退化为机械配图，也不能脱离原剧情另讲一件事。
- 当整集剧本、各片段时长、现场对白区间与素材职责已经清楚时，可以一次性输出整集所有片段提示词。比较前段结尾与本段开场的具体空间和人物关系：同场且站位、接触或连续表演复杂时，优先等合格源片后延长；换场、跳时或主动重新建立关系时，独立生成并硬切衔接，无源片依赖的片段可并发。同场简单关系可独立生成或用静态状态参考，不因同场而强制延长，也不因跨集而排除延长；开场承接、段内随后换场时仍可先延长再硬切。

## 固定审美方向

- 8K超高清制作目标、120fps高帧率运动质感，极致真人电影实拍效果；真实发丝、皮肤纹理、自然瑕疵与布料编织细节清楚可见，拒绝过度磨皮、CGI塑料感与虚假材质。
- 最终交付为9:16竖屏，不生成横向黑边；保留球面电影镜头的质感，不同时指定冲突的2.00:1画幅。近景可以只拍场景局部，固定结构留在画外不等于被删除，不为展示全屋牺牲人物占比。
- 摄影质感以ARRI Alexa 65、Cooke vintage cinema lenses、35mm胶片颗粒与Kodak Vision3 500T美学为基线；纪录片式写实表演，自然光与环境光融合，运动场景保留真实、适量的快门模糊。
- 人物与环境比例真实。严格保持场景图的建筑结构、家具和物件位置；换机位只改变观察方向，不擅自删改、移动或重新装修场景。
- 公寓日常以曼哈顿夜色、暖色室内灯和深色木材形成私密、安全但略显孤独的空间。
- Moretti与地下世界压力场景转为更冷、更硬的构图与光线，但不改变人物肤色和整体写实质感。
- 全剧以真实人物温润肤调、低对比度、低饱和度、暖棕与奶白为主；暗部深邃但保留细节，高光克制不溢出，阴影柔和，保留自然眼神光与环境氛围光。
- 空间建立、多人关系和站位镜头使用较深景深，保证环境结构可读；人物情绪近景使用浅景深与柔和复古镜头质感，背景陈设自然虚化。景深随镜头任务变化，不在同一镜头同时要求高景深与浅景深。
- 中性平视为普通关系戏基线；只有权力、危险或脆弱关系需要被观众明确感受时，才使用有动机的俯仰过肩镜头。
- 情绪甜度来自视线、停顿、手部、距离和具体照顾行为，不依赖持续慢镜头或重复侧面近景。
- 禁止额外叠加字幕、标题、水印与未经要求的背景音乐；保留指定英文现场对白、动作声和自然环境声。剧情必要的手机消息与文件短句必须允许，可直接写明英文内容并由Seedance生成，不默认依赖后期贴图。正文写清载体、朝向与可读时间，不凭空增加与剧情无关的文字。
