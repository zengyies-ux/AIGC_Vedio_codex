# EP18 v1反馈与v2修订

## 证据与实际状态

- 片段01 v1和片段02 v1已生成；片段03尚未生成，只调整预备提示词。
- 用户认可01放枪动作；指出端碟帮忙不自然、碟子推向镜头、厨房站位略漂移、校园发型改变。
- 用户指出02独立生成造成Evelyn站位多变、前世落座者误成配角、结尾男主露齿大笑偏离性格。
- 聊天截图直接支持笑幅过大；其余按用户文字反馈记录，没有主动打开视频或其他本地图片。v1原稿保留，v2尚未生成验证。

## 预期与原因假设

- 预期是克制日常甜感、稳定厨房站位和清楚的前后世身份对比。
- 递碟缺少即时需求，同时增加取物、走近、递放和放手，使帮忙变成独立表演任务；镜头方向也没有限制清楚。
- 01“岛台短端”和02独立重建的组合没有锁住人物相对侧别，可能增加站位漂移。这是本次设计需修正的部分，不全部归因于模型。
- 三张当前人物图同时含有面孔与发型，校园场景也可能诱发新的造型；需要一个身份/发型主参考，其余只管服装和武器状态。
- 配角合照提供多张脸，前世落座又从配角肩后开始，主角身份没有先被独立确认；这是身份竞争的一种可能来源，不能断言模型内部原因。
- “笑出来”“笑意展开”鼓励持续放大，“不夸张露齿”也没有明确要求闭唇。

## 最小修正与接力调整

- 01保持23秒10镜，镜头06/07脱外套与放枪逐字保留。统一发型锚点，厨房先建立双人位置，再以松开的袖口作为帮忙起因，由Evelyn就近折齐，不拿碟。
- 02改成延长01修正版20秒，10镜；前世依次拍主角面部、同一人落座、侧席反应、主位目光。返回厨房先恢复源片双人关系。
- 成熟Adrian为02图片1；主角有3个独立镜头，侧席人物仅1个反应镜头。02撤掉五人配角合照，降低面孔竞争，不以虚构数值权重替代实际主体归属。
- 男主改为温柔目光、放松眉心与极轻闭唇浅笑，笑幅不继续扩大。
- 03保留16秒延长结构，删除重复理袖和餐碟动作，改为她先轻碰指尖、他读懂后回应轻握、她安心靠近。
- 生成顺序是01 v2合格 -> 延长得到02 v2合格 -> 延长得到03 v2，不使用旧版问题成片作为源。
