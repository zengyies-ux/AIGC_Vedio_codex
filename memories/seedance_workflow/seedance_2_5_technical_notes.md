# Seedance 2.5 技术摘要与当前制作方式

核对日期：2026-09-07。本文件是根据官方资料整理的工作摘要，不是官方原文或公司平台操作手册。产品介绍、用户确认和待验证方法分开使用。

## 1. 当前工作基线（用户确认）

- 当前主要使用公司部署平台的Seedance 2.5，保持全能参考与视频延长的制作方式；不为匹配公开产品入口另改工作流。
- 全能参考用于本次人物、场景、道具及必要状态绑定；独立生成与视频延长依开场的具体空间、站位和身体接触连续性决定，执行规则见 `execution_rules.md`。用户2026-09-08确认当前不上传首尾帧或成片截图作生成参考，截图仅内部审片；这是制作选择，不是对官方能力的修订。
- 当前生产规则是一条未经过延长的合格源片只向后延长一次，延长产物不再继续延长。官方资料中的“两次／多轮”只说明产品公开能力，不是本项目当前允许次数；若用户以后明确改变生产策略，再以最新决定更新核心规则。
- 不默认增加白模、绿幕、预演动画或额外技巧试拍版。直接交付综合判断后的正式提示词，成片不理想再按用户反馈修正。
- 白模与绿幕只作为已知可选能力；不要求用户为日常镜头制作此类资产。

## 2. 官方公开能力（不等于当次平台全部开放）

| 能力 | 官方信息 | 对当前工作的意义 |
|---|---|---|
| 单次时长 | 最高30秒 [1] | 不再沿用2.0资料的15秒限制；分段仍先看剧情、对白窗口及动作完整性 |
| 视频延长 | 产品页写两次延长；发布文章概括为多轮延长 [1][2] | 保留延长工作流，但不推断无限延长；到具体限制时再核对平台 |
| 多模态参考 | 发布文章列出最多30张图片、10段视频、10段音频 [2] | 是公开能力上限，不是每次素材配额，也不推断所有上限能同时叠加 |
| 参考理解 | 加强参考视频意图与镜头语言理解 [1] | 可学习原素材中的表演与运镜；仍需明确每份素材负责什么 |
| 定向编辑 | 支持按时间段控制或编辑内容 [2] | 了解能力即可，不自动取代当前重生成或延长方式 |

以上均为产品宣称，不保证每次输出达到同等稳定性。复杂物理、多主体交互仍需成片验证。未核实的格式、大小、分辨率、帧率、接口和平台限制不补写；“电影级”“8K细节”等风格文字不等于原生输出规格。

## 3. 我们已使用的控制方式

此节依据用户反馈与现行项目规则，不是官方规格。

- 人物、场景、道具用简名绑定参考，具体职责写进同名状态段；视频只承担指定的站位、接触、动作或视觉参考，不能提供剧情记忆。
- 时间放在空间状态开头。夜间必须统一窗外、门后、玻璃反射及室内光源，场景图的下午不能覆盖剧情的黑夜。
- 站位检查在内部完成：人物位置 → 视线目标 → 摄影机侧 → 接触与持物 → 结束状态。只把易出错、影响当前画面的关系写入正文。
- 旁白意义、节奏与现场对白窗口内部对齐；正文只写需要生成的画面、现场对白、其他声音及剧情文字。
- 默认快节奏真实切镜，运镜不冒充新增镜头。更强参考能力不代表可以省略动作因果，或把十个静态展示镜头当成情绪推进。

## 4. 镜头语言的学习边界

镜头方法见 `director_patterns.md` 第20节。影视教材和其他模型的官方示例用于启发，不作为Seedance 2.5执行成功的证据。

按当前剧本的发现、压力、情绪、反差或动作冲击综合选择镜头，不把发糖、打斗或黑手党题材锁定为一套运镜公式。十几个快切镜头中可以自然安排一处有趣的运镜或转场，但不是每段配额，不另出技巧测试版本。
