# Seedance 模型行为与版本边界

> 本文件保存项目观察、版本比较与原因边界；官方公开能力另见[技术摘要](seedance_2_5_technical_notes.md#public-capabilities)，当次公司平台和用户制作决定见[当前基线](seedance_2_5_technical_notes.md#current-production)。没有重新验证的观察不升级为机制或效果保证。

## 1. 正确的心智模型

```text
本次提示词 + 本次上传素材 + 当前模型能力 → 本次视频
```

把一次生成视为一次新对话是协作心智模型，不是官方内部实现说明。它不会自动获得上条提示词、完整剧本/人物小传、旧站位/道具、Codex导演计划或下一段剧情。连续制作由当前项目状态、实际合格源片与下一条自包含文本建立；具体做法只在[执行规则第1节](execution_rules.md#self-contained)维护。

## 2. 将设计交给模型时要写清什么

以下是信息组织顺序，**不是官方注意力权重**：身份及真实参考→人物/摄影机空间→触发、行动、可见变化、直接回应、结果→现场对白对象与窗口→选定拍法起止→光源/环境反馈→材质画质。先按[导演流程](director_os.md)选拍法，再按[模板](prompt_template.md#information-ownership)归位；顺序不能作为删情绪或记忆点的理由。

已有文本问题是状态段完整讲情绪弧、逐镜重复、声音/摄影再加否定清单；前面“抬臂/逼近/挥手”后补“不要攻击”仍可能产生动作冲突。去重与正向替换能消除自身歧义，但不能证明模型的注意力机制，也不能保证随机偏差消失。具体返修见[接续规则](continuity_and_review.md#review-and-repair)。

## 3. 编号镜头与状态重建观察

现有项目中“镜头01、02”通常被执行为剪辑边界，跨镜也出现姿势、道具、方向或环境重建。走路、摘戒指、破云或挡位被错误编号切开时，可能卡顿/重启；“每镜一个任务”不能等同每个动作阶段切一镜。此为成片观察，完整切点规则只在[执行规则](execution_rules.md#shots)维护，匿名案例见[field_lessons.md](field_lessons.md)第2节。

## 4. 执行容量不等于观看容量

历史Fast案例：15秒11个明确编号镜头完整执行、无明显穿帮，但反应与重要信息停留不足，平均约1.36秒；另一类20秒以上少切镜成片虽正确仍慢。来源为[匿名复盘](field_lessons.md)第3、22节。

这证明生成成功、可读性和情绪时间要分开判断，不证明长期应少镜或“越快越好”。海外旁白密度与动态情绪例外由[执行规则](execution_rules.md#shots)维护；真人大量对白规则仍[待建设](live_action_dialogue_drama.md)，不能从这些案例推固定上限。

## 5. 参考素材影响观察

| 已见现象 | 证据/边界 | 执行位置 |
|---|---|---|
| 场景参考下午光覆盖剧情夜晚 | 既有项目反馈；前置时段只是控制方法，不保证执行 | [空间与光照](execution_rules.md#space) |
| 多场景图/身份/道具竞争，所需区域未进入成片 | 项目观察，不能认定固定权重公式 | [素材职责](execution_rules.md#references) |
| 反向场景图透视/左右竞争 | 车辆案例仍为原因假设，未证明单张图/编号致因 | [车辆与双视角](execution_rules.md#space)；匿名复盘第28节 |
| 低清/塑料材质/正面对称生物影响高潮 | 匿名复盘第6节；质感词不能保证洗去参考影响 | 执行规则第3节 |
| 同一角色局部与全身身体不连接，复制人物 | 匿名复盘第12节，需看实际构图 | 执行规则第3节 |

当前截图只内审是用户决定，不能由此声称模型必然因截图发糊；完整范围在[接续规则](continuity_and_review.md#generation-choice)。

## 6. Seedance 2.0 Fast（历史经验）

既有项目观察到：清楚编号单任务多镜、焦点转移、天气/风场、简单关系、英文旁白、直线单方向动作可执行。历史低成本文戏/补镜曾用于结构验证，但**当前不默认Fast测试**，旧旁白生成法也已停用。

曾反复出现多阶段惯性/因果较弱，多方向调度、群体、车辆、高风险物理混乱；左右手、精细道具方向/数字随机；幻想巨物/强特效/复杂真人动作易塑料或生硬，跨镜状态易重置。匿名依据见[复盘](field_lessons.md)第2—8、13节。

同一局部反复失败先查具体歧义与动作容量，减少无关细节或选择更适合版本，不无限加字、不重写已成立全段。

## 7. Seedance 2.5（项目比较）

既有项目相对Fast观察到皮肤/服装/晨光/室内材质、较长关系戏/多次视线、保护动作/相对位置/因果及明确专业镜头指令有改善；来源为匿名复盘第4、7、18节和本文件既有版本比较记录，不是官方成功率测量。

约2—4秒、焦点明确换手的硬切链曾有更好执行空间；不因此改当前旁白“普通镜原则上不超3秒”。视线回避、呼吸停顿、手指/接触力度递进曾被执行，但抽象“紧张/羞涩/逐渐加深”不会稳定补成表演。旧记录提过脸颊升温，后续着色反馈使当前默认避免用脸部颜色写情绪，措辞见[表演规则](execution_rules.md#performance)。

2.5仍会在错切摘戒指时重置手势、沿用低质奇观材质；错误空间、过密不可读镜头或错反应时点不自动修好，左右手、精确文字与复杂物理仍可失败。当前正式制作默认2.5，全段都可直接使用，选择来源为[用户基线](seedance_2_5_technical_notes.md#current-production)，不只留高潮。

## 8. 高风险区域的证据边界

| 风险 | 已见/未证实边界 | 方法唯一入口 |
|---|---|---|
| 左右手 | 即使指明无名指也可能混淆，不保证加描述稳定 | 执行规则第6、11节 |
| 精确文字/数字 | 英文短词/姓名/日期有成功；中文、小数、长讯、透视屏幕更不稳，但不禁止剧情文字 | 执行规则第11节 |
| 复杂因果 | 线索/干预/接触/惯性可因过载或错切失败 | 执行规则第6节 |
| 人群 | 多人同步动作和复杂路线可能混乱，不能因容量有限冻结关系人 | 执行规则第7、12节 |
| 车辆/镜面 | 坐标体系与反向参考较复杂，缺车外驾驶门时可能坐错/开错；成因仍假设 | [空间规则](execution_rules.md#space) |
| 光影/质感 | 泛化“高清/电影感”不足以核对光源，非成像规格 | [摄影](execution_rules.md#cinematography) |

不把风险自动变成禁止项、删表演或要求后期。按当前问题查对应方法。

## 9. 如何判断问题来自哪里

| 现象 | 先查 |
|---|---|
| 人物走错/复制/消失 | 绑定、指代、站位、同框容量 |
| 动作卡顿/重启 | 连续动作是否错切、阶段是否接住 |
| 行为莫名 | 触发、目的、知情顺序、反应时间 |
| 虚假/塑料 | 素材质感/视角/光线与版本 |
| 正确但不好看 | 关系变化、可见表演、直接回应、高点落点、镜数与意义同步 |
| 越改越乱 | 保留错误路径再加否定、状态与逐镜重复、引入未上传/未来对象 |
| 坐错前后排/开错门 | 车辆坐标、反向图竞争、车门素材缺口 |
| 同词Fast差/2.5好 | 候选版本边界，不能单因归结字数 |

保留成功剧情/资产/表演，只改相关变量。平时直接正式设计，不默认A/B或技巧试拍；需要对照时依[接续规则第11节](continuity_and_review.md#controlled-comparison)。

## 10. 后期是备选

需要绝对精度或生成失败时，可讨论精确倒计时、复杂界面/标题、细致卡点/声音、已有动作倒放/时间回流、单屏文字替换或小范围修补；当前全无BGM仍按[声音规则](execution_rules.md#sound-and-time)。

Seedance默认承担指定表演、空间、动作、镜头、现场声与剧情文字。用户一般不贴屏幕/文件，后期不能成为镜头完成前提；仅必要时确认替代，不为一处文字错自动重做优秀表演。

## 11. 流程不能代替成片验证

文本与参考是生成条件，不能视为固定坐标、关节控制或逐帧动画指令。“稿件写明但成片偏离”已存在；形式通过不证明理解、资产或输出通过。

1. **设计/核验遗漏**：没看实际末态、左右不明、过肩对象错、动作时间不足，先修设计，不能归随机性免责。
2. **参考/约束冲突**：构图、结构、时段、衣装争同一状态，核对实际上传职责。
3. **执行偏差**：设计与素材核对后仍漏镜、遮挡后手位回退或切镜换位，记实际观察；无对照不能断言内部原因，也不承诺一句话稳定修复。
4. **文件/呈现差异**：分辨率、压缩、播放显示对清晰度影响与动作/空间错误分开。

反复同错误再查负担与歧义，同条件波动可记观察。记录来源、验证与成熟度按[复盘规则](continuity_and_review.md#review-and-repair)；没有可定位证据的既有比较保持观察。最终采用依真实画面、声音与接缝，未知保持未知。
