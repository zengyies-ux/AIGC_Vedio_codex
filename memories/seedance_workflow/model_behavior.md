# Seedance 模型行为与版本边界

> 本文件记录真实项目中反复出现的执行规律。产品规格会变化；数量、时长和上传限制以当次界面为准。

当前默认Seedance 2.5，公司平台主要使用全能参考与视频延长。官方能力摘要见`seedance_2_5_technical_notes.md`；下方Fast经验用于历史诊断，不要求每次先用Fast测试。

## 1. 正确的心智模型

一次 Seedance 生成可以理解为一次全新的对话：

```text
本次提示词 + 本次上传素材 + 当前模型能力
  → 本次视频
```

模型不会自动拥有：

- 上一条提示词。
- 完整剧本和人物小传。
- 已经生成过的角色站位与道具状态。
- Codex内部的导演计划。
- 下一段会发生什么。

因此，每条执行提示词必须自包含。所谓“连续制作”是 Codex 通过项目状态、实际合格源视频和下一条自包含提示词重新建立连续性，不是模型记住了前文。

## 2. 将设计交给模型时要写清什么

以下是提示词信息组织的协作顺序，不是官方模型注意力权重，也不是效果保证。剧本理解与拍法选择先按 `director_os.md` 完成：

1. 当前主体是谁，以及对应哪张参考图。
2. 人物和摄影机在空间中的位置。
3. 对谁行动、动作起点、触发与因果、人物可见情绪变化、对方回应和结束状态。
4. 本次现场对白的对象、声音与反应窗口；后期旁白节奏由Codex内部对齐，不写入正文。
5. 选定的镜头切点、运镜或转场的触发、起止构图与可读结果，不能只交给模型技巧名称。
6. 光源、方向、明暗关系和环境反馈。
7. 材质、风格与画质修饰。

提示词很长但前四项含糊时，方向、身份、动作和声音仍可能出错。把这些写清有助于减少歧义；人物情绪与镜头记忆点也须落到具体画面，不能因顺序在后就删掉，也不能据此承诺稳定执行。

### 指令不是越多越稳

真实项目中出现过一种明确的文本问题：状态段先写完整人物弧，逐镜再次写动作，声音和摄影段又追加同义禁止项。重复会提高相关概念的显著度，也会让多个栏目竞争同一动作解释；后面的“不要攻击”未必能抵消前面已经给出的“抬臂、逼近、挥手”动作路径。

- 内部可以完整推演人物目的、情绪弧、备选拍法和失败风险；Seedance正文只保留最终选中的可见执行结果。
- 状态段写跨镜事实，逐镜写当下表演。一个事实原则上只出现一次。
- 修bug时先删除产生偏差的动作词，再在失败镜头用正向目标动作替换；不在旧稿上层层追加否定。
- 未上传、未安排、当前剧情也不需要的角色和物件直接省略，不列“没有手机、不要酒杯、不能出现某人”等缺席清单。
- “角色想动手但忍住”这类潜在冲动，只写观众实际看到的敌意、呼吸、声音或距离变化，不把未发生的攻击动作先描述出来。

这些是当前项目的文本组织经验，不是Seedance官方注意力机制说明。成片仍有随机性，但先消除提示词自身的正负竞争，才能判断剩余偏差是否来自模型。

## 3. 编号镜头就是切点

Seedance通常会把“镜头01、镜头02”理解为真实剪辑边界。它能据此执行大量独立镜头，但每次切镜也可能重新建立人物姿势、道具位置、运动方向和环境状态。

- 时空、视角、信息焦点或情绪落点真正变化时，编号切镜有帮助。
- 同一人持续走路、摘戒指、破云、挡到另一人身前等连续动作，被拆成多个编号后容易卡顿或动作重启。
- “每镜一个任务”不等于“每个动作阶段都切一镜”。一个镜头可以完整完成一条单一动作链。

## 4. 执行容量不等于观看容量

实测中，Fast可以完整生成十五秒内十一个明确编号的镜头，且没有明显穿帮；成片仍然因为反应不足、信息无法停留而显得过快。

这不意味着镜头数量应当长期保守。十五秒十一镜平均约1.36秒，明显快于当前海外旁白短剧约3秒一镜的默认基线；它证明的是“存在过密上限”，不是“镜头越少越稳”。另一类真实反馈是：成片没有穿帮、人物也正确，但二十秒以上真实切镜不足，观众仍会觉得节奏慢、镜头普通。

当前按内容模式区分：

- 海外9:16旁白短剧：每个编号镜头原则上不超过3秒，按时长满足真实硬切密度，同时保护连续动作。
- 真人大量对白剧：暂不套用旁白短剧的3秒规则，等待真实项目后单独建设。

判断节奏时分别问：

- 模型能不能生成？
- 观众能不能看清？
- 观众有没有时间产生情绪？

快节奏需要两件事同时成立：镜头密度足够更新注意力，切点又准确承接信息与动作。镜头数量不能独自制造节奏，也不能完全脱离时长不设下限。

## 5. 参考素材如何影响结果

参考图不仅提供身份，也会把构图、材质、光线、视角和风格带入视频。

实际成片曾沿用参考图的下午光照，覆盖剧情夜晚。控制时将“时间”前置到空间状态，分别写明窗外、室内主光与反射；场景图只继承固定结构和陈设，不默认继承与剧情冲突的时段。此举是执行约束，不保证模型一定正确，成片仍需复核。

- 每张参考只承担一种主要职责。
- 场景图负责固定空间；源视频负责实际起始状态与动作轨迹；角色图负责身份；道具图负责必须稳定识别的物件。当前不上传首尾帧或成片截取的站位图，截图只用于内部核对。
- 多张场景图与角色、道具资产可能竞争注意力。必须出现的场景区域要获得独立镜头或更明确的职责。
- 相反观察方向的场景图尤其容易竞争透视和左右关系。必须逐张绑定到具体摄影方向与镜头，不能笼统要求它们共同定义整个空间。
- 低清、塑料材质、正面对称的生物图，会把这种先验带进高潮镜头；再多“真实、电影感”也难完全洗掉。
- 同一角色的局部与全身同时出现但身体不连接时，模型可能复制人物。

## 6. Seedance 2.0 Fast

已验证优势：

- 能执行清楚编号、单一任务的多镜头结构。
- 对焦点转移、天气变化、风场、简单关系戏和英文旁白有不错表现。
- 清楚的空间站位、直线路径和单方向动作可以稳定完成。
- 成本适合结构测试、低风险文戏和补镜。

常见上限：

- 多阶段复杂动作的自然惯性和因果理解较弱。
- 多个运动方向、多人调度、车辆轨迹和高风险物理动作容易混乱。
- 左右手、精确道具方向和细小数字具有随机性。
- 巨型幻想生物、强特效和复杂真人动作更容易出现塑料感或生硬感。
- 跨镜动作状态容易重置，即使文字写得很细也不一定改善。

当 Fast 反复无法理解同一个局部细节时，先定位造成歧义的具体描述，删去不必要细节、缩短局部因果链或换成更稳版本，不继续无限加字，也不因此重写整段。

## 7. Seedance 2.5

真实项目观察显示，2.5在以下方面明显更强：

- 真人皮肤、服装、晨光和室内材质的真实感。
- 较长连续关系戏和多次视线变化。
- 复杂保护动作、人物相对位置和动作因果。
- 对更专业、明确的镜头指令的遵循。
- 对约2至4秒一镜、人物和观看焦点明确换手的高密度硬切镜头链有更好的执行空间；这是模型能力观察，不改变当前海外旁白短剧“单镜原则上不超过3秒”的导演规则。
- 对视线回避、呼吸停顿、手指收紧、脸颊升温、接触力度变化等细微表演的执行；但这些反应必须被明确写出，模型不会稳定地从“紧张、羞涩、吻逐渐加深”等抽象词自动补全。

但2.5不是错误设计的修复器：

- 连续摘戒指被切成两个镜头时，2.5也会重置手势。
- 低质巨型生物参考仍会生成虚假材质。
- 不合理空间、过密镜头和错误反应时点不会自动变好。
- 左右手、精确文字和复杂物理仍可能失败。

2.5是当前正式制作的默认版本，不只留给高潮段。简单段落也可直接制作，不默认通过Fast验证结构。

## 8. 高风险区域

### 手部与左右

即使明确写“左手无名指”，模型仍可能混淆。重要时同时写人体左右和画面左右，说明掌心方向、另一只手从哪里进入；先优化接触机位和动作容量，缺必要道具参考则请用户补齐，不默认制作动作首帧。

### 精确文字与数字

英文短词、日期或姓名有机会正确生成，中文、精确小数、长消息和透视屏幕更不稳定。这是执行风险，不是禁止使用文字：剧情必要的手机消息与文件短句可明确写出内容，默认由Seedance直接生成。用可读机位、字号与足够停留时间降低风险；成片仍需检查。若失败，再讨论局部重抽、专项参考或后期，不默认要求用户贴图，也不因一处文字错重做整条优秀表演。

### 复杂因果动作

先保证存在角色能够察觉的触发线索，再设计发现、干预、接触与后果。看到对方伸手就试图阻止可以先于最终落地；没看到的人可到听见撞击才反应，不让全体预知结果或统一晚半拍。若需要连续惯性，用侧面或三分之四角度一镜观察；若同镜容量过高，则在稳定的因果节点切开。

### 人群

“热闹”不能只写很多人，“自然”也不能只删到空场。用已提供的角色、活动类型与前中后景分布定义密度；安排谁先察觉、谁尝试干预、谁听声才回头。非说话者也有目的与回应，但不让所有人同时承担复杂动作，执行容量有限时分配先后，不直接冻结所有配角。

### 车辆与镜面

车辆同时包含车辆坐标、摄影机坐标、车门和镜面反射，是高风险空间。先按车辆前进方向锁定驾驶位、前排乘客位与后排座位，再为每张相反视角场景图分配具体镜头。只有车内图而没有车辆外观或驾驶侧车门参考时，模型可能选错上车门并重新分配座位；此时从人物已经坐稳开始更可靠。后视镜只能辅助表情，不能代替座位关系建立。

### 光影与质感

只写“电影感、高清、真实”不足以稳定质感。必须给光源、方向、落点、明暗关系和材质反应，例如右侧窗光、脸部眼神光、窗框投影、湿地反射或逆光轮廓。

## 9. 如何判断问题来自哪里

| 现象 | 优先检查 |
|---|---|
| 人物走错、重复、消失 | 参考绑定、站位、指代与同框容量 |
| 动作卡顿或重启 | 是否把连续动作切成多个编号 |
| 行为莫名其妙 | 触发点、人物知情顺序和反应时点 |
| 画面虚假或塑料 | 参考图材质、视角、光线与模型版本 |
| 生成完整但不好看 | 剧本意图是否变成可见关系变化、表演强度与反应是否入镜、高点拍法与可读落点、真实切镜密度和旁白同步 |
| 提示词越改越乱 | 是否保留旧错误动作又追加禁止项、是否在状态和逐镜重复、是否引入未上传或未来对象 |
| 车辆人物坐错前后排或开错门 | 车辆坐标、相反视角参考竞争、驾驶侧车门素材缺口 |
| 同提示词Fast差、2.5好 | 可能已接近Fast执行上限 |

出现具体失败时，尽量保留成功的剧情、素材和表演，只修正相关变量，以便判断原因。平时直接交付综合设计后的正式版本，不默认额外生成A/B或技巧试拍版；用户反馈后再迭代。

## 10. 后期是备选，不代替当前任务

以下内容在需要绝对精度或生成失败时，可以考虑后期：

- 精确倒计时、复杂手机界面和标题卡。
- 节奏卡点与细致声音设计；当前生成禁用BGM及源视频音乐延续，只保留指定对白、现场声和短促非旋律音效。
- 已有动作的倒放、时间回流和重复事件。
- 单个屏幕或文件文字替换。
- 不值得为一处小错误重生成的局部修补。

Seedance默认承担本次指定的人物表演、空间、动作、镜头、现场声与剧情文字。用户一般不做屏幕或文件贴图，不能把后期设为完成这些镜头的前提；只有必要时再与用户确认替代方法。

## 11. 完整流程不能代替成片验证

流程图描述要做的工作，文本检查只能核对已经写出的约束。两者不证明理解正确、实际素材已看清，或模型已在每个镜头兑现要求。现有项目已经出现“稿件写明但成片偏离”的情况；自然语言与参考素材是生成条件，不是固定的角色坐标、关节控制或经过校验的逐帧动画指令。

出现穿帮时分层排查，不直接归为随机性：

1. **设计与核验遗漏**：没看实际结尾、左右参照不明、过肩对象错、动作时间不够。先修自身设计，不能用模型不确定性免责。
2. **参考或约束冲突**：素材构图、背景结构、时段、衣装与正文争夺同一状态。检查实际上传内容与必要职责，减少互相矛盾的要求。
3. **执行偏差**：设计与参考核对后，仍出现镜头遗漏、遮挡后手位回退、切镜后位置变动等。记录为实际现象；未做对照不能声称已经知道内部原因，更不能承诺加一句话就稳定修好。
4. **文件与呈现差异**：所查文件的分辨率、压缩与播放显示影响清晰度判断，应与空间/动作错误分别记录。

同一条件下表现波动可记为观察，但反复相同的错误要回查可执行负担和指令歧义。文字越多并不意味着约束全部生效。清楚、可拍且有表现力的设计能减少可避免错误；最终采用仍依据真实画面、声音与接缝，未知的成片结果保持未知。
