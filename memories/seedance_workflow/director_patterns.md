# 可复用镜头任务

> 这些是观众注意力的组织方式，不是固定模板。先服从当前剧本与用户想法，再选择需要的骨架。

读完`director_os.md`并明确当前事件后再查本文件：台词密集查第3、15、22节；多人同场查第7、16、18、22节；记忆点与转场查第19—21节；整集拆3段或4段查第23节。创意可以从剧本已有动作、物件、形状与运动出发，不必先找到情绪反转才允许设计；不能为迁就技巧改写关键剧情。

## 1. 危险钩子

```text
正常状态或空间 → 威胁信号 → 人物感知 → 距离缩短 → 停在结果前或核心后果
```

- 先让观众知道威胁来自哪里，人物行动才有理由。
- 反应按知情顺序发生。
- 结尾可停在即将发生，也可在用户明确要求时完整给出后果。

## 2. 权力转移与反转

```text
旧掌控者姿态 → 被压者承受 → 关键台词或道具 → 旧掌控者反应 → 新掌控者获得最后落点
```

- 最终镜头留给真正改变局面的人。
- 台词杀伤力经常落在听者反应，而不是说话者一直说。

## 3. 长台词与旁白

```text
说前蓄势并建立发言对象 → 开口让口型和第一层态度可读 → 句中语意变化带动声音、视线或身体升级 → 直接听者即时受击 → 最相关关系人作出选择 → 句尾落在新的关系状态
```

- 声音可以跨镜继续，画面不必一直拍口型。
- 先让观众看清谁向谁发言，再在当前对白窗口内切给最受这句话影响的人；听者在真正击中自己的词意到达后开始变化，不必等整句结束，也不能提前预知。回到说话者时，他已进入下一层态度，不用同一表情重复念词。回应可以是当面反驳、想争取确认却落空、压住干预冲动或重新作出选择。
- Codex在内部按旁白意义单元安排证据、反应、欲望或伏笔，不将旁白原文或对应说明写入提示词。
- 内部检查后期旁白与现场对白窗口不冲突，正文只调度本次需生成的声音。

## 4. 道具行动、互动与揭示

```text
来源与归属 → 有目的地拿起、递出、放下或合上 → 对方接住、拒绝或受到影响 → 持物与位置落稳 → 关系后果
```

- 先确认道具与人物、空间的关系，再切纯特写。
- 道具至少推进信息、关系、情绪或行动状态，不做装饰插图；只从剧本、当前场景与已提供素材取材，不把每段递物、拿物设成道具互动配额。

## 5. 人物进入与双线汇合

```text
分别建立人物位置或入口 → 门框、脚步、视线或携带物交代来路 → 沿可达通路进入当前行动区域 → 触发对视、行动或关系变化 → 停在新的关系落点
```

- 没有空间基准的交替近景只是两张人脸。
- 不要求每次拍完整长距离走路，但不能在硬切后让人物突然刷新到别人身旁。
- 脚步进入同一构图可以承担“距离正在缩短”；相遇后的关系变化比相遇动作本身更重要。

## 6. 情绪留白

```text
触发信息 → 呼吸、眼神或手部停顿 → 对方反应 → 双人关系构图 → 安静决定或动作
```

留白不是静止。身体、距离、视线或声音仍在发生变化。

## 7. 群体信息与环境反应

```text
代表性个体反应 → 另一人补充或行动 → 核心人物接住后果 → 回到主关系
```

- 群演负责空间真实、信息扩散或事件反应。
- 用少量不同景深人物，不让所有人围成一排。
- 外围人物发言可以在已经建立的桌区、门边或人群中用单人近景拍清，视线对准真正对象。没有靠近剧情就保持原位置，不为了在前景塞入主角肩膀而把外围人物挤进主关系；单人景也要继承正确光线、视线、衣装与持物状态。
- 群体完成任务后退出焦点。

## 8. 时间、地点与空镜

```text
前一动作或声音 → 1至2秒有任务的环境镜头 → 新时间或新地点的人物
```

空镜至少承担一件事：确认时间、建立地点、保留余震、交代道具或换情绪。每次只表现一个主要变化。

已提供场景中的陈设也可以成为短促的观看入口。例如门边雕塑、吊灯、门把手、镜面或桌上物件，可在人物长对话或连续关系戏中承担关键词呼应、匹配切镜、空间提醒、动作后果或情绪转折。使用时先说明它如何连接前后镜头；若删掉后叙事、情绪与转场均不受影响，就不加入，不为视觉隐喻临时添加无参考道具。

## 9. 9:16 双人关系

推荐注意力链：

```text
局部空间或紧凑双人关系建立 → 局部动作改变状态 → 过肩/前后景表现关系 → 近景承接重音 → 纵深构图收钩
```

可使用门框、肩部、楼梯、窗、走廊和人物距离表达权力、亲密、威胁或疏离。不要把“避免中景”理解成不停换角度。

同一场先建立主双人构图，固定双方画面左右、场景锚点、互看方向和摄影机侧。两人互相说听或对视时，左侧人物近景朝画面右看，右侧人物近景朝画面左看；过肩只更换观看对象，不跨到人物连线另一侧。人物转看道具、第三人或出口时，视线可以改变，但身体位置与画外对象方位仍须成立。确需换边时，连续拍清完整走位与新落点，再用双人关系镜头重新建立主轴。新时空可以重新建立关系轴，不把某个角色永久固定在一边。

## 10. 连续奇观与巨型主体

```text
人物或环境建立尺度 → 光、声或风触发视线 → 摄影机沿同一方向找到异象 → 主体完成登场并落稳 → 切人物反应
```

- 同一主体、同一方向的“触发 → 发展 → 完成”优先连续拍。
- 巨大感来自人物、栏杆、屋顶、建筑或云层的尺度对比。
- 避免正面对称静止展示；使用三分之四方向、遮挡、惯性和环境扰动。
- 关系近景里主体可退到画外。

## 11. 多段闪回

```text
现实触发动作 → 闪回A单一地点/动作/终点 → 闪回B → 回到完全相同的现实状态
```

- 短闪回中的每个独立时间或地点应成为正式编号镜头，不作为同一镜头里的项目列表。
- 短闪回也必须清楚，约一秒只做一个动作。
- 同一现实动作包住闪回，帮助观众重新进入当前危险。
- 只有当前剧本、旁白或用户想法已经建立该过去片段，且相关人物与场景素材齐全时才采用；现实触发与回到现实后的身体、持物、接触和情绪状态必须清楚。

## 12. 高风险动作转主观体验

```text
第三人称拍清接触、脱手或撞击成立 → 在该因果节点切第一人称 → 以原有运动方向表现手部与环境的相对运动 → 稳定终点
```

- 用于坠落、失去意识、眩晕或完整身体难以稳定生成的运动。
- 主观镜头必须有清楚触发，不无故切视角。
- 切入时承接已经发生的运动，不把脱手或撞击重新做一次；无法在短镜内清楚接续时，简化动作而不是靠模糊隐藏缺失的过程。
- 价值既是降模型负担，也是让观众进入角色身体。
- 第一人称也可用于明确的信息或情绪视点切换：先由第三人称建立对象、空间与触发，再沿角色已经成立的视线、伸手或身体刺激切入主观；回到第三人称或结束主观段时，必须留下清楚的新情绪、关系或空间结果，不把第一人称当作无触发的风格插镜。

## 13. 实体遮挡转场

分清连续运镜与隐藏剪辑，不用同一个“无缝转场”混写两种关系。

```text
人物向固定门框或柱子移动 → 实体遮满镜头 → 遮挡后保持步伐和摄影机方向 → 揭示新区域
```

以上是同一人物在相邻空间持续移动的连续运镜，只算一个镜头，不用遮挡掩盖不成立的路线。实体门框、墙柱可提供清楚遮挡边界。

若跨地点或跳时，可以在实体遮满画面时明确剪辑到另一个镜头，再揭示新空间。前后段分别绑定场景、时段与人物状态，说明这是剪辑省略，不是摄影机穿墙或人物瞬移。此类隐藏剪辑计为真实切点，执行稳定性仍待成片验证。

## 14. 焦点转移

```text
一个前景对象 → 一个后景人物或结果
```

焦点转移必须改变观众知道的信息，例如从戒指到新签名、从前景人物到后景威胁。起点和终点都只有一个，避免同时要求推镜、横移和多次移焦。

## 15. 海外旁白短剧高密度镜头链

适用：9:16海外旁白短剧，单段约16至30秒，需要约每3秒更新一次观看入口。

```text
强信息或异常开场
→ 主角动作/承受
→ 对手或关系方反应
→ 局部证据、手部或空间关系
→ 新机位推进压力
→ 关键动作或台词兑现
→ 主角、对手、旁观者中的一个余震
→ 结尾钩子
```

- 最低真实镜头数按“总时长除以3后向上取整”：16秒至少6镜，20至21秒至少7镜，22至24秒至少8镜，25至26秒至少9镜，30秒至少10镜。
- 常规信息镜通常约2至3秒，原则上不超过3秒；高压段落中的发令、脚步、视线、证据、承受者反应和接触可压到约0.6至1.2秒。存在多个可分离焦点且需要爆发感时，可用连续3至5个短镜快速换手，再把约1.5至2.5秒留给完整对白或结果余波；不可打断的对白、连续接触或单人表演用较少镜头在镜内推进。表演仍在继续时，切到听者、局部证据或新的关系机位承接。
- 镜头之间默认真实硬切，可按剧情在少量位置加入明确的遮挡、甩镜或匹配切镜。一次有动机的快速摇摄若从一个人物迅速落到另一个人物，为了写清执行节拍，可以把落到新主体后的部分另列镜头号并标明“连续快速运镜、无剪辑”；它不计入最低真实切镜数。普通推近、拉远、横移、变焦、移焦和一镜到底只负责当前单镜里的变化；模糊本身不代表剪辑。
- 有效变化可以来自人物换手、正反应切换、景别变化、前后景关系、手部或道具证据、群体态度和情绪视点，不必每次都更换场景。
- 不能为了达到数量把连续行走、抓取、开门、牵引或身体接触拆成动作重启。先把动作设计到3秒内完成；确实装不下时简化动作，或在到位、接触完成等稳定节点切到反应或后果。
- 旁白按意义节拍分配画面，避免一个普通中景覆盖多句不同信息。

### 爆感检查

从下列方向选择最贴合当前剧情的一项作为主轴，不同时堆满：

- 权力：谁被围住，谁被让路，谁获得最后一个视线落点。
- 反差：公开表情与无人看见时的表情、对众人冷淡与对一人温柔。
- 证据：手、伤口、手机、戒指、门、衣料或距离突然改变关系。
- 余震：对手笑容收住、旁观者交换视线、主角终于敢抬头。
- 欲望或危险：靠近、呼吸、视线停留、出口被挡、威胁进入纵深。
- 悬念：动作完成但决定未说出口，或一句话让所有关系重新排列。

目标市场网络梗只作为可选调味。先判断是否符合人物、语境和当前时效；不确定时不用，不让梗改变关键事件或挤占主要提示词权重。

## 16. 过肩镜头的权力角度

过肩镜头先写清三件事：谁的肩膀在前景、焦点拍谁、摄影机俯拍还是仰拍。

```text
强者肩后俯拍弱者 → 弱者被压低、被审视
弱者肩后仰拍强者 → 强者体量和压迫感被放大
平视正反过肩 → 权力接近、重点回到说听与情绪
```

- 高低角度服务当前权力与情绪，不按人物身份永久固定。关系翻转后，角度可以随权力一起改变。
- 过肩只改变摄影机，不改变人物原有左右、距离、接触点和视线轴。
- 前景肩部只做关系锚点，不大面积遮挡说话者口型或听者眼睛。

## 17. 打斗与危乱感快切

```text
冲突触发与出手意图 → 关键关系人察觉或回应 → 接触与正确受力 → 施力者随动或收手 → 承受者结果 → 最相关旁观者余震 → 新的压制或关系状态
```

若剧本写的是“得到示意后立即执行”，示意、启动、快步接近与接触必须保持同一股动势：视线或命令落下后立即启动，最后一步直接转成踢、抓、拦或推，不另写“走到、站定、等待、摆姿势、重新蓄力”。“落稳”只能出现在接触造成结果之后。承受者在听见脚步、看见逼近或感到威胁时立即转头、闪避、护挡或调整重心；其反应与执行者前进同时发生，不能让执行者停下来等反应。跨镜时动作时间线继续向前，不重复第一步，也不从新镜头重新启动。

- 以明显短于3秒的镜头在进攻、承受、反击和后果之间换手，避免一个普通侧面中景覆盖整场打斗。
- 紧凑关系景负责站位与对象，动作近景负责力度，手脚或衣料特写负责触感，环境道具镜头负责扩大失控感；不同任务之间真实硬切。只有剧情必须读清较长行动路线或完整阵型时，才短暂放宽景别。
- 水杯摔碎、瓶子滚落、桌面被撞翻、窗帘或幕布被扯下，都必须由人物或物件的可见碰撞触发。没有合理碰撞就不加入。
- 快切不能破坏因果。一次抓握、推倒或坠地先完成到稳定结果，再切对手反应或环境后果；损坏物与人物落点在后续保持。
- 例如掌击高点可以依次拍清：施力者出手前已有怒意或决断；保护者通过已成立的对视、靠近或挑眉表示支持；撞击及正确偏头；关系最深的旁观者捂嘴并急看施力者；施力者甩一下发麻的手，以嫌弃或决绝收尾。该例只说明反应层次，不是所有掌击戏的固定动作模板。

## 18. 长时间亲密动作的镜头层级

适用：亲吻、拥抱、贴近或其他持续时间较长、动作本身变化有限的双人关系戏。

```text
空间与身体关系建立
→ 一方主动动作
→ 另一方即时面部反应
→ 接触局部或手部力度
→ 反打或三分之四角度确认回应
→ 呼吸、眼神或重心变化
→ 双人关系镜头完成情绪落点
```

- 镜头数量达标不等于视角丰富。连续使用相近侧面中近景，即使编号切镜也会显得单调。
- 按主动、回应、接触变化与后果组织景别和观看方向；优先从关系双人景、正反过肩、正面或三分之四近景、眼神/嘴唇/手部局部、结束后的反应中选择，不为凑方向数量重复已经读清的情绪。
- 亲吻本身可以持续，但画面焦点必须轮换到“谁主动、谁震惊、谁回应、手部力度如何改变、呼吸如何失控、结束后谁先睁眼”。
- 特写必须提供新信息，不为装饰重复嘴唇接触；反应镜头仍保持双方身体接触和摄影轴线连续。
- 一个机位只完成一种主要情绪任务，不连续安排多个几乎相同的侧面机位。

### 多人表演不是轮流特写

目的与线索 → 主要人物行动 → 直接对手及时应对 → 旁观者按所见所闻分层反应 → 新关系。按需要在同框行动、听话反应、证据和空间关系之间切换；不能只因换了人物或角度就认为信息已经推进。

明显动作与适度夸张可服务冲突和记忆点，不设“只许微表情”的统一强度。主动性来自试拦、求援、让路、争取或拒绝，不靠不停动手脚凑热闹。剧情要求震住时保留静默，静默的力量来自此前有效的行动与变化。

### 同一场景怎样持续推进

先看当前关系变化：谁提出要求 → 谁尝试影响谁 → 谁没有得到预期回应 → 谁因此改变行动。切镜沿这条变化换视点，屋子不变也能不断提供新信息。

- 要看接触归属时，拍清行动者、目标与接触点；要看一句话的伤害时，切给听者；要看公开孤立时，短暂放宽到已经成立的关系构图。景别由信息决定，不按全景、中景、特写循环。
- 无台词主角的关键变化必须落到具体镜头。可用正在讲话的声音跨镜承接其察觉、选择和及时干预，让反应融入原时长；不能只在状态段写“警觉”。
- 近处直接对手、关系最深的人、外围人群依其所见所闻先后回应；同镜有主次，反应不必同时发生，也不必每人单独一个特写。
- 回到同一人时应有新状态，例如第一次争取认同、第二次意识到被忽视、第三次改向施压；相同表情的反复回切只会增加站位依赖。
- 同场独立视点是否可并发、何时原生重建，另按`continuity_and_review.md`核查实际依赖。窄构图可以减少要生成的空间关系，不能免除画外人物位置和视线的检查；不使用成片截图投喂来补站位。

## 19. 选择规则

在已有剧情、表演和时间轴上主动寻找值得强调的变化，不等用户提醒才考虑镜头表现力：

1. **找触发、可见行为或视觉材料。** 除了谎言被戳穿、关系翻转等节点，先问人物此刻能对谁或什么做一个具体动作，再找当前物件、形状、反射、遮挡和换场边界：擦拭、转伞、经过门框等本身就可以成为镜头创意的起点。
2. **选观看效果。** 此刻要让观众突然发现、感到逼近、看到反差、体验动作触感，还是因巧妙连接两个画面而感到新鲜？记忆点可以来自人物情绪，也可以来自镜头与转场本身的趣味、节奏、空间揭示或视觉联想。必须指出具体画面，不能只写“高级、有冲击力”。
3. **比较拍法。** 在内部比较直接呈现与一种具体视觉方案。除了快速变焦、关系揭示，也考虑动作驱动的擦除、旋转遮挡、图形/动作匹配、反射揭示和声音桥。找到合适落点便写入正式稿，不用“怕穿帮”泛泛否决；若不可执行，应指出具体冲突并调整方案。普通硬切仍可选择，但不能以“默认硬切”为由略过创意构思。
4. **落实执行。** 确定触发时刻、注意力起点与终点、切出切入状态、声音承接和落稳后可读的反应。切前标记观众正在看画面哪里，切后让首个关键信息落在可追踪区域；写入已有镜头段，不新建技巧表或每镜必填栏目。

同时检查：符合人物动机与场景路线，素材已经具备，正常速度装得进当前镜长。可执行性有问题就保留想表达的效果、调整拍法；不能把所有有表现力的尝试直接退成静止中景。每段寻找情绪、信息或视觉表达的记忆点，但不等于每段必须使用特殊转场。同一项目还要对照最近2—3集，避免连续使用相同的签字特写、权限卡、门禁、甩证件或遮挡藏切来表达不同事件；保留叙事功能，换一种动作结果、构图关系、声音或视觉连接。

若镜头链只剩“走来—站定—说话—正反打”，回到人物目的，从已有道具、入口、桌椅或人物距离中设计一次有来路、有对象、有回应、有结果的简单互动或状态变化。它可以是递物，也可以是靠近、让路、停笔、拒绝或转开视线；不能为防无聊硬塞无关道具和走位。

### 长时间单一事件的画面推进

通话、亲吻、等待、阅读、工作等主事件持续跨过多个旁白意义或情绪阶段时，先保留主事件的因果和最终结果，再比较以下方式：让当前动作或关系进入新阶段；切到直接对象、局部证据或后果；插入剧本或旁白已经支持的回忆、想象或平行场面；沿真实可达路线转到新的行动区；承接用户已经明确采用的小插曲。只选真正增加信息、态度、反差、关系变化或动作结果的方案，不设换场、闪回或插曲数量配额。仅换机位继续同一表情、同一接触和同一状态，不算推进。

切出必须由台词、感知、物件、动作或环境变化触发；切回必须交代主事件是否仍在继续，以及人物位置、手机、身体接触、持物和情绪进度。回忆、通话对端、第三人、第二场景或新道具必须有剧本、用户想法或已建立世界的依据，并有真实素材支撑；缺失时先在提示词外同步素材需求，不能为了热闹临时补支线。

例如长通话可以让声音继续，画面切到持机者的有目的行动、已建立的通话对端反应或已获支持的回忆；长亲密戏可以通过主动与回应、手位/距离/呼吸变化、短暂停顿、真实换区或明确结束形成阶段。人物从卧室移动到浴室，或第三人意外撞见，都会改变空间、隐私和关系后果；只有当前剧情允许、来路与素材齐全、且不改写主线结果时才采用。

### 25秒以上片段与整集的主动检查

单段25秒及以上，以及约一分钟或更长的整集，在定稿前主动寻找至少一个具体的特殊转场或镜内视觉设计候选：放在哪里、借用什么已有动作或物件、怎样连接前后画面、观众会获得什么新感受。段内检查关注观看节奏，整集检查关注场景/时间/处境的连接与可被记住的一笔；已有一个方案同时满足两者时不重复添加。

这是创意检查点，不是“每25秒必须出现一次特效”的配额。合适就采用；没有采用时内部应能说明当前窗口、调性或具体执行条件，而不是一句“无必要”带过。整集通常只采用约2处真正有记忆点的特殊转场，明显更长时最多约3处，其余使用干净硬切；短段遇到合适机会也可用。转场可以使日常动作变有趣，不要求它必须制造反转或补充剧情事实。保持已确认对白、关键动作、人物表演及真实切镜要求；镜内效果计一镜，藏切才计新的切点。

## 20. 快节奏中的运镜与转场

按剧本意义、情绪和逻辑综合设计，不限定某种题材的固定拍法。下列为导演选择方法与候选镜头示例，不是已验证的Seedance成功模板；不保证生成遵循度或爆款效果。确定拍法后直接融入正式提示词，不默认另交技巧试拍版。

### 先选此刻需要怎样改变注意力

| 当前剧情需要 | 可选方法 | 观众应获得什么 | 关键落点 |
|---|---|---|---|
| 一句话或一个细节突然击穿认知 | 镜内快速变焦收紧 | 突然看见破绽、惊惧或笑容失守 | 先让触发成立，再收紧；落稳后看清反应 |
| 近景隐藏着重要关系或空间后果 | 快速拉宽景别，或硬切关系景 | 发现有人撑腰、无人支持或出口受阻 | 新出现的关系必须已在空间中成立 |
| 两个时刻、人物或动作存在有意义的对照 | 轮廓、姿态、视线高度或动作匹配硬切 | 把期待与现实、强硬与温柔直接放在一起比较 | 对照依赖剧情；匹配构图不强迫人物同位置 |
| 注意力被突然的声音或行动拉向另一端 | 有动机的快速摇摄；有真实剪辑时再用甩镜衔接 | 和人物一起发现新的压力来源 | 方向可解释，落稳后立即读清新主体 |
| 人物穿过边界，或剧本明确跳时换地 | 实体遮挡中的明确剪辑 | 从一个处境进入另一个处境 | 遮挡来源真实，前后时间与落点各自明确 |
| 日常动作容易显得重复，但动作本身必须保留 | 擦拭清晰区、前景揭示等镜内设计 | 让动作直接改变观众的观看体验 | 变化边界跟随动作，完成后留清楚结果 |
| 已有物件具有鲜明轮廓、纹理或旋转运动 | 物件遮挡藏切、图形或运动匹配 | 体验连接巧思、换场新鲜感或两种处境的联想 | 前后匹配位置、方向与节奏；不是物体无故变形 |
| 台词或现场声已经足够有杀伤力 | 声音跨硬切到听者，或在声音结束处切入安静反应 | 看见话语造成的后果，感到众目睽睽或无人回应 | 保持原对白窗口，不重读、不靠配乐提示情绪 |
| 前后场景可由声音自然牵引 | 下一场声音提前进入的J-cut，或上一场声音延续到新画面的L-cut | 先产生期待，或让上一场余韵压住新画面 | 声音必须来自已建立的人物或环境，不生成新对白 |
| 命令、问题或决定已经成立，中间过程没有新信息 | 因果硬切到执行、答案或后果 | 让故事逻辑直接带观众跨过冗余过程 | 结果必须由前镜真实触发，不能省掉关键接触或受力 |
| 两条已建立事件正在同时逼近同一结果 | 有节制的平行剪辑 | 增加时间压力、临近碰撞或主题对照 | 两边人物、场景与素材均已成立；交替必须持续升级，不凭空新增支线 |
| 前后画面有真实光源或明暗变化 | 相机闪光、车灯掠过、窗光熄灭后的光线切换 | 用时间、记忆或权力变化连接场景 | 光源有来路，不能用无因白闪掩盖站位错误 |
| 一个物件或局部承担前后注意力 | 前镜移焦到物件，后镜从相似物件移焦到新人物 | 让观众沿同一注意力线进入新关系 | 两端物件均已存在，移焦完成后要读清新主体 |
| 前后情绪差异本身最有冲击 | 喧闹群体直接硬切空办公室，或胜利表情硬切沉默后果 | 用反差制造余震 | 不强行添加效果，时空变化必须一眼可辨 |

快速的作用是让注意力发生突变，落稳的作用是让情绪被读到。转场只占相邻镜头已有的短促时段，不能吞掉对白口型、关键接触和反应，也不能替代真实切镜数量。无剪辑快速摇摄到新主体时，可以另列执行镜头号，但内部仍按一条连续实拍计算。不要把每个愤怒眼神都变成快速变焦；同一强调反复使用会让情绪没有层级。

### 切点前后的注意力连续

Eye Trace只解决观众切后先看哪里，不取代关系轴和物理连续性。切前先找当前最强注意力点，例如眼睛、手中证据、门口动静或运动主体；切后让新信息出现在相近画幅区域，或用视线、声音和运动清楚把注意力带到另一处。需要惊吓、失衡或突然发现时可以故意改变区域，但变化本身必须有触发。不能为了视觉位置匹配水平翻转场景、让角色跨轴、交换持物手或移动真实锚点。

连续片段中的特殊转场若依赖同一个动作、遮挡、物件形状或运动方向，优先让切出与切入位于同一次生成任务，保证动作和速度自然接住；拆成两个独立生成任务时，只设计后期可明确匹配的稳定构图，不假装模型会自动记住前一段运动。

### 镜内快速变焦

人物察觉或事件触发 → 快速变焦收紧到明确主体 → 镜头落稳读清反应或证据。

- 摄影机位置不变，用焦距变化收紧景别；若是摄影机实际靠近，就写快速推近，不混称。
- 幅度与落点决定效果：可以强化警觉、压迫、识破或克制的喜感，不自动附带夸张表情。
- 用当前镜头中的短促运动强调一次信息变化，其余时间留给可读结果；不连续多次放大缩小，也不单独列作新镜头。
- 若要揭示近景外的关系，可以反向快速变焦拉宽；先确认扩大画幅内本就存在谁、距离多少，不能让同伴或威胁随变焦凭空出现。切到更宽的固定机位也可完成同一效果。

### 匹配切镜与变焦转场

切出对象的轮廓、位置或动作 → 明确剪辑 → 切入对象在相近位置和尺度接住注意力 → 揭示新的时间或处境。

- 可由现在的道具切到过去同一物件，也可由两个相关动作连接不同场景；前后两镜都需要独立场景、时段和状态。
- 若结合快速变焦，写清前镜放大到什么、在哪切、后镜从什么构图开始及如何落稳。不只写“快速变焦转场”，也不让物体变形代替剪辑。
- 匹配只是视觉连接，不暗示不同地点物理相通；对白与现场声仍遵守原有窗口，不另加旁白校准文字。
- 构图相似只在它放大有意义的对照时使用。不能为轮廓匹配改变持物手、接触点或人物视线，也不凭空加入闪回、旧道具或新时间线。

### 同状态匹配：用相同镜头拍出时间流动

适用：多晚辅导、反复训练、长期照顾、重复工作或恢复过程。观众需要一眼看出“同一件事持续发生，人物或结果正在变化”。

普通叙事或时间蒙太奇以每个真实切镜约1.2秒或更长作为可读性起点，再按证据、人物表情和动作结果加时；不用高压冲突的极短快切节奏均匀扫过所有状态。切入后先让新变化读清，再进入下一时刻。

先明确三项，再写镜头：

1. **不变量**：机位、景别、人物画面左右、座位或锚点、主要身体姿态、动作方向和共同接触点。
2. **变化量**：练习或工作进度、可见成果、人物熟练度与关系松弛程度，以及剧情允许的光线、服装或环境状态。
3. **共同切点**：铅笔触纸、抬杯到同一高度、工具落到同一位置等动作的同一阶段；下一时刻从该动作阶段直接接住，不重新起动作。

至少让一个变化量在每次切入的第一眼可读，否则只是重复镜头。提示词不能只写“相似构图”“又一个夜晚”或“完整替换”，这些词没有规定观众凭什么感到时间经过。最后一次重复应进入结果或退出转场：可让已有物件以稳定位置和尺度占满画幅，再匹配切到新的时间状态或最终成果；切入后迅速拉开或移焦，让新时空和人物关系清楚成立。

同状态匹配锁住的是画面骨架，不是把人物冻住。每个状态内部仍要有一个清楚的进步：从不会到重算、从等待提示到独立完成、从防备到自然信任。若返修只是删除分屏、多手或拼贴，却没有重新建立上述三项，错误虽消失，时间蒙太奇仍未完成。

### 甩镜衔接

前镜由明确动作或注意力变化带动快速横摇 → 短暂运动模糊处剪辑 → 后镜以相容方向与速度接入 → 迅速落稳在新主体。

- 明确摇摄方向和新主体落点；若同一空间内直接摇到另一人物而没有剪辑，实际仍是一条连续实拍，但可以把落到新主体后的反应另列执行镜头号，并明确无剪辑。
- 适合需要能量、冲击或明显时间地点切换的具体节点，不因某种题材就必用。
- 运动模糊只承担短促连接，不能吞掉关键接触、对白口型或情绪反应。前后人物不能借模糊交换位置。

### 候选镜头对：把方法写成能拍的画面

以下时长是示范用的局部节拍，不是固定时码或额外段落。只有当前剧本、真实素材和对白窗口满足前提才采用；角色名替换为本项目语义名称，台词仍只在既有声音栏列一次。

**认知被击穿：一句话落下，笑容来不及收回。** 前提是剧本支持对手自信转为惊惧。

- 镜头A，2.4秒：平视三分之四近景，发言者始终朝正确听者完成当前对白，最后落在说完后坚定的目光。
- 硬切镜头B，2.2秒：关系轴同侧拍听者胸口以上，保留其刚才的笑意；听者理解话意的瞬间，在约0.3秒内快速变焦到面部，随笑容收住落稳，余下时间读清嘴角僵住、呼吸停顿和仍指向发言者的目光。双手保持原低位，不因拍脸增加手势。
- 切点跟随认知变化，声音按既定窗口结束；可以只留现场呼吸。若明确选用变焦音效，只给一次短促非旋律声。眼睛保持正常人眼和现场反光，不用自发光表达震怒。

**公开支持：从一张脸，揭示谁已经站在同一边。** 前提是两人的并肩关系已经由剧情和前镜建立。

- 镜头A，2.5秒：轴线同侧的主角紧近景，主角接住质疑后抬眼；快速变焦拉宽到竖屏双人中近景，露出本来就在侧后方的支持者。支持者盯住质疑者，主角肩颈稍松，两人不为构图额外移动。
- 硬切镜头B，2秒：原位拍质疑者单人近景，质疑者的视线先停在主角方向，再小幅移向支持者的实际位置，意识到局面改变。这里读反应，不再重复放大。
- 声音保持当前对白连续或原有安静窗口。记忆点来自关系突然进入画幅，无须新增人物出场声或音乐。

**同一张脸的反差：旧照片切到现在。** 前提是剧本已经允许观众比较两者，旧照片和当前角色资产均已提供，不能提前泄露待揭晓身份。

- 镜头A，2.3秒：拍持机者原手中已朝观看者展示的屏幕，照片中的人脸可读，手机高度、握法与屏幕方向已经落稳。
- 在照片人脸的眼睛高度处明确硬切镜头B，2.4秒：当前人物的三分之四面部近景以相近尺度和眼睛高度接住构图，表情从承受审视转为镇定回望，视线朝真实持机者。摄影机仍在关系轴同侧；照片没有变形成真人，手机继续在画外原持机者手中。
- 允许既有质疑声跨切继续，一句只读一次；不新增闪回对白或转场配乐。这里使用用户提供的照片素材，不能用成片截图替代。

**空间边界成为情绪切点：门关上，角色不再犹疑。** 前提是剧本本就包含已走到门外的角色关门、独处后坚定下来，门内外场景参考已具备。

- 镜头A，2.5秒：从门内靠近门框的固定位置看门外角色，角色已经站到门外，原地将门关闭；已有门板扫满画幅，在门板完全遮满、关门接触成立处明确剪辑。
- 镜头B，2.3秒：硬切门外的三分之四近景，角色仍在门外原位置、门已关闭，持物与手部动作终态一致。角色听到门内声响隔着门变闷，呼出一口气，收住犹疑，抬头望向下一去向，镜头落稳读清变化。
- 关门声只出现一次并与接触同步，声音距离随门关闭改变；没有摄影机穿墙或人物跳过门槛。若剧情还需要拍跨门槛，就在此前独立拍清到位，再接这对镜头，不把整条路线强压进关门镜头。

### 站位与视线检查

按第9节已经建立的主双人关系，内部追踪：人物锚点与画面左右 → 视线目标 → 摄影机位于关系轴哪侧 → 身体接触与持物 → 结束状态。只在正文写当前风险点，不给每镜增加整张表。需要换边时，核对连续走位是否拍清、新双人关系镜是否已经重建；转场之后再检查是谁、在哪里、什么时间、刚发生什么，能否立即读懂。

剪辑前后还要检查谁在向谁说话、接触是否已经解除、道具由谁持有。声音可以跨切，人物位置和手部状态不能因此回退。全段禁止任何BGM、配乐、背景音乐及源视频音乐延续；指定对白、现场反应、动作声与短促非旋律音效各按触发和窗口执行，不用音乐或持续转场音补情绪。

### 学习来源

- [Runway官方镜头术语示例](https://help.runwayml.com/hc/en-us/articles/47313504791059-Camera-Terms-Prompts-Examples)：参考运动起终点及可见结果的写法，不据此推断Seedance成功率。
- [Adobe：180度规则](https://www.adobe.com/uk/creativecloud/video/discover/what-is-the-180-degree-rule.html)：关系轴与空间连续性的影视依据。
- [Adobe：摇摄与甩镜](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/pan-shot.html)：运动方向、揭示与节奏的影视依据。

以上是学习与设计依据，不新增拍摄资产要求，不改变全能参考和视频延长流程。

## 21. 动作、物件与转场本身的记忆点

本节于2026-09-09根据用户的擦镜头、旋伞示例补充。下面是由影视方法转成的候选设计，尚未验证Seedance 2.5成片效果。示例不自动加入当前项目；执行时使用当次已具备的角色、场景与道具，替换时间与状态，完整对白仍只写在声音栏。

### 先分清三种画面关系

| 观看效果 | 实际执行关系 | 镜头计数 |
|---|---|---|
| 擦过的区域逐渐清楚，同一人仍在原处 | 同一镜头内，遮蔽物或脏污被动作移除 | 一镜 |
| 物件遮住画面，移开后到达另一地点 | 遮满处藏一次剪辑，前后分别是两个已定义的场景 | 两镜，观感连续 |
| 摄影机跟人穿过真实相邻区域 | 一条真实连通的路线，没有剪辑或跳时 | 一镜 |

“像一镜到底”描述观感，不强制跨地点做成真实连续运动。移焦只改变清晰焦平面；转伞是物件运动；横摇、绕物环绕、摄影机绕镜头轴旋转是不同运动，正文分别写清，不用“旋转对焦”包办一切。大胆的是视觉构思，明确的是执行关系。

### A. 擦拭把画面擦清楚

来源：用户提出的清洁动作创意；擦除/自然划像原理参见下方Adobe资料。此处局部清晰区随手势变化的具体设计是本项目改写，不冒充官方Seedance示例。

适用：剧本已有清洁动作，且擦拭载体成立。可把摄影机放在被擦玻璃另一侧；若用户选择直接擦镜头的风格化拍法，保留这个意图，不擅自改回普通清洁中景。不为这个效果默认要求新建白模或额外试拍。

候选单镜，约2.8秒：摄影机透过有薄薄污迹的玻璃看女主，女主已拿布准备擦拭。布从画面左向右贴着玻璃一次擦过；布经过的位置紧随露出清楚的脸，尚未擦过的一侧仍保留原污迹。布离开右画缘，擦净区域保留清晰，女主手自然落下，镜头停住读表情。摄影机不动，人的脸保持原位置，不用整幅画面同时由糊变清的普通移焦替代局部擦除。

控制点：谁拿布、擦什么面、屏幕移动方向、清晰区边界跟谁走、未擦区域如何保留、完成后露出什么。重点是动作与画面变化同步；不能只是加一团模糊后消失。摩擦声随动作出现，无BGM。

### B. 旋转伞面，把换场藏进去

来源：用户提出的旋伞换场创意；结合自然遮挡和运动匹配。具体两镜设计为候选，不是已验证模型能力。

适用：前后场景已经允许换地或跳时，伞及两处场景素材齐全。同场换视点也可以使用，不因“只有一个房间”自动排除。先明确伞转、摄影机动还是两者先后配合，避免同时写人物旋转、摄影机环绕、画面滚转、变焦及场景融化。

- 镜头A，约2.4秒：角色持伞，先将焦点交给伞面。角色让伞面朝镜头略倾、顺时针旋转一小段，摄影机沿已确定方向靠近，直到伞布纹理遮满整个画幅。满屏遮挡处明确隐藏剪辑；伞在遮挡前保持真实伞骨和布面，不变成传送门。
- 镜头B，约2.4秒：从另一已指定场景中同一伞布满屏开始，图案尺度、画面位置与旋转方向接住前镜。继续同向运动，摄影机退开到人物近景或伞沿抬离画幅，迅速揭示新的环境和人物状态并落稳。接伞动作与新地点状态明确，不能出现半边旧场景、半边新场景的无意融合。

如果需要的是同一地点的真连续镜头，就只绕伞或随伞移动到新视点，空间必须可达，不写藏切；仍只算一镜。跨场景的连续观感可由上述两镜实现，不把“一镜到底”的措辞变成不必要的物理负担。前后只接指定环境声、雨声或伞布声，无配乐。

### C. 更多可以主动选用的视觉连接

| 方法 | 可拍的连接 | 可带来的观看记忆 | 执行重点 |
|---|---|---|---|
| 前景自然划像 | 布料、经过的人或门板扫过画幅；其后显出另一视点或场景 | 角色动作像在主动换页 | 跟随实体边缘揭示；满遮挡藏切或移动边界划像二选一写清 |
| 图形匹配 | 两场已有物件的圆形、轮廓或相近构图接在一起 | 观众主动把两个处境联系起来 | 尺度、位置接近，切入后让新物件和场景可辨，不生成形态融化 |
| 动作匹配 | 上一场抬手、合物件或转身，接下一场方向相容的动作 | 日常动作形成节奏与跨时空呼应 | 明确是同一动作延续还是两次动作的剪辑类比；手位和结果各自成立 |
| 甩镜接运动 | 视线或动作带动横摇，模糊处接下一镜的相容横摇 | 突然把注意力甩到新的事件 | 方向、速度相容，落稳后立即清楚；不必绕人物一整圈 |
| 反射或移焦揭示 | 先见镜面中的人或前景物件，移焦/小幅移动揭示真实位置 | 观看对象或空间认识被重新解释 | 单独选择主要变化；镜像朝向与实际位置成立，不凭空复制角色 |
| 叠化与构图重复 | 同一位置或相近姿态，叠化到已授权的另一时间状态 | 时间流逝、回忆感或状态反差 | 明确时间跳跃，不用叠化掩盖同一动作的接触错误 |
| 声音先行或留声 | 下一场特有环境声先进入，或前一场最后一句留到新画面 | 先听后见、反讽或联想 | 不移动用户对白窗口；声音归属清楚，无BGM |

这些方案各有适用场合，不把所有场景都拍成圆形匹配或甩镜。镜头趣味本身可以是价值，但画面必须让观众看懂动作和转换后的结果；不需要为它硬编一个人物身份反转。

### 写入正式镜头的最小信息

使用既有镜头段写清：借用的动作/物件 → 切出构图 → 变化方向或遮挡边界 → 有无剪辑及切点 → 切入状态 → 最后看清的主体 → 声音。前后两镜属于同一次设计，先一起构思；若两镜属于连续内容并依赖同一动作、遮挡、形状或运动完成转场，优先把切出与切入放进同一次生成任务，让模型在一个上下文里完成完整转场。不要为了沿用旧分段，把转场两侧拆给两个彼此独立的原生生成任务；确需跨任务时，只把它视为后期匹配切方案，并分别锁定构图位置、尺度、方向和声音，稳定性低于同次生成。不能只设计前镜漂亮的遮挡，不知道后镜怎样接。

动作或镜内视觉效果需要2—3秒时，将这段时间真实留给它；隐藏剪辑的两侧分别计镜。不要为凑镜头数量把一次擦拭切成多次重新擦，不把转场只压成一个看不清的闪动。长段与整集的机会检查按第19节执行，仍保留原对白窗口、完整摄影和禁BGM。

### 本次联网来源与适用边界

以下于2026-09-09查阅。影视转场的原理与提示词写法可以借鉴，其他模型和剪辑软件的功能不代表Seedance 2.5已经验证支持。

- [Adobe：Wipe transition](https://www.adobe.com/creativecloud/video/post-production/transitions/wipe.html)：自然划像可借人物或场内物件完成，移动边界与方向帮助连接场景；也可带来趣味和调性变化。用于本节自然遮挡与动作揭示的原理依据。
- [Adobe：Match cuts](https://www.adobe.com/in/creativecloud/video/discover/match-cut.html)：图形、动作与声音匹配可把不同场景联系起来。用于形状、运动与声画连接，不据此要求后期必须完成全部效果。

## 22. 冲突高点与对白表演接力

本节用于解决“事件拍到了，角色仍像木头”的问题。它是导演设计与审片方法，不保证模型一次执行成功，也不要求每段套同一动作。先守住剧本事件、人物关系与物理规律，再按当前强度选择表演。

整集先分清普通推进与最重要的情绪爆发点。施害者的恶意应由针对具体对象的选择、逐步升级的行为和可见后果证明；受害者的承受，以及剧本随后确有的反抗、保护或救赎，要获得足够镜头时间。镜头技巧只强化这条变化，不能替代它，也不能提前发明救援。既有情境内的表演可直接设计；新增会改变剧情因果或后续状态的行为、剧情性道具先作为拆解候选供用户确认。

### 对白不是口型段

关键对白先写成一条表演接力：

```text
触发
→ 说话者想让哪个对象怎样
→ 台词进行中从什么态度变到什么态度
→ 直接听者在哪个意思被击中后回应
→ 最受影响的关系人怎样支持、阻止、争取、拒绝或忍住
→ 说完留下什么关系状态
```

长台词按语意变化安排2至3个表演拍，不按标点平均切。例如“先否认、再反咬、最后逼对方表态”是三层目的；视线、呼吸、语速、手势或距离只需在相应重音处完成一次清楚变化。声音跨到听者近景仍连续，不重启台词。说话者在镜头外时，听者必须对当前已经听见的意思反应，不能提前破防，也不能等整句结束后才统一动起来。

### 高情绪短剧的五拍放大

```text
压住或伪装
→ 刺激击穿
→ 声音先变、身体跟上
→ 镜头在破防点突然收紧
→ 直接对象与关系人承接余波
```

这是高情绪段的导演骨架，不是要求把五拍逐字写进提示词。反转、羞辱、危险、救援、追悔和强势质问默认做到中强至强幅度；只有人物此刻明确在掩饰、试探或强忍时，才把当前一拍压低，并在后续击穿处释放。

- **声音变化**：一句话内选择语速、音量、呼吸、停顿、咬字或重音中的两三项形成转折。例如开头压低声音求证，听见确认后停半拍，随后加快语速并咬重最后几个词。语气变化必须服务人物正在争取、逼迫、否认或挽回的对象。
- **身体变化**：让面部、手部、重心或距离至少有一项跟随刺激发生清楚变化；大动作应改变对方判断、人物距离、道具或现场状态。无对象握拳、突然耸肩、原地挥臂和无理由奔跑不算情绪。
- **镜头变化**：在真正的认知断裂点使用一次快速推近、快速变焦、快速拉远或短促跟落。高压链含多个可分离焦点时，可用3至5个约0.6至1.2秒的快切在刺激者、被击中者、行动结果和直接反应之间换手，随后用约1.5至3秒的镜头让余波落稳；若张力来自不可打断的对白、连续接触或单人表演，就用镜内语气和身体变化承载。快速镜头不是全段恒速，也不能遮掉口型、接触或表情。
- **关系余波**：说话者爆发后必须有人被改变。直接对象立即躲、挡、逼近、反驳、失语或强忍；最受影响的关系人再作出支持、阻止、拒绝或判断。群众只能放大已经发生的后果，不能替核心人物回应。

### 抒情与泪点的四拍

```text
克制或不敢相信
→ 一个具体动作、物件或词句击穿
→ 声音、呼吸、视线或身体出现变化
→ 直接对象与关系人承接，留下新的关系状态
```

家庭接纳、创伤被看见、失而复得、离别和悔恨不默认从开场一直哭。先让观众看清人物怎样维持体面或防御，再让一个具体刺激打破它。破防可以是眼中稍微出现泪花、声音短暂失稳、呼吸停住、身体终于靠近或一只手不再缩回；幅度由人物目的决定。

情绪高点可以使用约3至4秒的稍长镜头，但机位与画面关系必须继续变化：缓慢推近、轻微横移、弧线调整、移焦或人物主动靠近都可以让情绪逐步显现。刺激击穿时，也可从当前人物快速摇摄到直接对象或已建立在场者，落稳读清反应；需要回到主角时再使用真实切镜或另一条有动机的运镜。周围人的快切或快速运镜反应只用于确认事件造成的后果，不抢先替主角哭、不凭空增加陌生群众，也不让快速运动吞掉最关键的面部与声音变化。

返修时把这五拍视为一个整体。若旧版的语气、身体爆发或快速收紧已经有效，只修正错误站位、持物、路线、接触和构图；不能为消除一个穿帮，把刺激后的声音变化、对象反应和余波一起删掉。强表演可以改用更合理的动作承载，但叙事强度不能无故下降。

### 冲突高点的四拍

```text
前摇：决心、威胁征兆或关系确认
→ 爆发/接触：动作沿清楚短路径发生
→ 受力结果：身体按真实方向改变并落稳
→ 余波：行动者、承受者或关键见证者确认后果
```

四拍可以分在两至四个快速镜头中，也可把前摇与爆发放在同镜；接触与受力惯性不能被错误切断。高点后的余波不是装饰，它告诉观众这件事对关系造成了什么：发起者可能甩手、收回手或冷眼确认；承受者可能偏头、失语或试图恢复体面；利害关系人可能捂住嘴、猛然转看行动者、立刻靠近或压住出手。选最符合人物目的的反应，不要求全部出现。

### 候选镜头链：公开掌击后的关系确认

前提：剧本已经包含一方准备掌击、保护者明确站在她这一边、对手与其伴侣均在场。以下动作只是候选，不能在没有相应关系时套用。

1. **前摇，约1.5至2秒。** 行动者在出手前带着压住的怒意看向对手，再与侧后方保护者短促对视。保护者以很小的点头、挑眉或稳定回望表达“我在这里、我会护住你”，不替她批准或代替她决定；行动者下颌收紧，视线重新锁回对手，掌心开始抬起。
2. **爆发与受力，约1至1.5秒。** 稳定关系机位拍清哪只手、击中哪侧脸、接触方向和头肩受力，掌击正常速度完成。镜头技巧不能遮住手与脸的连接；撞击声与接触同步。
3. **第一余波，约1至1.5秒。** 对手的头停在受力终点，呼吸和目光恢复；行动者收回手，手腕轻甩一下或擦过掌心，用身体表达嫌弃与决绝，不回到无表情站姿。
4. **第二余波，约1至1.5秒。** 对手的伴侣先被掌声惊到，明显捂住嘴或倒吸气，立刻转看行动者；随后硬切行动者的近景，读清她没有后悔。若保护者仍重要，可留在画缘看住对手，而不是无任务发呆。

这条链的记忆点来自“出手前有人支持、出手后各方关系被改写”。实际时码不足时，先删除重复的普通近景，把对视、掌击和余波压紧；不能只保留掌击结果，或为了拍齐每个人让所有人同时捂嘴、退步、挥手。

### 单一场景的一分钟如何保持活力

长时间停留在同一房间时，变化来自关系和注意力，不靠角色不断换位。先把人物按当前事件分成行动者、直接承受者、利害关系人和外围放大者，再沿每次刺激改变观看焦点：说话者的进攻、听者的破防、盟友的选择、对手的补救、群众的气氛确认。

- 核心人物承担剧情动作，不能用群众替代他们的反应。
- 公开派对、会议、婚礼等场景需要社会压力时，使用已经建立的宾客或工作人员。把他们固定在桌区、门边或后景，按事件只选1至2个代表动作，例如笑容骤停、杯子停在半空、捂嘴、低声骚动或向后让路。
- 群众反应放在动作结果之后，不能抢占未完成接触或跨段接续窗口；功能配角完成任务后退回自己的区域，不长期挤在四位主角旁边。
- 每镜一个主表演焦点、至多一个次反应。静止可以表达震住、判断或克制，但必须有明确的视线、呼吸或身体张力让观众读懂；没有目的的静止就是罚站。

定稿前可将片段静音播放：若仍能从脸、身体、对象与切点看出谁在施压、谁被击中、谁支持谁和关系怎样改变，表演才真正落到画面；若只能依赖“愤怒、悲伤、沉稳”等提示词标签，回到表演接力重排。

## 23. 按情绪归属拆3段或4段

分段是在给生成风险分仓，不是平均分配总时长。先把整集标出不可拆的剧情单元：一句关键对白及其直接反应、一次揭露及第一轮关系变化、一次“前摇→爆发/接触→受力→余波”的动作闭环、一次明确的情绪转折。随后组合3段与4段候选，比较哪套能让每段独立验收和局部返抽。

每段生成前用一句话回答：

```text
这一段主要拍谁，因为谁的刺激，从什么情绪变成什么情绪，
直接对象与关系人怎样回应，最后停在什么稳定状态？
```

说不清通常表示一段混入了多个主情绪命题。“主要拍谁”是摄影和表演优先级，不代表只拍一个人；行动者、直接对象、关系人和群众仍服务同一个命题，按触发错峰接力。

### 优先提出4段候选的风险信号

以下风险命中两项时，优先重排4段，但仍须通过稳定边界检查：

1. 候选单段接近或超过27秒，且并非单一、清楚的情绪弧线。
2. 主情绪承载者在一段内更换两次以上，形成两个独立高潮。
3. 有三个以上说话轮次，或同一句长对白需要照顾多个不同听者和关系反应。
4. 同时存在两种复杂任务，例如抓腕加掌击、手机展示加多人争辩、身份揭示加群体爆发。
5. 四名以上剧情相关人物都必须获得可读反应，三段方案已经挤掉其中关键人物。
6. 一段既要精确继承复杂源片末态，又要大幅改变站位、持物或构图。

特别是长对白、复杂接触、主要人物破防和群众余波挤在同一张卡时，局部失败会迫使整段重抽。若可在动作开始前或结果落稳后，把其中一个高风险情绪单元独立出来，4段可能比反复重抽一个过载长段更省。

### 保持3段的反向检查

- 同一人物的情绪弧线和同一句对白正在连续升级，拆开会削弱力量。
- 新边界落在抬手到命中、抓住到释放、递出到接稳等动作中途。
- 第四段没有独立主情绪命题，只重复已经读清的表情或群众反应。
- 新段仍需继承大量未知站位或必须延长已经延长过的片段，返抽范围没有真正缩小。

找不到稳定边界时保留3段，并减少同段次要任务；不能为了凑4段破坏动作因果。找到稳定边界也不自动拆分，第四段必须能独立回答“抽坏时只需重抽哪一个情绪/动作单元”。

### 生成边界门槛

切点应落在完整现场对白或明确语意停顿之后；动作、受力、手位与道具已经落稳；关键刺激至少获得一个直接回应；下一段能明确继承实际源片或由原始资产重建。对白声音可以跨镜，生成任务边界原则上不截断一句必须由同一结果承接的现场对白。人物仍在快速移动、接触未解除或反应尚未出现时，不能把“后段会继续”当作稳定边界。

### 单场景中的群众视点

同一宴会厅连续多段或多集时，群众可以成为独立的观看入口，但必须承担“公开事件已经被整个空间看见”的后果。轮换已建立的入口区、餐桌区、蛋糕区或酒水区宾客，不长期只回切同一个功能朋友。

```text
核心刺激成立
→ 直接关系人先回应
→ 1至2位对应区域宾客用0.8至1.8秒确认公开后果
→ 返回已经改变的主关系
```

群众动作随认知升级：日常交谈或饮酒→收笑停杯→交换不安视线→捂嘴或明显后缩→害怕牵连、避开目光或让路。不能每集重置为同一种“震惊张嘴”。掌击等连续动作先拍清接触与受力，远处群众在看见结果或听见声音后再反应。

若群众镜头完全不出现主角及其肩、手、道具，不继承核心接触，只保留已确定的区域、身份、朝向和心理进度，它可以作为弱依赖原生候选独立准备；剪入位置和刺激必须预先确定，不为了“以后也许能用”抽一堆无任务素材。

## 24. 情绪、实物动作与特效都要形成闭环

情绪和特效都不能只给一个结果标签。导演先设计“从哪里开始、怎样累积、在哪一下兑现、对人物或环境造成什么、最后怎样落稳”。普通真人剧情优先用表情、身体、实物和空间完成；只有剧本本就需要超现实力量、魔法或风格化视觉时才加入特效，不为让画面热闹强行叠加粒子和光效。

### 情绪的可见递进

```text
人物察觉刺激
→ 面部与呼吸先泄露变化
→ 手指、肩颈、重心或距离开始响应
→ 一次有对象的动作或选择兑现情绪
→ 对方、道具或空间状态发生结果
→ 人物与环境逐渐落稳
```

不要求每段拍齐六步。根据时长选最有效的节点，保持刺激和结果完整。若肢体动作没有对象，也不改变任何状态，删掉；若一个盖章、甩证件、关门或移走棋子的动作就是权力结果，让接触点获得一次短促快切近景、清楚力度和同步声音，再把注意力交给被改变的人。

### 特效的最小拆解

先回答三件事：效果是什么形状和材质；它从何处、以什么过程产生；它出现后怎样影响人物与周围环境。正式设计再按以下顺序播放：

```text
载体与局部征兆出现
→ 粒子、流体或光线逐渐聚集并与人物动作绑定
→ 主动作释放，效果沿清楚方向运动
→ 冲击、震动、风压、灰尘、水滴、发丝或衣料产生对应反馈
→ 主效果衰减，残余粒子与环境运动逐渐停止
```

“粒子”和“光效”只是组成材料，不能代替形状、来源、方向、尺度和环境后果。优先使用人物与镜头能清楚读到的局部效果；大范围体积光或满屏特效只有在空间、光源与剧情确实支持时才采用。效果开始前、峰值和消退后都保留可辨的现实环境，避免凭空出现、突然消失或只贴在人物表面而不影响周围世界。
