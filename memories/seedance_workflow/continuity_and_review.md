# 连续性、动态站位与成片复盘

> 本文件维护生成方式、实际源片与跨段依赖、审片证据及精准返修。镜内素材/轴线/动作/声音的完整执行方法见[执行规则](execution_rules.md)，分段判断见[导演流程](director_os.md)。用户文字已足以定位时直接修，不默认重新读整部剧或全部视频。

<a id="task-recovery"></a>
## 当前任务的恢复范围

先用用户最新范围与项目状态区分任务，再读取相应采用材料，不把最新文件或缓存当作当前方案：

| 任务 | 继承与重新核对 |
|---|---|
| 继续制作 | 继承当前采用解读、分段、提示词及有效输入；按[声音采用规则](execution_rules.md#sound-and-time)核对音频／原文／归属版本，接续只消费合格源片实际末态。 |
| 局部返修 | 从已知可用基线保住有效部分，只修问题与受影响声音、预算和接缝；不重新审整集。 |
| 用户明确独立重测 | 从原始剧本、当前采用音轨与实际资产重做设计；可复用同音频有效词表，不继承旧未采用段首、生成窗口、加时预算及补图结论。旧方案仅作后续对照。 |

独立重测使用单独试制输出区或新版本文件名，保留旧稿及当前采用入口；未获最终采用不抢改正在制作的状态。状态分别记录前置的验证／本任务自主授权范围／已启用长期常规模式与真实依据，以及本次网页准备或生成权限。文本完成、方案认可、音频采用、实际生成和成片评价分别记录，不以文档发布自动切换工作模式。派生段首变化按[声音规则](execution_rules.md#sound-and-time)局部重校，未变音轨不重转或重复索取确认；新边界不能可靠映射时仍待解决。

项目当前制作入口只由既有状态链接指向用户选定的结果；重测清楚标候选／历史，采用后再切入口并保留原路径，不能按修改时间抢占其他聊天正在制作的稿。完整原文及目标集位置能恢复依据就复用，不每轮复制全剧逐集文件，不为每段另建写稿脚本或检查JSON。工具指纹与必要缓存继续内部保留；摄影原文和稳定设定各有单一出处，使用处引用，正式正文仍自包含。

<a id="source-state"></a>
## 1. 八类实际状态

| 状态 | 追踪内容 |
|---|---|
| 空间与轴线 | 具体功能区、锚点、入口、威胁来源、屏幕顺序、视线、运动方向与摄影机侧 |
| 角色 | 服装、伤势、姿态、已知/误信、情绪阶段、发声与对象 |
| 画外人物 | 方位、距离、视线参照、景别内是否可见或已开始的路线 |
| 身体与主观视角 | 正从谁身体看、手/衣袖/饰物及左右 |
| 道具 | 来源、持有人、手位、朝向、数量、位置与损坏 |
| 动作 | 起点、触发、接触、受力、结果与落稳状态 |
| 世界条件 | 时间、天气、光源、风、环境声与行动区域 |
| 竖屏层次 | 前景遮挡、中景主体、后景目标、高低与安全区 |

每个连续新镜从上一镜实际终态开始；已拨开的手、已松握、已落下道具或已开门不无因恢复。人物出画不等于离场，画外位置与已开始移动仍有效，不能为反打换位。

逐接缝把“上一镜最后一句＋下一镜第一句”成对连读：能直接承接位置/姿态/持物/阶段/视线/机位，或剧本允许明确换场/跳时且首帧可读新时空和稳定关系；二者都不成立即瞬移。校门→走廊→教室不必拍完全部路程，但入口、途中锚点、门槛、到位中承担身份或关系的必要节点须保留。

已按[生成方式](#generation-choice)确定需要真实源的同集接续或用户明确要求的跨集连续任务，以**合格源片实际末态**为准；跨集默认独立原生不因此索要前集结尾。先核当前反馈与采用记录，已足够则直接使用，不以计划终态代填。已获延长准备或完整生成授权时，GPT负责必要的局部核源：查看已提供本地视频或正常网页可见结果的相关终点、人物阶段／身体状态、空间、持物和接触，复用已有可靠核查，不默认把责任退给用户。读取量按[审片边界](#review-and-repair)，不重跑音频或整集解读。记录实际源片、生成方式、选用终点及已知关键末态，未核项保持未知；无法定位采用源或关键矛盾内部无法解决时只问该条。

上游采用稿或真实源改变后，沿相关人物、道具与动作阶段查全部受影响下游镜头，不只开场一句“沿源”。原双手持纸，下游须仍双手或拍清松开一手才有空手；扶持／站坐／高度／朝向同理。未知不猜，能据当前文字先修矛盾就修；不因此整集重写或削弱有效情绪。

本集后段独立原生已有可用结果时，在前段定稿／提交之前核其必要首态，与前段已知开场一起校准相关接缝，不等前段付费生成后才发现姿态冲突；下游未生成则不为此新造等待。只缺影响接缝的关键左右／朝向时问该项，不扩大为全片审查或必交状态表，不擅自重做已有合格后段。一个已获用户认可的接缝先交代女主入座与男主相邻位置，末镜落女主等答近脸，再硬切男主回答关系镜；动作与视线接力使构图变化自然。此为历史用户认可，不证明所有同场关系都可无依赖重建，也不改变跨集默认独立。

局部抽帧与媒体元数据核查优先复用项目已验证的Python环境及decoder；现有工具可通过`imageio_ffmpeg.get_ffmpeg_exe()`定位解码器，不在已知有环境时先盲调系统`ffmpeg`／裸Python或重复安装。不同平台按已验工具入口执行，环境确实失效才重新发现；临时帧仅供内审。

## 2. 场景图与空间基线

首次复杂空间内部辨认固定结构、入口/出口、行动区、人物锚点/视线、主轴/摄影机侧与光源，再核对实际源片有没有偏离。只把当前所需事实写进正文，不另建长期导演卡。

素材本身不支持必需路线时，在解读／规划中列清补图用途与必要结构，或调整拍法；受影响正式稿等补齐核看，不阻塞无关工作，权限见[导演边界](director_os.md#creative-boundaries)。单人紧特写可仅继承正确视线、光线与背景色，不每镜塞门柱或肩沿迫使远处人物挤近。场景双视角、用户俯视站位图及多人风险闸门完整维护在[执行规则：空间](execution_rules.md#space)。

<a id="generation-choice"></a>
## 3. 接住开场，允许行动改变站位

### 生成方式与当前用户制作约束

**不同集默认独立原生。** 使用对应角色身份、当前剧情阶段、场景与必要道具资产建立本集开场，保持剧本事件和人物关系，不要求复刻前集实拍的机位、姿态、接触或非剧情锁定的持物；前集成片、实际末态与区域累计不是本集开工条件。只有用户明确要求跨集连续动作或跨集延长，才建立相应真实源依赖。已有跨集待源计划按最新默认解除，不自动返工已完成成片。

下表用于同集各片段，或用户明确要求跨集连续的任务。比较前段结尾与本段开场的具体空间、距离、朝向、持物、接触和表演阶段；同一地点本身不制造依赖：

| 实际关系 | 默认方式 |
|---|---|
| 不同大地点、明确跳时或需重建状态 | 原始资产独立生成；可硬切/有任务空境，无素材依赖可并发 |
| 同一具体空间、简单关系可可靠重建 | 原始人物/场景/道具独立生成 |
| 同一具体空间，站位、接触或连续表演复杂 | 同集内平台支持且前段合格后优先一次延长；跨集只在用户明确要求连续时适用 |
| 连续时间转入相邻区域 | 拍清起步、移动与新到位，再按实际末态选择延长或独立 |
| 开场同场而片段中途换场 | 可延长开场关系，再硬切到独立场景/已建立回忆 |

平台延长允许真实硬切和换机位，不等于全段一镜到底。视频参考与平台视频延长是两种操作，顶部制作设置分别记计划与实际操作，正文只说明源视频承担的状态；视频不提供剧情记忆。源片的人物、阶段／身体状态、衣装或时段有错，不作为正确状态继承：定位受影响接缝，先找已有合格源或提出最小局部修复／重建方案，不能只改下段文字就称解决。保住无关导演与声音，修复操作仍依本任务授权，不擅自重做用户成片。

以下是**当前用户制作决定/公司平台工作约束**，不是官方模型物理上限：

- **一条源片只向后延长一次。** 延长结果不能再当下一条延长源；候选源必须未经过延长且合格。把唯一延长留给最依赖真实接触/移动/连续表演的接缝，后续预留原始资产可重建节点。历史“连延3—4次可能逐渐发糊”只解释旧成片，不拥有当前次数执行权。
- **仿真人与拟人动物在本集连续演绎链内，同一场景图／固定区域按约55秒预留转换，持续演绎不超过60秒**，通常用一条原生加一次延长承载。本集普通正反打、换文件名／卡／片段、同区重新原生和短暂空镜／回忆不重置累计；跨集默认独立原生不继承前集区域累计，也不为计算它等待前集。用户明确要求跨集连续动作／延长时才沿该连续链累计。可在同一空间推进到拓展区域／场景视角，但须有剧情目的、可读移动和新互动关系。区域转换在本集拆段时确定，时间纳入[整集预算](execution_rules.md#sound-and-time)，不据此拉长整集；素材不足按[必需性](execution_rules.md#references)列最小缺口。此约束用于后续新设计，不自动返工已采用视频。
- **首帧、尾帧及成片截图仅内部审片，不上传生成。** 不改名“状态/衣装/站位图”继续投喂。停用来自用户关于画质和构图继承的反馈，不是模型必然发糊的官方结论；原始人物、场景、道具及用户补制角色状态资产仍可用。用户专门制作的俯视站位图另按[执行规则](execution_rules.md#space)使用，不冒充成片截图。

源视频锁开场实际状态，人物图锁身份、场景图锁固定空间、必要道具图锁物件；延长不自动删图片参考，具体绑定见[执行规则](execution_rules.md#references)。

<a id="execution-handoff"></a>
### 交付与网页执行，沿用现有文件

GPT按[当前材料入口](director_os.md#workflow-stages)完成剩余前置；新设计在验证模式集中采用一次，有本任务自主授权则按范围内部采用。网页层消费唯一采用结果，不重新拆段、估时或偷偷改导演稿，也不为网页执行强制补齐协作角色或重转已有可靠音频。指定网页任务才读[唯一执行技能](../../extensions/seedance-jumeng-operator/SKILL.md)；网页目标沿用户URL或当前可信项目映射定位，仍缺时只问一次，不猜其他集。

自主前置决定设计／出稿的内部采用方式，网页默认只准备，不包含生成或付费提交。一次明确授权“本集原生及所需延长准备”即覆盖该集设计需要的准备，不逐段另批；缺合格原生源先预排，仅相关段待源。用户通知就绪后，沿当前状态定位实际采用结果，完成[必要局部核源](#source-state)后直接准备，只校准受影响接缝。视频槽、正文节点与区间等具体操作沿[唯一延长规程](../../extensions/seedance-jumeng-operator/references/video-extension.md)。

用户明确授权按当前采用方案完成本集原生及所需一次延长生成时，范围可覆盖原生提交、活动任务内等结果、必要局部核源、同集一次延长准备／提交及结果记录，不在范围内逐段重问。将目标项目／集段、采用版本、允许动作及用户已给的次数／预算记入现有状态；未给预算数值不编造，也不增加逐段审批。只有超出原范围的追加、失败重提或换源／改稿，才返回对应决定。按[完整生成规程](../../extensions/seedance-jumeng-operator/references/generation-execution.md)逐卡执行：核当前目标与队列、正文／真实引用及正确模式，最后设置本卡整数秒数、同页核准、提交一次并取回执。点击后回执未知先核正常可见队列／历史，不盲重试；完成、失败与未知分别记。应用关闭后的后台唤醒不默认具备，当前活动任务内等待、重开沿已有记录续做。

三个入口只由GPT整理执行所需事实，沿下列已有文件分工，不要求用户另交JSON、卡号表或指定内部目录。

| 唯一出处 | 交给执行者的事实 |
|---|---|
| `production_state.md` | 目标集段、本次范围与授权依据、前置工作模式、当前采用输入／方案及认可依据；链接当前提示索引、音频依据、运行记录和未决项。 |
| `assets/README.md` | 语义名、真实素材路径、用途与核看／可用状态；单段制作设置选本次素材，不再复制另一套清单。 |
| 当前提示词的制作设置与正文 | 模型／模式、整数时长（延长为新增）、A／G／R及可裁位置／映射、实际源／区间和已知状态、当前依赖、唯一正文版本；延长含固定源名视频引用。 |
| `prompts/INDEX.md` | 每段唯一当前文字及具体等待条件；正文完成、源已确定、真实绑定、可执行、采用、已填、已提交、已生成、可用于接续和用户评价分别标，链接实际运行记录。 |

实际上传／引用后回读语义名到平台真实正文节点，再同步该段角色映射与参考区；计划编号、普通@文字或引用条带都不等于正文绑定。延长正文必须有固定源名的@视频和同名状态，即使延长入口已选源也不能省略。实际@视频2替代预设@视频1时核真实语义源，不只核编号。没有可靠节点则明确待源／待绑定，不编造或降成免引用可执行。

源片用实际平台结果／任务标识或本地文件和认可依据指明，不把文字V3当V3真实源，不凭缩略图顺序或“最新”猜选。用于延长的源须原生且尚未延长；真实源长、选用区间和本次新增整数时长分别记，源内余量不重算，选用终点改变重核真实状态。未核项保持未知，按前述局部核源取得必要事实；具体歧义内部无法解决才问。接续仍正常切镜、行动和对抗，不冻结整段。已授权延长准备或生成时可正常选真实源与区间；具体UI唯一路由见[延长准备](../../extensions/seedance-jumeng-operator/references/video-extension.md)，不据原生一卡规则盲建延长目标。

执行者只按实际绑定修编号；模式正确时只读，必要切换放在填稿之前。缺图、源不明、参数不符或关键接缝矛盾返回具体阻断，不替图、删词、缩时或填后切模式。只填稿时沿制作设置或一份运行记录保留正式稿指纹、URL／卡ID、节点语义、已选模式和目标整数秒；正常保存后核当前正文／引用即可，不为已知的秒数回退反复切卡／重访。沿当前采用版本记目标值，收到本任务生成指令才设置秒数、同页核准并提交；不提前声称时长已持久。真实恢复或新异常出现时只补差异，记录实际观察；不以点击生成测试保存，未知回执不编造，真实网址与截图留私有项目。

中断先读状态和索引，按项目＋集＋段＋稿版本／指纹＋真实卡查已填内容，只补差异，不重复建卡／上传。既有生成中任务只读，不重复提交；已生成也不自动合格。同集连续链的一次延长与区域累计不因失败、未知或重新原生归零，跨集范围按上方新默认。原生填稿／图片节点通过不等于延长准备通过；准备另核真实源与区间、已选模式、槽／正文视频同源、人物／场景图及目标新增秒数。生成提交及结果处理遵本次明确授权，不能为“验收准备”点击生成。

### 依赖与可并发候选

连续内容中的特殊转场若依赖同一动作、实体遮挡、形状或运动，优先把切出与切入放在同一次生成任务中，必要时据此调整分段。拆成两条独立原生任务只作为后期匹配切备选，不能把尚未成立的前后匹配当作无依赖并发；选定后仍核对两端状态与可读结果。

同集没有抓握也可能依赖泪痕、持物、衣装、视线或四人回切，单人特写不自动独立。必要同集连续链等待合格源片，不为并发删反应／跳物理过程；跨集默认原始资产重建，只沿剧本保身份／阶段／场景，不把本段规则扩大成前集待源要求。

桌区功能角色单人发言、外围宾客反应等，身份/光线/朝向/心理起点已明确且不带未知末态的主角脸、肩、手、道具时，可作为独立候选，不把外围人搬进核心关系。剧本解读、时轴、资产核查及后段初稿可提前，等待只阻塞依赖真实结果的生成与最终校准。同一预算内的候选段数与返抽范围由[导演流程](director_os.md#segmentation)维护，不默认每镜一个生成任务或每段占满平台长度。

从同一清晰源片分支只适用于各分支真实共享同一开场末态、无需继承彼此新增变化；需要前段放手、递物或移领结果仍顺序接续。延长后遇换场、跳时或可靠重建点重新原生，不继续串联。并发策略收益按项目验证，不能承诺节省成本或提高成功率。

### 动态站位

```text
实际源片终态 → 谁因何起步 → 通路与谁跟随/让路/试拦 → 接触/避让 → 新落点
```

接续只继承开场，不冻结整段。允许按剧情走、跑、跟随、绕行或阻止，速度与可达距离合理；各人路线和起步不同，不机械全员跟上。重要经过、绕行、阻拦、接触与到位可读，无事路程可剪辑省略，已起步的画外移动可用视线/脚步承接。明显门、桌、柱可帮助定位，不强制为标志物摆位。

到位后仍表演，下一镜/下一段接实际新落点，不复位旧构图。末镜落在本段人物结果/情绪上，不为“稳定终态”排队、冻结或追加全员全身/俯视核对镜；既有镜头已建立清楚关系且动作落稳即可。新增关键人物须来向和入场，不受旧源片人数限制，用紧凑纵深、过肩或必要短暂放宽建立新关系。

执行前只核对当前依赖：源片合格/未延长、实际末态与正文一致；移动目的/通路/距离可达；该见者可见、画外者有位置；新落点/持物/接触/时段清楚；上传无截图残留。

## 4. 动作链与切点

镜内完整规则见[执行规则：镜头](execution_rules.md#shots)。跨段切点必须是动作与关系可解释的节点，不能只是换到下一行：同方向经过、取/递物、摘戒指、开门、巨型登场及需连续惯性的保护/拉回/坠落先保完整；时空变化、明确主客观转换、结果已落稳或注意力交给直接反应时再切。

复杂接缝内部成对核对`N镜终态 → N+1开场 → 变化依据`，比位置/左右、视线、运动、接触、持物与阶段。轴线例外、时间匹配蒙太奇与真实镜数只按执行规则，不另算一套；生成边界还需[第3节](#generation-choice)的可重建性。

## 5. 物理因果检查

跨段核对谁触发、谁先察觉/仍不知、何时接触、受力与惯性、结果时身体/脚/道具位置及他人反应。完整接触与受击做法见[执行规则第6节](execution_rules.md#action-physics)，已完成动作终态不能在新任务重启。

## 6. 声音连续性

声音也有状态：内部核对旁白覆盖和现场对白窗口、谁在说/听、词句跨镜是否只读一次、最先可听线索、接触同步以及环境声随空间/距离/主观状态改变。三种时间、对白原文与完全无BGM按[执行规则：声音与时间](execution_rules.md#sound-and-time)，正文不复制后期旁白调度。

## 7. 9:16 连续性

跨镜检查纵深、肩膀归属、拍摄对象、俯仰与轴线、主要阅读路径；已建立巨型主体或关键物件可暂退画外，但世界位置仍成立。实际成片查看原片与字幕/界面安全区叠加版本，具体构图见[执行规则](execution_rules.md#vertical-frame)。

<a id="review-and-repair"></a>
## 8. 四层验收与精准返修

### 按证据决定读取量

用户2026-10-08明确：**一般情况下不主动看视频效果，除非用户主动提出。**普通成稿不自动打开视频、抽帧或听检，不把全片审看设为必经步骤。用户要求审片／逐帧定位时只读相关范围；当前明确延长准备或完整生成授权还包括[必要局部核源](#source-state)，由GPT检查影响接缝的真实终点和状态，不额外索取审片授权或要求用户先代核。两者均不默认全片播放、全轨听检或重审整集。记录不足先查当前提供的局部依据，仍无法解答的具体歧义才短问。未知保持未知，不以计划终态代填；定位已够不重读全部片段或旧聊天。

文字检查只能说明文本覆盖；抽帧只能说明看过的画面。审有现场台词的成片须实际听检漏词、重读、抢拍、完整发声与句末截断，并比较说话进度与画面；没听音轨不能标声音通过。未见真实源片不能标接缝通过，未生成文本版本不能记成实际采用。

### 四层区分

| 层次 | 实际核对 |
|---|---|
| 故事 | 当前事实/知情顺序/因果是否成立，情绪和信息兑现是否看见，有无擅改剧情 |
| 导演 | 主体选择、直接回应、台词内变化与高点余波是否被看见，真实切镜与可读性是否兼顾；正确但不好看单独记录 |
| 模型条件 | 指代/空间/画幅容量、素材冲突与特殊风险是否已排查，不能用加字掩盖素材/版本上限 |
| 成片 | 实际时间/光照/反射、人物与道具状态、画质、声音、方式与源片；区分一次随机观察、重复模式和文件压缩/显示差异 |

文本成稿只按[模板一次检查](prompt_template.md#final-check)，不逐轮重复四层长清单。只有真实反馈需要时使用本节定位。

### 最小返修

1. **先选已知可用基线**：结合用户认可、实际采用与复盘，不把最新失败稿自动当最好版本；原稿/失败证据保留。标清满意、止损可用、仅文字完成、生成成功与未知。
2. **定位具体镜头与原因**：指出缺触发、表演、轴线、来路、受力、机位、资产或声音；分清设计/素材冲突/模型偏差，原因未验证时写假设。
3. **保住成立部分**：事件、动作顺序、空间、道具链及有效声音转折、身体爆发、快速收紧点和余波继续使用。修站位/手位不能默认改平直念词、普通中景或微表情；用户明确降调才降。增加情绪先加强说话者、直接对象和最相关关系人，不扩大成全员激动、走位或接触。
4. **替换错误句而非追加**：用一个清楚正向动作/落点替换，删其他栏同义限制；可压无观看作用的重复准备／等待；必要表演调整仍受[整集预算](execution_rules.md#sound-and-time)约束，只重核受影响声音、分段与接缝并同步对应。未采用攻击动作时不先引入攻击姿态再补禁止项；保留已采用的拦留、甩脱、拍开等交锋及直接回应，不因没有攻击把身体表现缩成眼神与呼吸。
5. **验受影响结果**：只核对修改镜与必要前后接缝，记录未验证项。若结构本身不可执行，说明需改分段/剧情/已确认拍法的具体依赖，不在错误基线上堆字，也不默认整段重写。

<a id="feedback-maintenance"></a>
## 9. 复盘格式与反馈维护

```text
预期：
实际：
成立部分：
主要偏差：
节奏数据：时长 / 真实镜头数 / 平均镜长 / 最长镜头
原因假设：
最小修正：
验证结果：
规则状态：观察 / 候选规则 / 稳定规则 / 项目偏好
```

原提示词与失败结果不覆盖。单次反馈先修本项目、记录成立部分与具体偏差；审美或流程偏好留本项目。只有具备可推广依据的经验才更新其唯一核心位置，替换过时说明并保留来源、适用条件与验证状态，不把每个失败都追加成全局禁止项。明确用户新决定立即更新当前状态并标适用范围；不以“尚未多次验证”延迟执行，也不把项目决定自动推广为其他项目约束。

用户报告制作完成时，更新总体阶段为已完成／转复盘并保留真实满意程度；具体最终稿、源ID或完整末态未知单独记，不继续指挥旧状态中的待重做任务，也不以最大版本号代填最终采用。仅后续工作真依赖该未知时补问，不为关闭任务另加用户作业。

## 10. 规则成熟度

| 状态 | 含义 |
|---|---|
| 观察 | 一次现象，原因未确定 |
| 候选规则 | 有原因假设，待相近任务验证 |
| 稳定规则 | 多个项目/对照版本重复验证 |
| 项目偏好 | 用户明确的当前项目审美／流程，立即执行；全局用户决定按明确范围执行，不属于待实验规则 |
| 废弃规则 | 新证据推翻，不再有执行权 |

同提示词Fast失败、2.5成功优先记版本边界，不升级为“必须写更长”。证据来源与执行偏差分层见[模型记录](model_behavior.md#evidence-boundaries)。

<a id="controlled-comparison"></a>
## 11. 必要时的对照验证

仅真实反馈仍分不清原因且用户同意时使用，不默认额外试拍。固定剧情、素材和大部分提示词，改变一至两个变量，如连续动作/切点、距离、镜数/反应时长、光线或版本。对照用于辨因，不借低成本改变已确认导演目标。
