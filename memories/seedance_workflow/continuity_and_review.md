# 连续性、动态站位与成片复盘

> 本文件维护生成方式、实际源片与跨段依赖、审片证据及精准返修。镜内素材/轴线/动作/声音的完整执行方法见[执行规则](execution_rules.md)，分段判断见[导演流程](director_os.md)。用户文字已足以定位时直接修，不默认重新读整部剧或全部视频。

<a id="source-state"></a>
## 1. 八类实际状态

| 状态 | 追踪内容 |
|---|---|
| 空间与轴线 | 具体功能区、锚点、入口、威胁来源、屏幕顺序、视线、运动方向与摄影机侧 |
| 角色 | 服装、伤势、姿态、已知/误信、情绪阶段、发声与对象 |
| 画外人物 | 方位、距离、视线参照、景别内是否可见或已开始的路线 |
| 身体与主观视角 | 正从谁身体看、手/衣袖/饰物及左右 |
| 道具 | 来源、持有人、手位、朝向、数量、位置与损坏 |
| 动作 | 起点、触发、接触、受力、结果与落稳状态 |
| 世界条件 | 时间、天气、光源、风、环境声与行动区域 |
| 竖屏层次 | 前景遮挡、中景主体、后景目标、高低与安全区 |

每个连续新镜从上一镜实际终态开始；已拨开的手、已松握、已落下道具或已开门不无因恢复。人物出画不等于离场，画外位置与已开始移动仍有效，不能为反打换位。

逐接缝把“上一镜最后一句＋下一镜第一句”成对连读：能直接承接位置/姿态/持物/阶段/视线/机位，或剧本允许明确换场/跳时且首帧可读新时空和稳定关系；二者都不成立即瞬移。校门→走廊→教室不必拍完全部路程，但入口、途中锚点、门槛、到位中承担身份或关系的必要节点须保留。

跨任务以**合格源片实际末态**为准；先核对当前用户反馈与采用记录，足够则直接使用，仍不足以确定接触、手位、距离或路线时，只看相关末段，不以计划终态代填。记录实际使用的源片、生成方式与关键末态；未知保持未知。

## 2. 场景图与空间基线

首次复杂空间内部辨认固定结构、入口/出口、行动区、人物锚点/视线、主轴/摄影机侧与光源，再核对实际源片有没有偏离。只把当前所需事实写进正文，不另建长期导演卡。

素材本身不支持必需路线时先补图或调整拍法；单人紧特写可仅继承正确视线、光线与背景色，不每镜塞门柱或肩沿迫使远处人物挤近。场景双视角、用户俯视站位图及多人风险闸门完整维护在[执行规则：空间](execution_rules.md#space)，这里不重复一份坐标规则。

<a id="generation-choice"></a>
## 3. 接住开场，允许行动改变站位

### 生成方式与当前用户制作约束

先比较实际前段结尾和本段开场的具体空间、距离、朝向、持物、接触与表演阶段，不按集号或“同一公寓”判断：

| 实际关系 | 默认方式 |
|---|---|
| 不同大地点、明确跳时或需重建状态 | 原始资产独立生成；可硬切/有任务空境，无素材依赖可并发 |
| 同一具体空间、简单关系可可靠重建 | 原始人物/场景/道具独立生成 |
| 同一具体空间，站位、接触或连续表演复杂 | 平台支持且前段合格后，优先视频延长；跨集同样适用 |
| 连续时间转入相邻区域 | 拍清起步、移动与新到位，再按实际末态选择延长或独立 |
| 开场同场而片段中途换场 | 可延长开场关系，再硬切到独立场景/已建立回忆 |

平台延长允许真实硬切和换机位，不等于全段一镜到底。视频参考与平台视频延长是两种操作，顶部制作设置分别记计划与实际操作，正文只说明源视频承担的状态；视频不提供剧情记忆。源片的人物、衣装或时段有错先修正或确认重建，不传播错误。

以下是**当前用户制作决定/公司平台工作约束**，不是官方模型物理上限：

- **一条源片只向后延长一次。** 延长结果不能再当下一条延长源；候选源必须未经过延长且合格。把唯一延长留给最依赖真实接触/移动/连续表演的接缝，后续预留原始资产可重建节点。历史“连延3—4次可能逐渐发糊”只解释旧成片，不拥有当前次数执行权。
- **仿真人与拟人动物同一场景图、固定演绎区域按约55秒预留转换，持续演绎不超过60秒**，通常用一条原生加一次延长承载。普通正反打、换文件名、换片段/集号、同区重新原生，以及短暂空镜/回忆均不重置该区累计。可在同一空间推进到拓展区域/场景视角，如沙发区→客厅与厨房连接处，但须有剧情目的、可读移动和新互动关系。区域转换与大地点换场在拆段阶段确定，转换时间纳入设计；素材不足列缺口，剧情不能合理转移时提出具体方案由用户决定。此约束用于后续新设计，不自动返工已采用视频。
- **首帧、尾帧及成片截图仅内部审片，不上传生成。** 不改名“状态/衣装/站位图”继续投喂。停用来自用户关于画质和构图继承的反馈，不是模型必然发糊的官方结论；原始人物、场景、道具及用户补制角色状态资产仍可用。用户专门制作的俯视站位图另按[执行规则](execution_rules.md#space)使用，不冒充成片截图。

源视频锁开场实际状态，人物图锁身份、场景图锁固定空间、必要道具图锁物件；延长不自动删图片参考，具体绑定见[执行规则](execution_rules.md#references)。

### 依赖与可并发候选

连续内容中的特殊转场若依赖同一动作、实体遮挡、形状或运动，优先把切出与切入放在同一次生成任务中，必要时据此调整分段。拆成两条独立原生任务只作为后期匹配切备选，不能把尚未成立的前后匹配当作无依赖并发；选定后仍核对两端状态与可读结果。

没有抓握也可能依赖泪痕、持物、衣装、视线或四人回切，单人特写不自动独立。必要连续链等待合格源片，不为并发删反应/跳物理过程；完全换场不制造无效等待。

桌区功能角色单人发言、外围宾客反应等，身份/光线/朝向/心理起点已明确且不带未知末态的主角脸、肩、手、道具时，可作为独立候选，不把外围人搬进核心关系。剧本解读、时轴、资产核查及后段初稿可提前，等待只阻塞依赖真实结果的生成与最终校准。3段/4段比较与返抽范围由[导演流程](director_os.md)维护，不默认每镜一个生成任务。

从同一清晰源片分支只适用于各分支真实共享同一开场末态、无需继承彼此新增变化；需要前段放手、递物或移领结果仍顺序接续。延长后遇换场、跳时或可靠重建点重新原生，不继续串联。并发策略收益按项目验证，不能承诺节省成本或提高成功率。

### 动态站位

```text
实际源片终态 → 谁因何起步 → 通路与谁跟随/让路/试拦 → 接触/避让 → 新落点
```

接续只继承开场，不冻结整段。允许按剧情走、跑、跟随、绕行或阻止，速度与可达距离合理；各人路线和起步不同，不机械全员跟上。重要经过、绕行、阻拦、接触与到位可读，无事路程可剪辑省略，已起步的画外移动可用视线/脚步承接。明显门、桌、柱可帮助定位，不强制为标志物摆位。

到位后仍表演，下一镜/下一段接实际新落点，不复位旧构图。末镜落在本段人物结果/情绪上，不为“稳定终态”排队、冻结或追加全员全身/俯视核对镜；既有镜头已建立清楚关系且动作落稳即可。新增关键人物须来向和入场，不受旧源片人数限制，用紧凑纵深、过肩或必要短暂放宽建立新关系。

执行前只核对当前依赖：源片合格/未延长、实际末态与正文一致；移动目的/通路/距离可达；该见者可见、画外者有位置；新落点/持物/接触/时段清楚；上传无截图残留。

## 4. 动作链与切点

镜内完整规则见[执行规则：镜头](execution_rules.md#shots)。跨段切点必须是动作与关系可解释的节点，不能只是换到下一行：同方向经过、取/递物、摘戒指、开门、巨型登场及需连续惯性的保护/拉回/坠落先保完整；时空变化、明确主客观转换、结果已落稳或注意力交给直接反应时再切。

复杂接缝内部成对核对`N镜终态 → N+1开场 → 变化依据`，比位置/左右、视线、运动、接触、持物与阶段。轴线例外、时间匹配蒙太奇与真实镜数只按执行规则，不另算一套；生成边界还需[第3节](#generation-choice)的可重建性。

## 5. 物理因果检查

跨段核对谁触发、谁先察觉/仍不知、何时接触、受力与惯性、结果时身体/脚/道具位置及他人反应。完整接触与受击做法见[执行规则第6节](execution_rules.md#action-physics)，已完成动作终态不能在新任务重启。

## 6. 声音连续性

声音也有状态：内部核对旁白覆盖和现场对白窗口、谁在说/听、词句跨镜是否只读一次、最先可听线索、接触同步以及环境声随空间/距离/主观状态改变。三种时间、对白原文与完全无BGM按[执行规则：声音与时间](execution_rules.md#sound-and-time)，正文不复制后期旁白调度。

## 7. 9:16 连续性

跨镜检查纵深、肩膀归属、拍摄对象、俯仰与轴线、主要阅读路径；已建立巨型主体或关键物件可暂退画外，但世界位置仍成立。实际成片查看原片与字幕/界面安全区叠加版本，具体构图见[执行规则](execution_rules.md#vertical-frame)。

<a id="review-and-repair"></a>
## 8. 四层验收与精准返修

### 按证据决定读取量

用户文字已经清楚说明结果与修法时，直接依据反馈、可用提示词和受影响接缝修正；只有用户要求审片/逐帧定位，或没有实画就无法判断末态、持物、站位、接触与落点时，才读取相关视频。定位已够不重审全部片段，不追旧聊天；文件缺失或决定冲突才寻找具体依据。

文字检查只能说明文本覆盖；抽帧只能说明看过的画面。审有现场台词的成片须实际听检漏词、重读、抢拍、完整发声与句末截断，并比较说话进度与画面；没听音轨不能标声音通过。未见真实源片不能标接缝通过，未生成文本版本不能记成实际采用。

### 四层区分

| 层次 | 实际核对 |
|---|---|
| 故事 | 当前事实/知情顺序/因果是否成立，情绪和信息兑现是否看见，有无擅改剧情 |
| 导演 | 主体选择、直接回应、台词内变化与高点余波是否被看见，真实切镜与可读性是否兼顾；正确但不好看单独记录 |
| 模型条件 | 指代/空间/画幅容量、素材冲突与特殊风险是否已排查，不能用加字掩盖素材/版本上限 |
| 成片 | 实际时间/光照/反射、人物与道具状态、画质、声音、方式与源片；区分一次随机观察、重复模式和文件压缩/显示差异 |

文本成稿只按[模板一次检查](prompt_template.md#final-check)，不逐轮重复四层长清单。只有真实反馈需要时使用本节定位。

### 最小返修

1. **先选已知可用基线**：结合用户认可、实际采用与复盘，不把最新失败稿自动当最好版本；原稿/失败证据保留。标清满意、止损可用、仅文字完成、生成成功与未知。
2. **定位具体镜头与原因**：指出缺触发、表演、轴线、来路、受力、机位、资产或声音；分清设计/素材冲突/模型偏差，原因未验证时写假设。
3. **保住成立部分**：事件、动作顺序、空间、道具链及有效声音转折、身体爆发、快速收紧点和余波继续使用。修站位/手位不能默认改平直念词、普通中景或微表情；用户明确降调才降。增加情绪先加强说话者、直接对象和最相关关系人，不扩大成全员激动、走位或接触。
4. **替换错误句而非追加**：用一个清楚正向动作/落点替换，删其他栏同义限制；保留已授权时码调整，可压重复准备/等待，重核对白和接缝。未发生攻击只写看得见的眼神、呼吸、声音或距离，不先抬臂逼近再补“不要攻击”。
5. **验受影响结果**：只核对修改镜与必要前后接缝，记录未验证项。若结构本身不可执行，说明需改分段/剧情/已确认拍法的具体依赖，不在错误基线上堆字，也不默认整段重写。

## 9. 复盘格式

```text
预期：
实际：
成立部分：
主要偏差：
节奏数据：时长 / 真实镜头数 / 平均镜长 / 最长镜头
原因假设：
最小修正：
验证结果：
规则状态：观察 / 候选规则 / 稳定规则 / 项目偏好
```

原提示词与失败结果不覆盖。新反馈先进入项目已有复盘；明确新决定立即更新当前状态并标范围。推广经验只更新其唯一维护位置，并保留证据。

## 10. 规则成熟度

| 状态 | 含义 |
|---|---|
| 观察 | 一次现象，原因未确定 |
| 候选规则 | 有原因假设，待相近任务验证 |
| 稳定规则 | 多个项目/对照版本重复验证 |
| 项目偏好 | 用户明确的当前项目审美/流程 |
| 废弃规则 | 新证据推翻，不再有执行权 |

同提示词Fast失败、2.5成功优先记版本边界，不升级为“必须写更长”。证据来源与执行偏差分层见[模型记录](model_behavior.md#evidence-boundaries)。

<a id="controlled-comparison"></a>
## 11. 必要时的对照验证

仅真实反馈仍分不清原因且用户同意时使用，不默认额外试拍。固定剧情、素材和大部分提示词，改变一至两个变量，如连续动作/切点、距离、镜数/反应时长、光线或版本。对照用于辨因，不借低成本改变已确认导演目标。
