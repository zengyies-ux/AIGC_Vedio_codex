# 连续性、动态站位与成片复盘

## 1. 八类状态

| 状态 | 需要追踪的内容 |
|---|---|
| 空间与轴线 | 当前功能区、固定锚点、前后左右、高低、入口、威胁来源、人物屏幕顺序、视线、主要运动方向与摄影机所在一侧 |
| 角色 | 服装、伤势、姿态、已经知道或误信什么、情绪阶段、是否说话及对象 |
| 画外人物 | 上一镜位于主体哪一侧、距离多远、主体应朝哪里看、是否能在当前景别被看见 |
| 身体与主观视角 | 正从谁的身体看，可见手部、衣袖、饰物和左右关系 |
| 道具 | 来源、持有人、左右手、位置、朝向、数量和损坏状态 |
| 动作 | 起点、触发、接触、受力方向、结果和落稳状态 |
| 世界条件 | 时间、天气、光源方向、风、环境声和场景区域 |
| 竖屏层次 | 前景遮挡、中景主体、后景目标、高低关系和安全区 |

每个新镜头从上一镜实际结束状态开始。不要让已经完成的动作再次发生，也不要默认模型会自动保持门、杯子、戒指或伤势状态。

最快的逐切点复核方法是把“上一镜最后一句＋下一镜第一句”成对连读，并只判断两种关系：

- **连续承接**：人物画面左右、姿态、持物、动作阶段、视线与摄影机侧能够从前句直接进入后句。
- **明确重建**：剧本允许跳时或换场，切入第一帧已经交代新时间、新地点、人物为何到此及稳定开场关系。

若既不能直接承接，也没有明确重建，这个切点就是未解释的瞬移。人物从校门到走廊、从走廊到教室等路线不要求逐步拍完所有距离，但当“如何到场”本身承担身份建立、关系互动或防止突然出现时，至少保留入口、途中锚点、跨门槛和到位中的必要节点。

跨任务同样要继承已经完成的动作终态。被推开的手、落下的道具、已经松开的抓握或已经打开的门，在新任务开场不能无原因恢复并重复动作。

人物离开画框不等于离开空间。反应近景中看不见另一人时，仍要继承上一镜的方位和距离；相对位置改变须有可信的起步、路线、到位或明确时间跳跃，不能为反打方便悄悄换位。

## 2. 场景图与空间基线

场景图不是背景墙。首次使用复杂场景时，内部记录：

```text
固定结构：
入口与出口：
主要行动区：
人物锚点、画面左右与视线方向：
主轴与摄影机侧：
关键光源：
```

- 多张同场景图片先判断方向关系，再安排人物。
- 必须出现的区域要获得镜头时间，不能只作为辅助图上传。
- 需要重新辨识空间时，用门、柱、窗、台阶或灯等已有结构定位；关系已建立的单人紧特写可以只继承正确视线、光线和背景色。不能为每镜塞空间标志或他人肩沿，迫使原本相隔的人挤在一起；画外位置仍须成立。
- 场景图不支持用户要求的路线或站位时，先补图或换拍法。
- 三人以上在单一场景中需要精确锚点、主轴和多人路线时，可使用用户专门制作并同步的俯视站位图。Codex负责识别图中A—H与角色的映射并据此设计提示词，不自行增加站位图生成步骤。俯视图只负责空间坐标，不负责人物外貌、服装、真实材质或成片构图，也不要求实际视频出现俯拍、字母或箭头。
- 俯视站位图是降低高风险多人原生重建抽卡率的工具，不是每段默认流程。用户未提供时，Codex可指出具体空间风险与需要标注的角色或路线，由用户决定并制作；双人、三人简单关系或无需精确换位的内容直接生成。
- 一次生成只保留一张主要站位依据；不把俯视站位图与白模、成片截图及多个相互竞争的空间示意同时投喂。人物图继续负责身份，真实场景图继续负责建筑与材质。

### 单一场景连续多集的空间风险闸门

当同一具体场景连续跨越多个片段或多集，并且场景模块无法清楚固定多人前后层次、精确落点或行动路线时，不再连续用文字方位返抽。出现以下任一情况，向用户说明具体风险与需要标注的人物或路线；用户决定制作并提供俯视站位图后，将它作为当前段的主要空间依据。Codex不自行增加制图步骤，用户不采用时则比较合格源视频延长、简化路线或调整切点：

- 三人以上需要保持固定主轴，同时有新人物入场、绕行、扶起、包围、换位或多人分别行动。
- 下一段或下一集必须继承当前动态终态，站位错误会迫使已合格前段重做。
- 纯文字或场景模块已经发生一次身份错配、路线穿越、人物瞬移或站位重排。

收到站位图后，把图中位置视为当前空间事实。除非剧本明确要求人物移动，不为了换构图、接下一段或丰富画面擅自改变A—H坐标；用景别、角度、反应近景和关系镜变化观看方式即可。剧情只要求E/F/G/H围向A或B时，正文直接使用字母说明谁对谁行动，不机械拆解每个人的步数、路线阶段和逐秒到位。只有接触对象、移动方向或新落点本身是剧情信息时，才补必要过程。

俯视图若与剧本必须发生的动作、对象或通道冲突，不通过额外走位自行改图，也不悄悄重新解释字母落点；先向用户指出具体冲突，由用户调整站位图或确认改拍法。

## 3. 接住开场，允许行动改变站位

### 当前生成方式

先比较实际前段结尾与本段开场的空间、距离、朝向、持物和接触。同场复杂接续优先等待合格源视频后延长，跨集也适用；开场换场、明确跳时或可由原始资产可靠重建关系时独立生成，无依赖即可并发。延长中可以真实硬切换机位，不能把平台延长等同于全段一镜到底。

- 当前不向Seedance上传首帧、尾帧或成片截取的站位图片，也不将它们改名成“状态图”后继续使用。截图可内部审片，不进入生成参考区。
- 停用截图参考来自用户关于画质和构图继承的反馈，是当前制作决定，不是官方能力定论。原始人物、场景、道具及用户专门补制的角色状态资产仍可使用，不能误删全部图片参考。
- 源视频负责开场实际状态和动作轨迹；角色图负责身份服装，场景图负责固定空间，必要道具图负责物件。源视频不提供剧情记忆，本段仍须自包含。
- 当前生产硬规则是一条源片只向后延长一次：视频延长生成出的片段不能再次作为下一段的延长源。过去关于连续3-4次后可能逐渐发糊的观察仍用于解释历史成片，但不再作为当前允许次数；需要继续接戏时，在动作落稳处使用原始人物、场景和道具资产独立重建，不重新启用截图参考。
- 源视频若人物、服装或时间本身有错，先修正或与用户确认重建方式，不将错误继续传递。实际使用方式与源片另记，不能把计划冒充已执行。

### 减少不必要的源片依赖（生产候选策略）

并发按本段可见内容是否依赖前段实际结果判断，不按是否同一个房间判断。没有抓握也可能依赖泪痕、持物、衣装、视线与四人回切；单人特写也不能因此自动判为独立。

- 核心接触链保持必要顺序。桌区配角单人发言、外围宾客反应等，如身份、光线、朝向和心理起点均已明确，且不出现依赖未知末态的主角色脸、肩、手或道具，可以设计为独立生成候选；不为同框把外围人物搬到核心关系中。
- 整集先比较3段与4段候选，在动作完成、关系可重建、关键回应已落下的位置选择生成边界，不把既定少段数当默认。第四段若能隔离高风险情绪/动作单元并缩小返抽范围可以采用；若只会切断对白或接触、增加延长链和身份重建，则不拆。仍不默认每镜一个任务，只有有实际剪辑用途且总体工作量合算时才增加独立补段。
- 整集剧本解读、对白时轴、原始资产核查及后段初稿可提前完成。等待源片只阻塞依赖未知状态的生成和最终校准，不必阻塞所有准备工作。
- 决定延长前先确认候选源片不是视频延长产物，并同时寻找下一处可重建节点。原生重建需动作落稳、接触/衣装/道具状态明确，并有原始资产支持；不恢复首尾帧或成片截图参考。
- 延长后遇到换场、明确跳时或动作已经落稳的可重建节点，重新比较独立生成，不因上一段使用延长而继续串联。
- 从同一清晰源片分支，仅适用于各分支开场确实共享该末态、彼此无需继承新增变化的情况；后段需要前段放手、递物或移领结果时仍须顺序接续。

以上用于导演与调度判断，不保证降低生成成本或提高成功率。具体收益依项目记录验证；不能为并发改编剧事件、跳过物理过程或减少关键人物反应。

### 动态站位的最短因果

```text
源视频实际终态 → 谁因何起步 → 通路与谁跟随/让路/试拦 → 接触或避让 → 新落点
```

站位不穿帮指变化有依据，不要求本段结尾和开场一样，也不要求每集维持同一构图。明显固定物可以提供容易辨认的目的地，例如桌内侧、柱旁或门边；有叙事需要才采用，不为控制模型让角色无目的地赶往标志物。

- 开场先继承实际相对关系；随后可以走、跑、跟随、绕行或阻止，速度服从剧情。人物起步和路线不同，不机械全员跟上。
- 让观众看见重要的经过、绕行、阻拦与到位。无事件的中途步行可以由真实剪辑省略，已开始的画外移动可用视线和脚步承接，但不能隐去跨人、穿桌或关键接触。
- 人物在动作节点到位后可以继续表演，不强制站稳等待。切镜沿用已经产生的新状态；下一段以合格成片的实际新落点为依据，必须精确继承时延长，能够用原始资产重建时独立生成，不复位到此前计划。
- 末镜只交代本段真正结束时的状态，不为了给下一段提供“完美站位图”把人物排队或冻结。
- “可供视频延长的稳定终态”不等于全员全身大远景。结尾仍应落在本段最重要的人物结果或情绪上；只要动作已经落稳、人物关系在此前镜头中建立清楚，后续视频延长可继承整段动态上下文。不能在结尾额外追加没有新信息的全局站位核对镜，更不能因为使用俯视站位图就让成片回到俯视构图。
- 新增关键人物须有可信的来向与可读入场，不凭旧源片人数让新角色消失。关系镜头可用近距离多人纵深、过肩或短暂放宽，非每镜必须全员入画。

### 执行前核对

1. 实际源视频是否合格，开场状态是否与正文相符？
2. 移动是否有目的、通路和正常速度下能达到的距离？
3. 该看见谁时是否被遮完，暂时画外的人是否仍有可信位置或移动轨迹？
4. 新落点、持物、接触及日夜是否清楚，下一段是否误恢复旧状态？
5. 上传清单是否残留首尾帧或改名后的成片截图？

## 4. 动作链与切点

切镜前问：当前动作完成了吗，还是提示词只写到了下一行？

优先连续拍：

- 同一人沿同一方向走过另一人。
- 一次完整取物、递物、摘戒指或开门。
- 巨型主体从触发到完成登场。
- 相对位置和惯性必须被连续观察的保护、拉回或坠落。

优先切开：

- 新地点或时间。
- 主观与客观视角的明确切换。
- 动作已经落稳，下一步从新的稳定状态发生。
- 同镜无法容纳武器、目标、飞行物、结果和群体反应。
- 注意力真正从动作转到人物反应或后果。

硬切不是问题；错误切点才是问题。

硬切前后额外核对：谁在主体左侧或右侧、两人是否隔着扶手或桌面、主体的视线应落向哪里。新镜头可以换摄影机角度，但不能在没有过渡动作时偷偷改变人物站位。

双人场先固定主双人构图：谁在画面左、谁在画面右、各自视线、紧邻锚点及摄影机侧。正反打保持在主轴同一侧，不能硬切后直接互换左右；换轴例外按下方逐对对账规则执行。该约束只作用于当前连续时空，新场景可重新建立。

三人以上先固定当前主关系轴，并记录其余关键人物的锚点、视线对象与从画面左到画面右的整体顺序。焦点关系换人时先用关系镜建立新双方的实际方位；不能用任何关系人的反应近景暗中交换主角左右。

复杂同场段在内部逐对做一次切点对账，不复制进Seedance正文：

```text
镜头N终态：人物画面左右 / 视线 / 运动方向 / 接触 / 持物 / 动作落点
镜头N+1开场：人物画面左右 / 视线 / 运动方向 / 接触 / 持物 / 动作起点
变化依据：状态不变 / 已拍清的起步与路线 / 稳定动作落点 / 明确换场或跳时
```

默认保持已经建立的轴线，不为构图变化或新鲜感主动换边。只有用户明确要求，或剧情动作自然导致人物交换位置时，才在连续镜头中拍清人物起步、经过与新落点，再用关系镜重新建立新轴；换到新场景或进入明确的新时空后可以重新建立。逐对同时比较主体、摄影机侧、景别、构图和动作阶段；普通相邻硬切不得无信息地复刻同一镜位或重启同一动作。故意用于时间流动的同状态匹配可以保持同一镜位与构图，但每次切入必须立即出现新的时间、进度或关系状态，并从同一动作阶段接住。稍后普通回到同一人物时，必须已经出现新的动作、情绪或关系状态。镜头密度不得靠无信息重复补足。

海外旁白短剧还要做密度检查：最低真实镜头数按“总时长除以3后向上取整”，例如16秒至少6镜、20至21秒至少7镜、22至24秒至少8镜、25至26秒至少9镜、30秒至少10镜；每个编号镜头原则上不超过3秒。只有真实剪辑切点计为新镜头，默认硬切，也可包含明确的遮挡或甩镜隐藏剪辑；推近、拉远、摇摄、横移、变焦、移焦和一镜到底仍只算当前一个编号镜头。连续动作不因凑数量被切断，动作落稳后立即转到反应、证据或后果即可。

## 5. 物理因果检查

对关键动作逐项检查：

```text
谁触发？
谁先看见或听见？
谁仍然不知道？
人物怎么移动？
何时接触？
受力朝哪里？
动作后双脚、身体和道具在哪里？
其他人物何时反应？
```

- 反应不能早于角色能察觉的线索；察觉意图后的预判和干预可以早于最终结果。区分先看见、后听见与仍不知情的人。
- 中弹、碰撞、拉扯或倒地后，身体惯性必须符合前一动作。
- 一个动作包含多个阶段时，阶段之间要共享同一位置和方向。
- 复杂威胁无法被模型稳定理解时，删去不必要装置，保留最短可见因果。

## 6. 声音连续性

声音也有状态。以下用于内部剪辑与连续性检查，不要求把后期旁白原文或调度说明写进Seedance正文：

- 旁白从哪一镜开始，在哪一镜结束。
- 台词是否跨镜继续且只读一次。
- 当前谁在说现场对白、谁在听，口型是否匹配；不要求人物在旁白期间始终闭嘴。
- 声音是否是该角色最先察觉的线索，接触声是否与接触同步；不要求已看见危险的人等声音响起才反应。
- 环境声是否随空间、距离和主观状态改变。

内部检查后期旁白不占用现场对白窗口。正文只写需生成的声音与口型。倒放、时间回流或意识变化可以通过环境声抽远、心跳、呼吸和动作声辅助，但不要让声音替代必要画面。

## 7. 9:16 连续性

- 先确定纵深，再决定景别；双人不默认并排。
- 过肩镜头同时核对肩膀属于谁、镜头拍谁、俯拍或仰拍，以及这一角度是否符合当前权力关系。强者肩后俯拍弱者与弱者肩后仰拍强者都能放大压迫感，但不能因此跨越摄影轴线或改变站位。
- 一个镜头保留一个主要阅读方向，例如上方车灯 → 中部人物 → 下方手表。
- 前景只做少量遮挡，中景承担主事件，后景承担目标或反应。
- 巨型主体、两张脸和关键道具无法同时清楚容纳时，已经建立过的元素退到画外。
- 质检时查看原片与字幕、安全区叠加后的版本。

## 8. 四层质检

### 故事

- 观众能否看懂因果？
- 当前段有无明确情绪或信息落点？
- 是否擅自改变剧本事实？

### 导演

- 每镜是否有任务？
- 当前内容模式是什么？海外旁白短剧是否达到对应时长的真实镜头密度？
- 每个编号镜头是否原则上不超过3秒？
- 是否只有真实剪辑切点被计入镜头数，镜内运镜没有被误算？特殊转场后能否立即辨认主体、方位、时段与动作结果？
- 核心事件是否被完整看见？
- 切点是否发生在动作完成或注意力换手处？
- 行动意图是否可被察觉，对手是否及时应对，反转或重台词后是否有反应时间？
- 镜头变化是否真正改变观看信息，非说话者是否有目的与回应，而非只增加眨眼皱眉？
- 每句对白的对象、头脸方向与前景人物是否一致，是否把下一句的转向提前用于当前句？重要非说话者的回应是否确实出现在具体镜头，而非仅写在状态段？
- 本段最值得看的爆感落点是否明确，兑现后是否有主角、对手或旁观者的余震？

### 模型

- 主体、站位、动作和指代是否单义？
- 当前画幅能否容纳要求同时可见的元素？
- 手部、文字、车辆、群演和特效是否超过版本容量？
- 素材职责是否竞争？
- 相反观察方向的场景图是否被错误地共同绑定到同一空间？车辆是否先按前进方向建立了座位图？
- 是否用更多文字掩盖素材或模型上限？

### 成片

- 剧情要求的白天、下午、黄昏或夜间是否落实到窗外、反射、门后背景与室内照明，是否误沿用参考图时段？
- 实际采用的生成方式与源片是否已确认，是否把计划方式误记成已执行方式？
- 偏差属于剧情、节奏、表演、空间、动作、道具、画质、声音还是审核？
- 是一次随机现象，还是可以重复的模式？
- 成片正确但不好看，是否还存在目的不清、行动不主动、反应太轻/太晚或观看节奏问题？
- 如原因仍不明，是否需要经用户同意的局部对照；不默认增加额外试拍？

## 9. 复盘格式

```text
预期：
实际：
成立部分：
主要偏差：
节奏数据：时长 / 真实镜头数 / 平均镜长 / 最长镜头
原因假设：
最小修正：
验证结果：
规则状态：观察 / 候选规则 / 稳定规则 / 项目偏好
```

原提示词和失败结果保留，不用修正版覆盖证据。

## 10. 规则成熟度

| 状态 | 含义 |
|---|---|
| 观察 | 一次现象，原因不确定 |
| 候选规则 | 有清楚原因假设，等待相近任务验证 |
| 稳定规则 | 多个项目或多个对照版本重复验证 |
| 项目偏好 | 用户在当前项目明确指定的审美或流程 |
| 废弃规则 | 被新证据推翻，不再拥有执行权 |

当 Fast 失败、2.5在同一提示词下成功时，优先记录为版本边界；不要错误升级成“提示词必须更长”。

## 11. 必要时的对照验证

仅当真实反馈仍无法区分原因且用户同意时采用，不是默认流程。固定剧情、素材和大部分提示词，只改变一个变量：

- 连续动作与切镜结构。
- 人物距离和站位。
- 镜头密度和反应时长。
- 光源与质感描述。
- Fast与2.5版本。

一次只改一到两个变量，才能知道改动为什么有效。
