# Seedance 提示词模板

## 1. 从已确认拆解直接落稿

审核通过的剧本拆解、分段方案和用户明确画面就是提示词蓝图。落稿前先做一次精简的转译分析，确认画面目标、人物动作因果、空间连续、镜头承载、时码和实际资产，再把已经选定的内容转成现有栏目。必须分析，但不再重复一整轮剧本解读、填写多层导演卡或展开大量备选拍法。选定内容只进入它实际发生的位置一次；分析过程、未采用方案、失败历史和验收推理不投喂模型。

写完后从第一镜顺读到最后一镜一次，核对拆解内容没有遗漏、动作与相邻状态成立、实际资产和声音齐全、正文没有重复说明。发现问题只修对应镜头或栏目，不重新推演整段。

## 2. 制作设置与可复制骨架

保持以下已经跑通的栏目、顺序与逐镜粒度，不随复盘另造新框架。流程精简只减少内部重复判断和正文冗余，不删改既有提示词结构、镜头节奏或必要信息；除非用户明确要求，不把逐镜提示词改成摘要、表格或另一套模板。

完整文件先放制作设置，再放可复制提示词，二者明确分开。单段文件和整集合辑都遵守；整集合辑用一张表列出`片段｜全局区间｜主情绪承载者与变化｜必须兑现的回应/余波｜方式与依赖｜分段理由`，不在每段正文重复操作说明。

文件顶部示例，以下不复制进Seedance：

```text
制作设置（不复制进提示词）
模型：当前选用的模型与版本
方式：独立生成 / 视频延长
源片：实际使用的合格片段；没有依赖则写无
正文时长：X秒
本次生成时长：Y秒；若采用延长，此数为新增时长。此项使用平台可选择的整数秒，正文区间与内部切点可以使用小数秒
调度：可与哪些片段并发 / 等待哪一段合格后生成
角色映射：人物A＝@图片1；人物B（本段状态）＝@图片2［只列角色，不把场景和道具混入］
实际操作：用户确认后填写，不用计划方式冒充实际方式
```

“角色映射”位于制作设置中，只供用户核对实际上传素材，不复制进Seedance。它必须与下方【人物与场景参考】的角色编号一致；同一角色存在日常、受伤、家长会或回忆状态时，在映射中直接写清本段使用哪一种状态。

可复制正文中的【生成任务】只保留生成时长、画幅、类型、真实镜头数及当前画面任务，不写模型名、“正常生成”“不使用视频延长”“向后延长”或平台操作步骤。也不写“为下一段保留”“方便下一集延长”“给后续接力”等生成目的；这些只留在制作设置和项目状态。精简不删已经选中的关键动作因果、对白窗口、镜头落点、必要空间控制和完整摄影要求；内部考虑过但未被镜头采用的微动作不进入正文。

下方示例适用于当前海外9:16旁白短剧。其他内容模式按当次任务调整画幅和节奏，不把3秒基线套到真人大量对白剧。示例中的“电影级真人”和发丝生命感是默认真人表述；拟人动物项目按`animal_city_motion.md`替换题材与动物生命感，栏目和声音时序保持一致。

```text
【生成任务】
生成[整数时长]秒、9:16竖屏、电影级真人短剧视频，共[镜头数]镜，默认真实硬切，每镜通常控制在3秒内；不可打断的完整对白或连续动作在因果落稳后再切。[简短写本段开场、核心事件与结束画面；有特殊转场时仅在对应切点说明。]

【人物与场景参考】
人物A：【@图片1】
人物B：【@图片2】
办公室：【@图片3】
手机：【@图片4】［仅在本段实际使用该素材时保留］

人物参考负责身份、外貌和服装，不在正文逐人复述；场景参考负责固定结构、透视及陈设。时段按下方要求，不沿用与剧情不符的参考图日光。

【空间与道具状态】
时间：[白天 / 下午 / 黄昏 / 夜间 / 午夜]。[窗外天空、城市明暗、室内主光源。不同场景或回忆分别列明。]
人物生命感：入镜人物保持自然呼吸，胸肩随呼吸轻微起伏，眨眼随注视与当下情绪自然发生；户外有微风时，发丝顺着实际风向轻轻摆动。

办公室：[填写门窗、入口、通道与必要开场关系；双人场填入具体的画面左右、对应视线、人物锚点和摄影机侧。无关项删除。]
手机：在谁手里、屏幕朝向哪里，动作后停在哪里。

【声音时序】
[每句现场对白原文只在此列一次：说话者→对象、起止窗口及必要的声线、语速或重音；跨镜沿当前词句继续。可见表演和说完落点放在对应镜头。无对白或特殊声音调度需要时可删除本栏。旁白节奏仅内部对齐，不写旁白原文或校准说明。]

【镜头设计】
编号之间有真实剪辑切点，默认硬切；特殊转场在相邻镜头中写清切出与切入。镜内推拉、摇移、变焦或移焦不算新增镜头。[同一连续时空内实际有双人反打时保留：反打只更换观看对象，机位保持在已建立关系轴同一侧，画外人物位置不变。]

镜头01【0.0-X.X秒｜景别、角度与主要运镜】
具体画面：主体在什么位置，对谁行动或看谁，触发后的动作、表演变化、回应与最终状态。关键对白写明说话者在台词进行中的可见变化；反应镜头写明角色听到或看到什么后，谁先发生什么变化，并写到动作落稳。镜头有变化时写清起点、终点及可读落点；特殊转场写清切出与下一镜切入，保留接触、方向与道具状态。
现场对白：[声音区已有原文时，只写对象、开口时点、表演与跨镜进度，不重复原文；仅在无声音区时在此列一次原台词。无需要则删除。]
声音：[与当前动作同步的必要环境声或动作声；无需要则删除。全段声音边界不在每镜重复。]

镜头02【X.X-X.X秒｜景别、角度与主要运镜】
……

【摄影、光线与真实感】
[完整保留当前项目由用户指定的摄影设备与镜头质感、胶片类型和颗粒、影调、柔焦与景深、肤质眼神光及运动模糊。以空间状态中的时间为准，明确光源方向；夜间不引入日光，接触动作保证景深和边界可读。不得在局部改稿时把摄影要求缩成几个泛化形容词。]

【声音与画面文字】
[统一说明声音边界，不重复列出对白原文。保留当前需要的呼吸、动作与环境声；列明剧情必要的手机或文件文字内容，由Seedance直接生成，不加额外字幕、水印。全段无BGM、配乐、背景音乐或源视频音乐延续；明确设计的快速变焦可用一次短促非旋律音效，不形成音乐铺底。无剧情文字时不虚构文字任务。]
```

已有明确且安全角色名时，直接把`人物A`写成角色姓名，例如`Sera：【@图片1】`，后续状态与逐镜也只写`Sera`。不要再追加“女主为Sera”“@图片1负责稳定Sera”等二次映射段。同一角色有两种必需状态时，用`Sera`与`受伤后的Sera`作为两个最短标签，状态切换条件放入【空间与道具状态】。

### 正文信息归属

| 栏目 | 只负责什么 |
|---|---|
| 【生成任务】 | 时长、画幅、镜头数与本段核心事件 |
| 【人物与场景参考】 | 本次实际上传素材的简名和`@`编号 |
| 【空间与道具状态】 | 时间、场景结构、开场关系及跨镜持续的接触、持物、伤势或道具事实 |
| 【声音时序】 | 现场对白原文、对象、时间窗口与必要声音表演，只列一次 |
| 【镜头设计】 | 当前镜头里的动作、表演、反应、运镜、转场与落点 |
| 【摄影、光线与真实感】 | 全段统一成像要求 |
| 【声音与画面文字】 | 全段声音边界和剧情必需文字 |

一个事实只放一个主要位置。【空间与道具状态】不写人物整段情绪弧、动作计划、未来动作或否定清单；人物图已经表达的身份、外貌和服装不再建立逐人说明。角色特殊开场状态确实无法由参考图表达时，只补一句，例如“男二左脸保留上一掌留下的淡红”。Seedance正文应由【镜头设计】承载主要篇幅，而不是在逐镜之前先写一遍完整剧情。

落稿顺序与最终栏目顺序可以不同：先根据已确认时码写【声音时序】和【镜头设计】，再回填实际素材与最短的【空间与道具状态】，最后加完整摄影和声音边界。只服务一个镜头的信息留在该镜；只有多镜共同依赖的事实才上提到状态段。若状态段开始逐人描述整段变化，或修bug没有增加新事件却使正文明显变长，停止补句并重新去重。

### 使用源视频时的正文

是否视频延长在顶部制作设置说明；参考区保留以下必要职责，不写【视频延长任务】或操作命令：

```text
厨房源视频：【@视频1】

【空间与道具状态】
时间：夜间，窗外为黑夜与城市灯点，室内由原有环境灯照明。
厨房源视频：只负责开场两人的实际站位、身体接触与道具状态。开场从视频末尾已经成立的两人距离、肩线与牵手状态开始；随后的行动、路线与新落点写在对应镜头。
```

同一具体空间且站位、接触或连续表演复杂时优先等待合格源片后延长，跨集也适用；开场换场、明确跳时或主动重建状态则独立生成，无依赖即可并发。开场接同场、途中才进入回忆时，可以使用源片保持开场关系，再由独立参考负责回忆。源片时段本身有错时先修正，不将错误照明直接传给后段。

## 3. 参考区规则

- 使用“固定简名：【@图片N】”，不输出文件名清单，也不把详细职责堆成引用名称。
- 需要建立状态条目的场景、源视频和关键道具，名称与下方标题逐字对应：上面“办公室：【@图片5】”，下面“办公室：……”。引用区不列书桌、主椅、门窗位置或人物服装；普通人物参考默认无需同名状态条目。多个同类场景用短而唯一的名称区分，不在正文临时换简称。
- 只保留用户实际提供的素材，不虚构编号。缺少本段所需角色、场景或道具时，先在正文外说明缺项与用途，用户补齐后再绑定；未经同意不加道具或把占位编号交付成可执行版本。
- 每个素材在参考区以简名绑定一次，源视频同样只绑定一次；场景、源视频和风险道具的必要职责在下方同名段写清，镜头正文使用固定名称或角色名，不重复`@`。模型与操作方法放在顶部制作设置，不能因此删掉视频所承担的连续状态。
- 不以“原视频已经出现过角色”为由自动省略用户要求的人物图。长时间延长、双人近景或身份稳定性重要时，若双方人物图均已提供，应分别绑定；用户专门提供的原始角色状态资产只负责该角色的特定状态，不能替代另一角色的身份参考，也不以成片截图冒充。
- 没有关键道具时，删除对应行，不保留空占位。未绑定素材且当前剧本和用户未要求的角色、群众、道具或环境元素，不建立状态条目，也不通过否定句主动引入。
- 同场复杂连续关系优先合格源视频延长，独立生成以原始角色、场景和道具资产重建。不上传首尾帧或成片截取的站位图，改名“衣装/状态参考”也不例外；这些截图只作内部审片。跨集按相同标准判断。
- 独立换场且无素材依赖的任务可以并发；需要前段实际成片的任务明确标注等待关系。素材无论来自哪一集，都不替代当前事件的自包含描述。
- 源视频负责已在场角色的起点，不限制本段只能有旧人数或旧站位。新增人物有明确来向，移动有过程和新落点；用近距离多人景、过肩或必要短暂放宽交代新关系，不默认拍全屋大远景。
- 两张场景图来自相反观察方向时，逐张绑定到具体摄影方向和镜头，不能笼统写成共同负责整个空间。车辆场景还要按车辆前进方向标记驾驶位、乘客位和后排座位。
- 参考完整表达的外貌和场景不在正文重复描述。
- 一张图包含多个状态时，明确本次只参考哪一个状态；剧情关键时优先拆成独立素材。

## 4. 镜头规则

- 编号默认意味着真实切镜。一次有动机的快速摇摄或甩镜若从一个主体迅速落到另一个主体，为了写清执行节拍，可以把落到新主体后的部分另列镜头号，但必须标明“连续快速运镜、无剪辑”。
- 海外旁白短剧最低真实镜头数按“总时长除以3后向上取整”：16秒至少6镜，20至21秒至少7镜，22至24秒至少8镜，25至26秒至少9镜，30秒至少10镜。
- 海外旁白短剧普通编号镜头原则上不超过3秒。先按动作进度、语意转折和直接回应选择切点，再核对镜长与最低镜数；切到听者、局部证据或关系机位须增加可读的反应、信息、感受或视觉联系，不只换角度。泪点、认知击穿或关系余波需要完整读清时，可以使用约3至4秒的动态情绪镜头，期间由缓慢推近、轻微横移、弧线调整、移焦或人物内部变化持续推进。
- 高压段落若包含发令、逼近、发现、接触和即时反应等多个可分离焦点，主动使用若干约0.6至1.2秒的有效快切；若高潮依赖一句不可打断的对白、连续接触或单人表演，则用较少镜头在镜内完成语气、面部和身体变化。连续两个超过2秒的镜头若没有完整对白、必要情绪落点或新状态，必须重排。快速变焦、快速推近和快速拉远只强化明确节点，不能冒充真实切镜。
- 普通叙事或时间蒙太奇以每镜约1.2秒或更长作为可读性起点，切入先读清新状态再切；重要表情、文字和动作结果可更长，不套用高压局部快切的节奏。
- 同一连续动作先设计到3秒内完成，不为凑镜头从运动中途拆开；确实装不下时简化动作，或只在到位、接触完成、落地等稳定因果节点切开。
- 连续动作跨快切时，后一镜必须接住前一镜已经开始的步伐、转身、抬手或失衡，不得形成“走到位—罚站—重新蓄力—执行”；承受者一旦察觉威胁便立即作出符合人物的预警、护挡或闪避反应。
- 只有真实剪辑切点计入最低真实镜头数。无剪辑快速摇摄即使另列执行镜头号，仍属于同一条连续实拍；普通一镜到底、推拉、横移、变焦和移焦不另列镜头号，也不能代替整段真实切镜。连续动作完成后，可硬切到对方反应、局部证据或新的关系机位。
- 遮挡或甩镜中的真实剪辑仍计为切点，单纯模糊或镜内移动不计入真实切镜数。特殊运镜与转场按剧情选择，不是必填栏目；写清触发、运动起终点、是否剪辑和落稳后的可读信息，不另出技巧试拍版。整集通常只保留约2处，明显更长时最多约3处，其余用干净硬切；轮换动作/构图匹配、声音桥、光线变化、焦点接力和情绪反差硬切，不连续只用遮挡。
- 过肩镜头必须写清从谁肩后拍谁，以及俯拍、平视或仰拍。表现强者压迫时，可从强者肩后俯拍弱者，或从弱者肩后仰拍强者。
- 持续亲吻、拥抱等长动作，先辨明情绪、回应或亲密程度怎样推进，再让关系景、接触局部与双方独立反应承载这些变化。接触可以持续，有任务的停顿可以保留；切镜须增加感受、关系或视觉联想，不按镜位清单轮换。
- 每镜只保留一个主要注意力路径和一种主要运镜。
- 四人及以上的多人场景默认不使用大远景或全身全员镜。每镜只让1至3名当前关键人物清楚对焦，其余角色用肩部前景、门框、摊位、课桌、画框边缘、进出画和浅景深分层出现；建立空间也不能把全部人物并排摊开。只有用户明确要求完整阵型且已有可靠站位依据时，才短暂放宽。
- 重要事件后给反应，不让下一条信息立刻覆盖。
- 多镜头段落不要求所有镜头都拍人物。可加入一次有叙事任务的场景局部、建筑细节、道具或陈设特写，用于转场、建立空间、承接关键词、制造视觉隐喻或重置观看节奏；不能作为无意义填充，也不能挤掉关键人物反应。
- 打斗段可在进攻、格挡、反击、失衡、旁观者反应和被波及的环境道具之间连续快切。杯子摔碎、瓶子滚落、桌面被撞翻或帘幕被扯落必须由可见动作触发，损坏与位移状态在后续镜头保持。
- 时间范围用于分配节奏，不做毫秒级机械控制。

## 5. 内部旁白对齐与正文声音

- 当前只在Codex内部对齐旁白节奏、意义与画面切点，不将旁白原文逐镜放入提示词；正文不附旁白时间轴、对应关系或校准说明。
- 正文只调度本次需要Seedance生成的现场对白与其他声音。内部核对现场对白窗口与后期旁白不冲突，不让人物对旁白做口型；自然呼吸和合理口部活动保留。
- 现场对白写清准确原文、说话者与起止窗口，跨镜不重复朗读。新旁白制作方法待用户另行确认，不预设旧法继续有效。
- 角色开始现场对白时，先用正面、三分之四正面或明确关系的过肩镜头保证面部和口型可读。
- 长台词可跨说话者、听者、道具和关系镜头，但声音不中断、不重启。

## 6. 正向描述优先

只为当前素材和动作的真实高风险错误保留必要约束。能用起点、动作和终点说清楚，就不再堆禁止项。

局部修正用新的正向动作或落点替换旧句，并删除其他栏目的同义限制；不能在原指令后追加“不要做原指令”。人物只是压住冲动时，写观众实际看见的眼神、呼吸、声音或距离变化，不把未发生的攻击动作写进正文再否定。

成片出现问题时，先定位具体镜头和句子，判断缺的是动作触发、表演、站位、物理结果、机位、资产还是声音。以当前可用版本为基线，在既有事件、动作顺序、空间与道具链内修正；增强情绪先调整相关人物的回应，改善节奏可压缩重复准备与等待，不自动改全员走位或接触。用准确的正向描述替换问题句，并删除其他栏目的同义说明；不因局部错误整稿重写。若修法确需改变分段、剧情或用户已确认拍法，先说明具体依赖与分歧。

错误示例：

```text
此时不要出现下一段的巨龙，也不要让人物提前离开。
```

正确示例：

```text
画面停在人物抬头看向逐渐变暗的天空，双脚仍留在原位。
```

## 7. 最终检查

检查在Codex内部完成，只从头到尾顺读一次，不另写检查表。先看连续画面怎样推进，再核对镜数与执行：

1. 用户确认的剧本内容、情绪落点和画面设计是否都有对应镜头，且没有擅自新增剧情；连续几镜合起来是否推进了行动、信息、情绪或关系，而非只轮换机位。有任务的停顿与视觉联想可以保留，不要求每镜新增剧情。现场对白逐句对照当前采用原文核对完整、顺序、说话者与对象，再将【声音时序】和同时间的镜头并读；长句跨镜连续，重音、必要停顿及动作留有可读时间，不靠加速念词凑时长，句末不被切段截断。
2. 人物来路、动作触发、接触与受力结果是否清楚；相邻镜头的站位、朝向、持物和动作阶段是否连续，跳时或换场是否重新建立当前状态。
3. 实际素材是否完整绑定；镜头节奏、现场声音、必要画面文字和全段无BGM是否符合当前项目；摄影段只保留本段真正影响成片的全局要求，不复制无关套话。
4. 同一信息是否只出现一次；状态段只写跨镜事实，表演只写在发生的镜头；导演分析、失败历史、未来计划、未采用动作和重复限制是否已经删除。

审看有现场对白的成片时，听检漏词、重复、抢拍与句末截断，并比较实际说话进度和画面落点。提示词写齐不等于成片说齐；只检查文本或抽帧，不标记音轨通过。

发现问题只精准修改对应镜头或栏目，并保留其余已经成立的内容。只有当前片段确实涉及手机、车辆、亲密动作、打斗、群众、视频延长或多场景时，才读取相应专项规则。现有提示词栏目、顺序与逐镜节奏保持不变。
