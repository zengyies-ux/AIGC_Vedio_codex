# Seedance 提示词模板

> 本文件只维护既有输出骨架、信息归属与一次成稿检查。素材/表演/声音等查[执行规则](execution_rules.md)，接续与返修查[接续规则](continuity_and_review.md)，导演选择查[导演流程](director_os.md)。不把这些方法再扩写为模板栏目。

## 1. 从当前采用设计直接落稿

已有正式稿且本次进入网页执行／续做时，直接按[交付与续做](continuity_and_review.md#execution-handoff)补最少执行事实；不因模板升级重排已采用正文、重走导演或音频转写。下面用于本次确需新写／补写的提示词。

当前采用的解读、分段和用户明确画面是蓝图；采用依据按[声音与时间](execution_rules.md#sound-and-time)区分验证模式的一次整体确认、本任务自主授权及长期常规模式的内部核查。继承画面意图和制作边界，按[三步导演判断](director_os.md#script-design)落实本段具体表演、空间因果、轴线/站位、镜头、声音和实际资产绑定，再写现有栏目；不把转译当机械复制，也不重开整轮解读、多层导演卡或大量备选。总预算、必要增量和余量按[声音与时间](execution_rules.md#sound-and-time)处理并同步受影响对应，不另行放宽本段或整集。内部推演、未采用方案、失败历史和验收推理不投喂模型。执行问题只回查受影响部分；按[素材必需性](execution_rules.md#references)判断的真实缺口在正文外标待补；解读规划与无关提示词继续，受影响正式绑定等待补齐核看。

## 2. 制作设置与可复制骨架

文件里的正式正文保留唯一明确边界：下述text代码块，或“## 唯一可复制正文”章节。检查工具支持这两种现有形式，不把格式错误误报为已完成结构核查；制作设置不混入正文。

保持以下栏目顺序与逐镜粒度。除用户明确要求，不改成摘要、表格或另一套正文；局部改稿保留完整摄影和声音边界。单段与整集合辑都分开制作设置和正文。整集合辑在正文外沿用[采用分段表](director_os.md#segmentation)，保留原文覆盖、画面任务、时间对应、生成方式与依赖；需要时在画面任务中补主情绪承载者与变化、必须兑现的回应/余波及分段理由，不逐段重复操作说明，也不另写混淆原音轨和成片的“全局区间”。

以下供用户操作与核对，不复制进Seedance：

```text
制作设置（不复制进提示词）
采用输入：当前剧本／目标集原文、音轨版本与音频采用依据链接；已核看真实资产
采用方案：集中确认记录 / 本任务自主授权或已启用常规模式及内部核查记录
执行范围：只出提示词／只填稿用户生成／授权AI生成及本次依据；与自主前置分开，最新明确范围优先
整集预算：原轨实际A、提交素材G、可剪余量R＝G−A及当集最新额度；按唯一时间政策，链接采用分段
模型：当前选用模型与版本
方式：独立生成 / 视频延长［视频参考与平台延长分别记］
源片：所选实际文件／平台结果标识与采用依据；延长源须原生，普通首次核尚未延长，授权返修另记替代候选关系及原修正次数；无依赖写无，未知写未知
镜头边界：本集真实单镜上限及适用依据；快节奏旁白短剧按执行规则核查，不按对白长度定镜长
正文时长：X秒
本次生成时长：Y秒［平台可选整数；延长时指新增时长，源片已有长度另记，不用延长输出总长填此处］
时间对应：原音轨区间/原文范围 → 本段生成局部镜头与对白窗口；采用分段文件
可剪余量与必要增量：本轮实际制作范围分得的余量、本段可裁位置、时长及裁后接缝；句前／句间余量的声音窗口位移，取整计入整集R；不可删的增量另记
剪辑对应：旁白与替换对白的计划位置；明确锁定节点［未实际剪辑时标计划，无锁定则写无］
交付条件与调度：只出提示词区分正式文本／完整预排待校准与真实缺项；网页范围另记源确定、绑定回读及可执行，网页不适用项不阻塞文字交付
角色映射：人物A＝@图片1；人物B（本段状态）＝@图片2
实际操作（仅网页范围）：真实URL／卡ID、语义节点映射、已选模式与目标整数秒、当前正文／引用回读；生成授权内另记提交与结果，未知如实保留
```

“角色映射”单列，只含角色，不混场景/道具；与参考区编号一致。日常、受伤、家长会、回忆等状态写在名称中，避免@图错配。时间对应按实际需要简写，但保留原音轨来源、调整后局部窗口和计划剪辑关系；分清句前移动、对白时长扩展及后续影响，必要变化附一条短剪辑说明。采用分段已记录的内容可链接，不另建声音台账或一套时轴。模型、方式、调度、缺素材、剪辑计划与未来制作目的留在此处或项目状态，不能进入可复制正文。

<a id="text-delivery"></a>
### 只出提示词的资产名称索引与交付

按指定EP／片段编号交完整正式正文及文件链接；同一集多段可在已有prompts位置给完整合辑，不只交摘要或待源说明。每段在正文外列最小资产对应：**参考简名 → 真实文件名／本地路径 → 本段用途与状态 → 正文预设@编号**，含实际用到的角色、场景、道具；同图复用现有资产记录，不复制图片或另建用户配置表。预设@图片／@视频仅供用户在平台手动选择，不代表已上传、绑定或生成；编号须有真实资产对应，缺源的@视频例外列计划源段名和待实际源校准，不编造文件或媒体ID。资产路径不放进生成正文。

只出提示词不执行网页节点／URL核对，未绑定不报整个任务未完成。声音、原句、镜长、预算和设计检查照常；轻量检查器只核结构／数字，识别到@文本不认证真实绑定。源未有仍保完整预排镜头、台词、摄影与参考计划，待校准说明在正文外。

以下为可复制骨架。示例适用当前海外9:16旁白真人短剧；拟人动物替换题材与生命感，声音与栏目仍按[动物专项](animal_city_motion.md)。明确采用的大量现场对白模式不套用旁白密度，但不因引号台词多自行切换模式或解除预算，见[专项边界](live_action_dialogue_drama.md)。删掉未使用的素材/状态行与方括号说明；预设编号与真实文件对应明确，不伪称已建网页节点。

```text
【生成任务】
生成[整数时长]秒、9:16竖屏、电影级真人短剧视频，共[真实镜头数]镜。[简短写本段开场、核心事件与结束画面。]

【人物与场景参考】
人物A：【@图片1】
人物B：【@图片2】
办公室：【@图片3】
手机：【@图片4】

[只列本段确需的参考，不复制整集全员清单；本段后续出镜者仍须绑定。删除此说明。]

【空间与道具状态】
时间：[每个场景/回忆的白天、下午、黄昏、夜间或午夜；窗外天空、城市明暗与室内主光源。]
人物持续状态：[仅写跨镜必须保持的伤势、持物或特殊状态；无必要则删，不常规列眨眼、呼吸、重心等微动作。]
办公室：[固定门窗、入口与通路；本段相关人物的开场位置、朝向、距离及必要接触。可用“A面向门，B在A左手侧靠桌”等有参照的短句；每条独立正文写当前必要关系，不只写“沿用上一段”。不要求开场全景或逐镜全员入画；画面左右属于机位，不代替人物相对方位。]
手机：[持有人、手位、屏幕朝向与跨镜状态。]

【声音时序】
[每次现场发言用：局部时间窗口｜说话者→对象｜完整台词原文｜最短必要声音表演。完整原文只列一次，剧本同文重复句按原顺序和次数保留。跨镜沿当前词句继续；关键等待由画面行为承载，不逐个列微小间隙。无对白或特殊声音调度时可删除本栏；不写旁白原文/校准说明。]

【镜头设计】
[按已选拍法说明真实剪辑边界与必要连接，不统一填“均为硬切”。动作匹配、视线或声音接力写在相关镜头；匹配／遮挡转场成对写切出与切入。镜内移动不算新增镜头，无剪辑区间整体核镜长。实际有反打时，说明机位保持已建立关系轴同侧，画外人物承接既有位置或已开始的行动；无需要则删除。]

镜头01【0.0-X.X秒｜景别、角度与固定／主要运镜】
具体画面：[写当下这一组关系的关键人物与动作目标，用自然短句表达带有对象和态度的行为、直接回应／结果，承接原文含义。近景具体到需要的脸、胸腰或接触；其余人沿整场位置延续，不为入画挤在一起。切入接前镜尚在发展的行为与情绪，关键反应读到自然阶段后再交出注意力；简单动作不拆手脚步骤，只有关键交接或具体穿帮补最少细节。]
现场对白：[写本镜与连续声音窗口交集：谁画内／画外，在本镜开口、继续或收尾。句首早于本镜则写“画外持续”或“接续同句”，不能把之前的开口时点写成本镜开口。声音区完整原文只列一次，跨镜不断声、不重念。]
声音：[本镜同步的动作声/环境声；无需要删除，不重复全段边界。]

镜头02【X.X-X.X秒｜景别、角度与固定／主要运镜】
……

【摄影、光线与真实感】
[完整保留当前项目指定设备/镜头成像参考、胶片类型与颗粒、影调、柔焦、景深、肤质眼神光及正常速度运动模糊。时段服从空间状态，光源方向明确，关键脸、接触与多人关系可读。统一成像不覆盖逐镜已选机位与运动，也不统一人物态度和表演强度。]

【声音与画面文字】
现场对白及剧情文字语言：[当前采用语言]。
[本段每位实际有对白／OS的角色各一条：角色名音色：声线性别、年龄感、音区／质感、语言口音；跨段复用本剧同一基线。本段情绪只改语气／力度，不换声音身份。无发言者不列。]
[OS／画外音及闭嘴要求另写，不能代替上面的音色；不能只写“沿用前段”。]
保留[本段需要的呼吸、动作与环境声]；全段无BGM、配乐、背景音乐，包括低量、短片段、场内音乐及源视频音乐延续。明确设计的快速变焦可用一次短促非旋律音效，不铺底、不盖台词。
[剧情必需的手机/文件文字由Seedance直接生成，内容写在唯一承载处。无剧情文字删除此行。] 不加额外字幕、解释贴字或水印。
```

正文【生成任务】不写模型名、正常生成、是否延长或平台命令。已有角色名直接替换人物A/B；普通角色不另写身份说明书，角色图之外确需持续的伤势、持物或姿态才补一句。

<a id="information-ownership"></a>
### 正文信息归属

| 栏目 | 主要归属 |
|---|---|
| 【生成任务】 | 生成时长、画幅、真实镜头数与本段事件 |
| 【人物与场景参考】 | 本段真实素材的固定简名和预设@编号；网页范围另核实际节点 |
| 【空间与道具状态】 | 时间、固定结构、开场关系与跨镜持续的接触、持物、伤势/道具事实 |
| 【声音时序】 | 现场台词原文、对象、窗口及必要声音表演 |
| 【镜头设计】 | 当下动作、表演、反应、拍法与落点 |
| 【摄影、光线与真实感】 | 全段统一成像要求 |
| 【声音与画面文字】 | 本段发声角色稳定音色、发声方式、全段声音边界和剧情文字要求 |

同一事实只写一次，状态段不是第二份逐镜脚本。角色怎样看、走、笑、呼吸只在对应镜头；整段目的、情绪弧、备选、风险推理留内部。剧情短句原文选一个承载处列明，不在文字区、状态段与镜头多次抄写。

实际落稿先沿原轨连续旁白含义与台词顺序组织场面，再从持续行动和回应选择镜头；整个意义区间要有相应的证据、因果或情绪承接，不能仅首尾关键词相符。旁白含义与画面任务的对应留原有分段／制作设置，不另加正文旁白栏。【声音时序】保留连续现场声轨，核每镜开口／继续／收尾与画内外状态；不得一行台词对应一镜。随后回填真实参考、最短状态、完整摄影和声音边界；最终仍按上列顺序输出。只服务一个镜头的信息留该镜，多镜共同依赖才上提。

逐镜标题填写已为当前行动／回应选择的拍法；固定与有动机的运动均可，模板或脚本不代选统一机位、运镜、切法或均分秒数。标题的“近景”须兑现本镜需要读的脸、对象或关键接触，状态栏名单不等于每镜出场名单。已采用的匹配、遮挡或情绪呼应须把两端必要状态写入正文，不能只留解读里的技巧名；正文仍自包含，不写“见方法库”让模型自行补。画外开口按[声音规则](execution_rules.md#sound-and-time)写现场状态，不为句首另改取景。制作设置与唯一正文直接交执行者，素材绑定及续做沿[交付分工](continuity_and_review.md#execution-handoff)，不另造导演稿。

### 使用源视频时

```text
【人物与场景参考】
厨房源视频：【@视频1】

【空间与道具状态】
时间：夜间，窗外黑夜与城市灯点，室内由原有环境灯照明。
厨房源视频：只负责开场实际站位、身体接触与道具状态。从视频末尾已成立的距离、肩线和牵手开始；随后行动与新落点写在对应镜头。
```

这段不替代已有且必需的人物/场景图。生成方式、截图范围、一次延长与真实源片核对见[接续规则](continuity_and_review.md#generation-choice)；不另造【视频延长任务】栏目。

当前平台延长正文必须在参考区列固定源名及`【@视频N】`，同名状态说明其实际接续职责；不能因进入延长入口省略。文字编号是预设。只出提示词缺源交完整预排、标待实际源校准／人工绑定，不为取得节点进入网页；网页执行时源／节点未落实标待绑定、不可提交，回读须证明正文节点和选定源相同。页面没有可核节点时保留阻断，不改成免引用可提交。

## 3. 参考区规则

按[执行规则：素材绑定](execution_rules.md#references)填写，保持简名与同名状态标题一致；缺口在正文外同步。反向场景图、车座、俯视图只在涉及时读[空间规则](execution_rules.md#space)。

## 4. 镜头规则

按[执行规则：镜头与切点](execution_rules.md#shots)核对真实镜数、镜长、相邻切出／切入、动作容量、反应、过肩与运镜；不从模板栏位反推剧情。具体转场与情绪拍法在导演设计时选定，正文写选定的触发、切点与可读结果。

## 5. 内部旁白对齐与正文声音

按[执行规则：声音与时间](execution_rules.md#sound-and-time)调度。原音轨含旁白和角色台词，GPT核定并定位的现场对白在正文中生成，后期替换对应原台词，旁白由后期编排；不能再把对白整段加到原轨总长上。旧绿标可作兼容依据。原音轨全局、本段生成局部和剪辑计划分别映射，原旁白与剪辑对应说明不进入正文。声音栏按短格式列完整原文一次，镜头承接同一窗口的等待、开口、继续和收尾；镜内开口写明局部时点，跨镜不截句、不重念。候选区间或旧标记不自动成为锁定节点；当前整集预算和用户明确上限仍须遵守。

## 6. 正向描述优先

能用起点、动作与终点说清楚，就不堆禁止项。只保留当前真实高风险约束，精准返修见[接续规则](continuity_and_review.md#review-and-repair)。例如不用“不要出现下一段巨龙，也不要提前离开”，改写“人物抬头看向渐暗天空，双脚仍留原位”。

<a id="final-check"></a>
## 7. 一次最终检查

羞涩核自然肤色与关系反应：不写发红、耳尖泛红或渐红；确有需要最多“微微皮肤润红”，不堆机械小动作。原句与可复制正文照常核对，成片声音默认不审，不向用户要求试听确认。

与[导演成稿核对](director_os.md#final-director-check)在同一次整体顺读中完成，不再另跑检查链或输出内部推理；顺读时沿相邻镜头核[切出／切入](execution_rules.md#shots)是否重复画面硬切、[动作阶段与移动依据](execution_rules.md#action-physics)是否接得上，只修问题镜头与必要接缝，不增加成片逐镜审查：

从本段【声音时序】提取实际发声者，逐一核【声音与画面文字】是否有其明确音色、是否与本剧基线一致；性别、年龄感和语言口音不能缺，OS不算音色。无对白段无需补声线。此为正文检查，不触发成片听检或用户确认。

1. 以实际通读完整剧本后核定的目标集原文及用户明确采用改词为依据，双向核对：从原文到正文查漏句、改词、身份、次数、顺序及说听对象，同文重复句保留；从整份可复制正文反查每句可辨话语的原文来源，包含镜头内临时呼喊、命令、OS及环境人声，不能只查【声音时序】或“原句都还在”。双引号通常是对白线索，仍按语境区分现场话、转述／引用、内心话与剧情文字，不把所有引号自动变成发言。行为要求不授权新增台词，补救援／指挥等表现优先落实为动作和直接回应。原句比对不得靠删词、改人名、否定词或同义改写来通过；排版空白／引号形式的比对处理不改写源文，音频工具的受限匹配也不证明说听归属或剧情理解。声音窗口与各镜开口／持续／收尾一致，画外开口合法，实际入画才核口型；同一角色发声与沉默不重叠。按原轨意义顺序看整组镜头是否持续承接用户事件、指定画面和旁白：具体新条件／人物／因果不能仅靠泛表情代替，不以某个词对应一帧当整段合格。
2. 以下为主控内部核查，不逐项复制进正文；从整场锚点和开场位置顺读到必要移动的实际落点，核人物来路、触发、接触/受力、朝向、持物与动作阶段；换机位只改变观看方向，不能凭屏幕左右重排人物，跨镜移动继承同一次动作；交叉核对剧情阶段—采用图可见状态—正文—实际源，[素材冲突](execution_rules.md#references)的处置须实际落实，不能只写遮挡就放行。跳时/换场明确重建；接续按合格源片实际末态，不能拿计划代填或继承已知错误状态。
3. 按[声音跨镜](execution_rules.md#audio-shot-independence)核真实切点、连续覆盖与单镜上限；在同一次顺读中，将逐镜标题和具体画面对照：取景能否容纳当前关键脸、动作目标与决定含义的接触，听者的回应是否真的入画，连续表演是否体现人物此刻的选择，放宽或运镜是否帮助读清当前变化。只列“近景、保护、震惊”等词或在状态栏写齐关系不能替代画面证据；隐藏剪辑展开。按[预算规则](execution_rules.md#sound-and-time)核A／G／R、整数及多个具体可裁位置，裁后完整声音／事件与接缝成立；素材、现场声音、剧情文字、无BGM和完整摄影一致。调整只同步受影响分段／窗口／依赖及全部相关下游镜头；未剪辑仍标计划。必要时用[轻量检查](../../tools/prompt_review/README.md)，其结构／预算结果不认证画面或余量实际可用。
4. 制作设置、素材索引和提示索引确定唯一当前稿、方式、整数时长及依赖；延长正文有同名源视频引用和状态，正文完成不等于源确定／绑定齐备／可执行。仅填稿不写生成回执。删除正文中的重复、旁白／后期调度、原文段落编号、抽象主题、失败历史、未来目的、未采用动作及否定清单。状态只留跨镜事实，表演留实际镜头。

结论针对本次实际交付文件；只改有问题的镜头或栏目，返修后只复核受影响内容与必要接缝，不把无误内容退回重设计。文本通过不等于成片通过，需审片时按[成片验收](continuity_and_review.md#review-and-repair)记录画面、音轨与未知项。项目完整提示词写入对应prompts文件并更新INDEX；只出提示词按[文本交付](#text-delivery)给分集分段完整可复制正文、文件链接与资产名称索引；网页任务默认给链接、版本变化、素材缺口与必要风险，用户要求全文时再内联。
