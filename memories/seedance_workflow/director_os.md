# 从剧本到 Seedance 提示词

> 本文件维护导演判断：事实、人物目的、可拍事件、情绪、功能场景与分段。具体执行查 [execution_rules.md](execution_rules.md)，生成依赖查 [continuity_and_review.md](continuity_and_review.md)，落稿查 [prompt_template.md](prompt_template.md)。按当前阶段读取，不把本文件变成每段必填表。

## 1. 工作目标

把当前剧本、用户画面想法与本次素材转成一个清楚的观看效果、一条自然的画面流程和一份自包含提示词。剧情正确、连续性与表现力同属初稿设计，不能先排镜头，再靠质感词、模型或后期补情绪。入口和当前依据恢复路径见根 [AGENTS.md](../../AGENTS.md)。

<a id="script-design"></a>
## 2. 先确认当前片段要让观众获得什么

先读整段，区分必须发生的可见事件、必须保留的现场台词，以及旁白承担的信息或心理。比喻不自动变成物理事件，台词字面意思也不等于真实目的。内部形成简短判断，不让用户另填表，不把推理原样投喂：

| 判断 | 要看清的内容 |
|---|---|
| 发生了什么 | 起因、顺序、结果；不可改的动作、台词与设定 |
| 谁知道什么 | 已知、误信、隐瞒、刚发现；可察觉线索与观众信息差 |
| 观众站在谁一边 | 主要POV；观众知道更多、相同还是更少；共情、怀疑或施压的观看位置 |
| 对谁、想达成什么 | 求确认、逼迫、掩饰、拒绝、试探、保护；对象是否中途改变 |
| 可拍事件 | 哪个动作结果、选择、环境或关系变化证明本段剧情发生了 |
| 关系怎样改变 | 谁原先掌握主动，哪个事件动摇它，结尾谁获得或失去选择；平静段也有信任或欲望变化 |
| 表演怎样接力 | 发起者、直接承受者、最受影响关系人的行动与回应，谁放大后果 |
| 观众应感到什么 | 期待、愤怒、快意、心动或不安具体来自哪个变化，最值得记住的时刻在哪里 |

只能概括成“他们对话”，却说不出观众最后看见什么变化，尚未压成可拍事件。只看拟定动作和反应、不读导演解释也应看懂关键变化；解释若依赖剧本没有的秘密、道具或动机，回到当前材料。

通读整集先锁定情绪主峰，普通节拍准确推进。施害、霸凌或压迫要由针对具体对象的恶意行为和可见承受证明；剧本随后确有反抗、保护或救赎时，再安排兑现与余波。逐级拉开反差，不把所有恶行堆在一段，也不提前发明救援。情绪曲线的选择见[第8节](#emotion-and-rhythm)，表演落画见[执行§7](execution_rules.md#performance)。用户标出的强弱和方向优先；未标注处仍由Codex主动补齐。

### 两种剧本入口

- **用户主导拆解**：收到初版理解、时码、画面想法和重点情绪后，仍通读当前剧本、找主峰、补可拍因果。保留原文、英文台词、时码与已有括号批注，只在相关句段后新增简短中文`（导演补充：……）`，不改写用户批注。先交Markdown审核稿，审核后再分段和提示词；已确认的阶段直接继续。
- **Codex代拆**：用户中途接入、不想先读剧本或明确委托单集拆解时，通读当前完整剧本，沿用用户既有简短批注方法。补观众所得、人物目的、表演、镜头、转场及素材判断，不提前拆Seedance任务。默认只交Markdown，不制Word、不做文档渲染预览、不检查原音轨实际时长；用户明确要求时才执行对应工作。

相邻旁白可合成一个完整情绪节拍，不机械逐句配图；关键人物、证据或结果应在相应信息第一次到来时可读。拆解可提出剧本支持的回忆、平行画面、其他场景快切、已建立在场者反应或剧情道具，在同一批注中写用途和`需补资产`。新增权限边界见[第3节](#creative-boundaries)；候选经确认、素材齐全后才进入可执行提示词。只在事实、对象或拍法存在实质歧义时集中提问。

用户给详细批注或明确画面时，内部拆成事件顺序、说听对象、反应、速度/停顿、指定景别/运镜、对白与时码；每一项映射到具体镜头，再反向核对原话。不能只留下结果而弱化快切、快速变焦、强度或直接回应。

例如“我才是你的伴侣”可能先向伴侣争取确认，未获回应后才转向第三人。只提取“生气”会丢掉对象与关系变化。匿名例子用于判断，不带入新项目。

### 审核后再拆整集制作单段

先通看整集场景与动作怎样贯穿，再结合总时长、对白和完整事件提出自然切点，不边生成边临时找边界。用户时码是叙事节拍，不自动成为生成边界。分段基本单位是能兑现的戏剧单元，不是“约30秒”。

1. 每段明确一个主要剧情任务和主情绪对象，以及刺激、直接回应、关键关系人、高潮、实际开场与动作落稳后的结束状态。其他人放大主命题，不争夺中心。
2. 保护完整台词、动作链及第一轮关系后果，先核算正常发声、换气、动作与反应需要的时间，再安排走路、取放物等准备。
3. 问候选切点：下一段能否凭原始资产建立清楚首帧，而不依赖上一段未知的站位、接触、持物或动作阶段？不能则合并或保留合格源片依赖；同地点明确跳时则重建当前人物和状态。生成方式与当前约束见[接续§3](continuity_and_review.md#generation-choice)。
4. 分清原旁白时间、生成局部与最终剪辑时间，不能直接用前段生成长度去减原旁白时码。完整换算及17/19/24.5秒实例见[执行§8](execution_rules.md#sound-and-time)。
5. 边界落在完整现场对白或明确语意单元之后，不切断伸手、掌击、抓握、转身、递物、转屏等连续动作；关键刺激至少获得一个直接回应，位置、头眼、接触、持物与衣装落稳。任一项不满足就移切点，不用“后段补反应”掩盖缺失。

### 情绪加时与对白授权

旁白区间与已确认的画面分段不是绝对时长。重要情绪点缺少可读行为、承受反应或兑现余波时，可主动多设计约2至3秒，例如20秒变22至23秒；确需更多时按剧情调配。新增时间必须增加证据、表演或关系结果，不靠重复镜头、慢动作或静止表情填满。

用户可在剪辑软件调整旁白；同步重算生成整数秒、受影响旁白与未锁定时码、相邻段起止、真实镜数和依赖，并核对当次平台上限。已锁定现场对白或同步节点不自动后移，冲突时说明具体窗口。

剧本标注对白不自动等于硬锁。已获准按成片调整台词与字幕时，可按完整发声、换气、动作和听者反应延长或平移窗口，统一列明新全局/局部映射，不逐句再确认，不以快读、吞词塞回旧标。台词原文、顺序、对象保持准确；字幕由用户按实片对齐。例如纯现场对白原估5至6秒，完整自然发声、换气和回应需要约10秒或更多时，可按已有授权扩展，不被原旁白秒数机械限制。生成余量与有效加时分开计算，见[执行§8](execution_rules.md#sound-and-time)。

### 3段与4段怎样选择

整集定稿前比较有依据的候选段数；下面3段与4段是常见例子，不是固定配额。比较时问：这一段抽坏，要重抽哪个情绪/动作单元，是否会拖累已合格前段？以首抽加返抽的预计总成本、失败波及范围和串行依赖深度判断，不以少一段表面省一次生成或未经核实的积分换算作结论。

| 优先比较4段 | 保持3段 |
|---|---|
| 一个长段有不同人物承担的两个独立高潮，都需前摇与余波 | 同一人物情绪弧和同一句对白连续升级，拆开削弱兑现 |
| 长对白、复杂接触、多人强反应争夺容量 | 抓握、受力、递物或转屏未落稳 |
| 高风险单元可在动作前或结果后独立，失败不推翻合格前段 | 第四段只重复信息或反应，无新主命题 |
| 新段有清楚主情绪对象、稳定首尾与独立返抽价值 | 新段仍继承大量未知状态，返抽范围没有缩小 |

先保证完整因果和情绪，再隔离风险；高风险本身不构成拆段理由。详细风险信号与群体视点案例见[方法库§23](director_patterns.md#segmentation-examples)。

镜头骨架可提前批量准备。拆后检查最短生成依赖：换场、跳时、稳定重建或不继承核心接触的功能视点可并发，真正继承末态的片段等待合格源片；当前一次延长限制由[接续§3](continuity_and_review.md#generation-choice)维护。并发与依赖写入提示词外制作设置，格式见[模板](prompt_template.md)。

<a id="creative-boundaries"></a>
## 3. 区分不能改与可以设计

**不可擅改**：关键事件及结果、人物动机、台词对象与知情顺序、用户指定动作顺序/画面，以及已成立的角色、道具和空间状态。

**在既有范围内主动设计**：景别、角度、焦点、切点；人物有目的的表演、反应、互动与走位；已建立或已获准群演的层次和环境反馈；有动机的转场、现场声音与结束构图。明显表情和较大动作不是天然违和，不因怕穿帮退回全员罚站。剧本已确立、没有新增事实且素材齐全的短暂回忆也可直接设计。

若新增场景、人物、剧情性道具，或改变因果、关系、知情顺序、后续状态的事件、未确立往事或小插曲，先在拆解稿提出具体用途、拍法、连续性影响与素材缺口，用户确认并补齐必要素材后进入提示词。既有情境内的翻身、停步、回看不逐项请示。

开放构思发生在拆解、分段和选镜阶段：先形成最有效方案，高点、长单一事件或确有更好拍法时再快速比较第二方案；随后按[执行§4–7](execution_rules.md#space)核对可执行性。被否决时换成同等表现力的方案，不默认回到静止中景。同项目必要时利用当前采用记录快速扫最近2至3集高频语法，避免换角色重复签字、门禁、证件或遮挡；不为此自动加载全部历史。

## 4. 什么时候问用户

画面明确或只有一种自然拍法时直接完成；叙事意图明确后的运镜、转场和细节由Codex定一版正式设计，不为每个技巧再确认或另出试拍版。

只问影响结果的具体缺项或冲突：不同拍法会实质改变未明确的叙事/审美方向；缺本段必需角色、场景、道具或屏幕素材；要求与参考空间/物理连续性相冲突。说明用途或最小修正，不把导演责任退回用户。明确获准直接描述的素材例外按授权执行。

<a id="functional-scenes"></a>
## 5. 先选功能场景，再读真实空间

先判断空间承担进入、交付、共看、阻拦、私谈、公开表态、等待，还是空镜的地点、时间、气氛、方向或转场任务。选能自然提供必要入口、锚点、道具和路线的简单功能场景；单张图优先承载一个主要功能、清楚主关系与主要路线。剧情必须在连续空间中完成多功能或多人关系时，压低次要路线；不为普通反打新增资产。不可逆状态会反复入镜时才准备状态变体。

整集先规划场景图承载的演绎区域，再拆片段；当前区域累计时长与拓展范围见[接续§3](continuity_and_review.md#generation-choice)，这是用户制作约束。相邻区域迁移须由人物目的推动，起步、跟随/留下与到达关系可读，无事件中段可省略；不同大地点可直接硬切或空镜。例：女主逼近、母亲面对她退让，把冲突带到新区域；一楼转二楼要有楼梯来路或上下楼依据。必要素材不齐就列用途和缺口，剧情无法合理转换时提出具体方案。

空间还包含行动权：谁可自由移动、谁必须等待、谁允许对方靠近、谁控制入口/出口、谁最终处于中心或边缘。权力与心理变化优先落成有原因的空间选择，不只解释表情。

内部只需看清：剧情功能、固定锚点、入口来路、主关系、行动对象和落点、道具归属、时间/天气/光源。实际空间、主轴与风险道具的执行描述见[执行§4](execution_rules.md#space)，不另填导演卡或重复空间说明。

### 人物目的先于表情

先判断“想让谁怎样→采取什么行动/说话方式→对方回应→自己如何调整”，再选脸、身体、距离和声音。优先使用剧本动作、现有道具和场景设施；没有合适道具时，距离、占位、视线或阻挡也能完成互动。

行动应改变距离、接触、道具、通路、对方判断或暴露态度；删掉后信息、关系与情绪都不变的整理衣服、悬手、摊手和抽象比划不选。例：一次拍证件、压章、合夹、推回资料或拉走物件，可把目的落成结果，再让被影响者接住；这些是候选，不是道具互动配额。

重要关系人要经历原有态度、察觉线索、为自己目的行动或忍住、得到回应后改变。关键刺激先形成“发起者进行中变化→直接对象即时回应→最受影响关系人选择→新状态”，具体表现交[执行§7](execution_rules.md#performance)，拍法案例查[方法库§22](director_patterns.md#performance-examples)。配角按事件职责进入焦点，不因素材齐全反复特写。

<a id="shot-language"></a>
## 6. 先在脑中播放，再编号镜头

已审核拆解是导演蓝图。正式提示词阶段做一次精简转译：从实际开场到结尾播放事件、情绪变化、动作因果和空间关系，核对时码与资产，再选择承载镜头并按[执行§5](execution_rules.md#shots)核对真实切点与密度。不得省略分析，也不重做整轮解读、展开大量备选或填写多层导演卡。

发现持续通话、亲吻、等待、阅读或工作跨多个意义阶段时，先找每阶段新的信息、关系、情绪或结果，不能只换机位重复表面动作。比较直接回应、局部证据、后果、有依据回忆/平行场面、真实空间迁移或已授权小插曲，见[方法库§19](director_patterns.md#selection)。切回要接住主事件实际进度，接缝按[接续规则](continuity_and_review.md)。

抽看连续约10至15秒：同一姿态、接触和状态只靠正反打撑时长，即使镜数达标也应重排。这是停滞诊断窗口，不是每10秒必须加动作或转场的配额。先推进当前人物行动与直接回应，再选有任务的局部、蒙太奇或视觉连接。

成稿只顺读一次：用户确认节拍是否全部落画，几镜合起来是否推进观看，人物来路与动作结果是否成立，接缝和最终状态是否清楚。发现问题只改对应镜头/栏目；正式栏目、素材与声音检查统一见[模板](prompt_template.md)。

## 7. 先选择节奏模式

海外9:16旁白短剧以持续更新观看入口为默认模式；先按剧情和信息差形成节拍，再用[执行§5](execution_rules.md#shots)核对密度，不能先凑编号再塞表演。换脸或换角度本身不等于推进。

真人大量对白剧按台词重音、说听关系、动作和停顿判断，暂不套旁白短剧镜数表；专项入口见[live_action_dialogue_drama.md](live_action_dialogue_drama.md)。

## 8. 快节奏仍要有情绪层级与记忆画面

开场及时进入异常、关系或问题，过程持续改变状态；关键证据、接触和反转台词读清，高潮后有直接回应。留人点来自信息差、危险、决定、情绪或未完成行动，镜头密度不能独立制造留人点。

普通段准确推进，主高点释放可读反差。高情绪段先理解“压住或伪装→具体刺激击穿→声音/身体显著改变→对象与关系人承接余波”；高潮不自动缩成微表情。泪点比较“克制或不敢相信→动作/物件/词句击穿→呼吸/声音/身体变化→关系承接”，除非剧本要求，不从开场一直哭。表演强度、动态情绪镜头与具体快切实施由[执行§7](execution_rules.md#performance)和[§5](execution_rules.md#shots)维护，选镜例子见[方法库§22](director_patterns.md#performance-examples)。

公开事件还应评估已建立群众是否能让后果可见，具体适用阈值、人数与接触/接续窗口由[执行§12](execution_rules.md#crowd)维护。

### 把值得放大的瞬间拍成具体画面

每段寻找已有变化：误解被戳穿、公开否认关系、危险逼近、保护发生或亲密被接受。铺垫也可留下明确期待，不制造剧本没有的反转。视觉创意不限于情绪爆点，现有动作、物件、形状、反射、入口、遮挡和环境运动都可成为记忆点。

先想事件后观众记住哪一帧，例如“曾逼迫别人的人等不到回应，落在关系构图之外”“证据露出，对手笑容停住”。再比较一项可由剧情改变的视觉变量：距离、是否同框、中心/边缘、前后景、入口/出口、门或道具状态、相机与人的距离。无收益不强行走位；母题只有随关系推进改变意义才成立。

随后比较直接呈现与一种具体方案：快速变焦、动作擦除、旋转遮挡、图形/动作匹配、反射揭示、焦点接力、光线变化或声音桥。选中的设计须提供态度、反差、触感、节奏、新观看体验或视觉联想，不一定新增剧情事实；若挤占对白、遮掉关键动作或无目的运动就调整。普通硬切更有力时直接用，仍明确切点。方法和候选镜头对见[方法库§19–21](director_patterns.md#selection)。

### 长段与整集的特殊转场评估

单段25秒及以上、或约一分钟以上整集，定稿前主动评估至少一个具体特殊转场或镜内视觉设计：时点、前后画面、现有资产与观看收益。已有方案同时满足段内和整集任务时不重复添加；适合就采用，未采用时内部能说出具体窗口、调性或执行条件，不能用“默认硬切”“怕穿帮”跳过构思。

整集通常选约2处真正有价值的特殊转场，明显更长时最多约3处，其余干净硬切；这是防技巧抢戏的默认密度，不是配额，也不限制有任务的表演、局部、蒙太奇或其他记忆画面。短段有合适机会也可用。轮换动作/构图匹配、声音桥、光线、焦点与情绪反差，避免长期只用遮挡。成对设计两端，跨任务依赖条件见[接续§3](continuity_and_review.md#generation-choice)与[方法库§20](director_patterns.md#transitions)。

依赖时效的文化/网络梗先核对当前语境；贴合人物与剧情才轻量采用，不为网感硬塞旧梗或抢素材权重。

## 9. 9:16 与旁白型内容

竖屏从纵深、高度和关系设计，不从横屏裁窄：肩部前景、门框、走廊、楼梯和局部动作可组织权力、亲密或疏离。具体构图/过肩执行见[执行§5](execution_rules.md#shots)，例子见[方法库§9、16](director_patterns.md#portrait-examples)。

旁白承担信息，画面承担证据、被评价者反应、道具/空间伏笔、未说出口欲望或互补反差。陈设局部只有承担空间确认、后果、关键词、情绪或转场任务才选；删掉毫无影响的装饰空镜不加。现场冲突尽量保留关键对白，让声音回到正在发生的事件；旁白内部对齐与正文边界见[执行§8](execution_rules.md#sound-and-time)。

心理旁白先转成可感知刺激、身体行为、即时回应与下一行动的小因果，不逐字照拍。例如“饿”不只摸肚子，也可在既有情境里辗转难眠、听到门外动静后改变注意力；具体行动仍服从本集空间和事实，若新增事件/道具/换场先作拆解候选。不能把情绪与动作一律缩小幅度。

## 10. 落稿前核对实现

导演选择先保剧情与表演，再落实实际资产、源片依赖及本段摄影适配；不用便宜模型把高潮拍平，也不因模型较强让单镜过载。模型观察查[model_behavior.md](model_behavior.md)，当前依赖查[接续规则](continuity_and_review.md)，声音/文字/摄影具体实现查[执行规则](execution_rules.md)。

观看复核先去掉情绪形容词并静音：只看行为、对象、表情与切点，能否认出逼迫、辩解、求证、嫌弃、保护或争取？主峰是否有刺激、结果和余波，关键证据是否及时落画，观众会记住什么？若只剩走来、站定、重复动作、轮流说话和皱眉，回到受影响的表演或选镜。随后按[模板的成稿检查](prompt_template.md)核对固定要求，形式检查不能代替观看判断。不把内部备选和验收推理复制进正文。

## 11. 成片反馈

精准返修与审片证据由[接续§8](continuity_and_review.md#review-and-repair)维护。文字反馈足够定位就直接修可用基线；保留有效情绪骨架，结构确有问题才说明依赖，不自动整段重写。

诊断时区分设计把错拍法写清、素材冲突、模型偏差和剪辑观看节奏；相似现象查[field_lessons.md](field_lessons.md)。失败版本保留，单次现象标观察，相近任务再验证后才升级规则；方法库不冒充成功率保证。
