# 从剧本到 Seedance 提示词

## 1. 工作目标

本工作不是替编剧重写故事，也不是展示复杂导演理论。目标是把用户给出的当前片段转成观众能看懂、模型能执行、剪辑能使用的视频。

```text
当前剧本事实
+ 用户想要的画面
+ 本次素材
→ 一个清楚的观看效果
→ 一条自然的画面流程
→ 一份自包含执行提示词
```

人物表演和镜头表达在初稿时一同设计；剧情正确、连续性与表现力分别检查。先理解编剧的事件与人物意图，再把它们拍得清楚、有情绪、有记忆，不能把情绪留给模型自动补。阅读路径以 `AGENTS.md` 第4节为准，本文件负责从已读材料到具体设计。

## 2. 先确认当前片段要让观众获得什么

先读整段再划镜头，区分三类内容：必须发生的可见事件、必须保留的现场台词、旁白承担的信息或心理。旁白中的比喻不能自动变成物理事件；台词字面意思也不等于人物真实目的。

构思前先形成下面几个简短判断，不要求用户另填表，也不把分析原样投喂：

| 判断 | 要看清的内容 |
|---|---|
| 发生了什么 | 事件起因、顺序、结果；哪些动作、台词与人物设定不可改 |
| 谁知道什么 | 谁已知、误信、隐瞒或刚发现；人物可察觉的线索与观众的信息差 |
| 观众站在谁一边 | 当前主要POV是谁；观众与角色知道得更多、相同还是更少；镜头应共情、观察、怀疑还是施压 |
| 对谁、想达成什么 | 每句台词的对象与目的：求确认、逼迫、掩饰、拒绝、试探、保护等；对象是否在中途改变 |
| 可拍事件 | 去掉解释后，观众必须看见哪个动作结果、人物选择、环境变化或关系变化，才能确认本段剧情已经发生 |
| 关系怎样改变 | 开场谁掌握主动，哪个事件动摇它，结尾谁获得或失去选择；平静、亲密段也可围绕信任或欲望变化 |
| 表演怎样接力 | 说话者或行动者怎样发起，直接承受者何时回应，最受影响的关系人怎样选择，谁把结果放大 |
| 观众应感到什么 | 用一句具体的话说清本段的期待、愤怒、快意、心动或不安来自哪个变化；最值得记住的时刻在哪里 |

如果只能把本段概括成“他们对话”，而说不出观众最后应看见什么变化或结果，剧本还没有被压成可拍事件。

通读整集时先找最重要的情绪爆发点，再判断哪些普通节拍只需准确推进。主高点若是施害、霸凌或压迫，先寻找能被镜头读到的具体恶意行为及承受者如何被击中；剧本随后确有反抗、保护或救赎时，再设计其兑现和余波。细节要逐级拉开反差，不靠“恶毒”“委屈”“很爽”等标签，也不提前发明救援。既有情境内的表演可直接设计；新增会改变剧情因果或后续状态的行为、剧情性道具，可在拆解稿中主动提出具体拍法与素材需求，用户确认后再写进正式提示词。

检查理解是否成立：如果只看拟定动作和人物反应，不读导演解释，观众还能看出剧本的关键变化吗？如果解释依赖剧本未给出的秘密、道具或动机，回到当前材料修正，不替编剧补设定。

用户直接标出的情绪点、表演方向和强弱是本轮设计的优先依据；没有标注的地方仍由Codex根据人物目的、说听对象和关系变化主动补齐，不能把表演责任退回给用户。内部可以先写“愤怒、慌乱、得意”，但正式逐镜前必须把标签翻译成观众能看见或听见的证据：面部肌肉与视线怎样变、呼吸和声线怎样变、身体距离与重心怎样变、手部真正做什么，以及对方怎样回应。情绪词本身不能作为完成稿。

抒情、家庭接纳、创伤被看见、失而复得或悔恨段落，若剧本没有要求立即爆发，默认先比较“人物克制或不敢相信→一个具体动作、物件或词句击穿→声音、呼吸或身体出现变化→直接对象与关系人承接”的情绪曲线。泪点不是让人物从开场一直哭，而是让观众看清防线在哪里、被什么打破以及关系因此怎样改变。

### 两种剧本入口，按需切换

- **用户主导拆解**：用户先给简短初版理解、时码、画面想法并指出重点情绪时，Codex仍需通读当前剧本，找出整集主峰，主动把旁白含义拓展为可拍行为、刺激、反应与结果。保留原始剧本、时码和已有括号批注，只在对应内容后追加导演补充，不覆盖用户原文；交用户审核通过后再转成分段与提示词。用户已经确认某一步时，从下一步继续。
- **Codex代拆**：用户中途接入项目、不想先读剧本，或明确把单集拆解交给Codex时，先通读当前完整剧本，模仿用户既有拆解方法制作一份Markdown审核稿。保留英文剧情、现场对白、时码与已有批注，在相关句段后用简短中文括号补充画面、表演、镜头、转场和素材判断；此时不提前拆成Seedance生成片段。第一步默认不另制Word、不做文档渲染预览，也不检查原始音轨实际时长；用户明确要求时再执行对应工作。

代拆不是每集强制步骤，也不要求用户填写模板。括号批注只保留当前需要的内容：观众应获得什么、发生什么、人物目的与情绪转折、关键表演、画面或镜头语言，以及连续性或素材缺口。文字接近用户平时的简短批注，必要专业词可以保留，不展开导演理论。已有用户括号后需要补充时，使用新的`（导演补充：……）`，不把用户决定悄悄改写。旁白画面可以逐句承接，也可以把相邻几句合成一个完整情绪节拍；只要关键信息第一次出现时，所需人物、证据或结果已经可读。

代拆阶段可以主动提出有剧情依据的回忆、平行画面、其他场景快切、已建立在场者反应或剧情道具，并在同一括号中写清用途；缺素材时标出`需补资产`。这些是供用户审核的导演候选，用户确认并补齐素材后才进入可执行提示词。用户通常只需补充资产、不可改变的想法和少量审美纠正；剧情事实、台词对象或拍法存在实质歧义时再集中提问。

当用户给出详细拆解、逐条批注或明确画面要求时，先把它拆成内部原子清单：事件与动作顺序、谁对谁反应、速度与是否允许停顿、指定景别或运镜、对白与时码。每一项必须映射到具体镜头中的可见执行，定稿后再从提示词反向逐项勾回用户原话；不能只保留剧情结果，却把用户明确要求的快切、快速变焦、表演强度或直接反应自行弱化。

例如一人说“我才是你的伴侣”，当前目的可能是向伴侣争取关系确认；先看伴侣、等待回应，未获回应后才有理由把矛头转给第三人。只提取“生气”会丢失对象与关系变化。这类匿名例子用于判断，不成为新项目剧情。

### 拆解审核通过后，再拆整集制作单段

Markdown拆解稿经用户审核后，再依据整集剧本、用户给出的总时长与对白全局窗口拆成生成片段；只有用户明确要求听检或现有时码确实无法支撑制作时才检查原始音轨，不边生成边临时寻找切点：

正式提出3段或4段方案前，先通看整集场景与动作怎样贯穿。用户时码首先是叙事节拍，不自动成为生成边界。判断候选切点时只问：下一段能否凭原始资产建立清楚首帧，而不依赖上一段未知的站位、接触、持物或动作阶段？能则可以独立，不能则合并或使用一次视频延长；同地点明确跳时时，重新写清新时段实际在场人物和状态。完整因果与情绪兑现先于返抽范围和并行效率。

1. 按时空变化、功能场景、情绪阶段、对白区间和完整动作链提出自然切点。
2. 优先用剧本标注的现场对白全局区间建立节拍；标注不自动等于硬锁。用户已允许按实际视频调整台词与字幕时，Codex根据完整发声、换气、动作与反应自主调整窗口，同步重算并列明新时轴，不为每句重复确认。只有明确锁定的对白或同步节点才不能擅移；真正影响拍法且无法确定的缺项再补问。
3. 用“全局时间减去前面片段累计时长”换算当前片段的局部对白区间。
4. 每段确定核心变化、主要行动区、可拍事件、实际开场、结束状态、情绪高点与具体记忆画面，再写镜头。拆段尽量保护完整台词、关键动作与余震，不让一次反转只剩准备、把结果挪出当前段。
5. 相邻段需要精确站位时，预留合格源视频依赖；实际成片出来后核对终态，再设计本段移动及新落点，不上传成片截图锁定开场。
6. 先核算完整台词、关键动作与反应需要的正常速度时间，再安排次要动作；不要让走路、放物等准备挤掉察觉与阻止。已获对白时长调整授权时，主动扩时并统一重算，不靠快读或漏句硬塞；与明确锁定的窗口冲突时，在定稿前说明。
7. 旁白区间与已确认的画面分段用于对齐意义节拍，不是绝对时长。分段后发现重要情绪点仍缺具体行为、承受反应或兑现余波时，可把约20秒主动设计成22至23秒；实际需要更多时按剧情调配。同步重算生成整数秒、受影响的旁白与未锁定时码、相邻段起止、生成依赖和真实切镜数，并核对平台时长上限；用户可在剪辑软件调整旁白。已锁定的现场对白窗口不自动后移，若新增时间与其冲突，在方案中指出。新增时间必须带来新证据、表演或关系结果。

分段的基本单位不是“约30秒”，而是一个能独立兑现的戏剧单元。每段在内部明确：主要剧情任务、主情绪兑现对象、直接承受者与关键关系人、本段高潮、实际开场状态、动作落稳后的结束状态、对白窗口及源片依赖。其他人可以放大本段，但不能与主情绪对象争夺中心。

### 3段与4段怎样选择

先按剧本自然形成候选切点，再比较整段失败时需要重抽的范围。段数少不自动等于省积分；一个30秒段只要巴掌、口型、群众或站位有一处失败，就可能整段重抽。第四段只有同时满足“有独立戏剧任务、切点状态已落稳、失败可局部重抽”时才有价值。

优先比较拆成4段：

- 一个长段同时包含两个由不同人物承担的独立情绪高潮，两者都需要清楚前摇与余波。
- 长对白、复杂接触和多人强反应争夺同一段的执行容量，任何一项失败都会拖累整段。
- 掌击、抓腕、身份揭示、手机展示等高风险单元能在动作开始前或结果落稳后独立成段，重抽时不必推翻已合格前段。
- 新段有清楚的主情绪对象与新关系落点，不只是补几个重复反应镜头。

保持3段：

- 同一人物的情绪弧线与同一句长对白正在连续升级，拆开会削弱兑现。
- 抓握、出手、受力、递物或转屏仍在进行，候选切点没有稳定终态。
- 第四段只能重复已经读清的信息，或仍必须继承前段大量未知站位，实际没有缩小返抽范围。

每段不要求只有一个角色有情绪，而是只有一个主要情绪视点。行动者、直接承受者、关键关系人与群众组成表演接力；下一段可以把主情绪视点交给另一人物。详细决策见`director_patterns.md`第23节。

无论采用3段或4段，生成边界同时满足以下条件：不落在一句现场对白或明确语意单元中途；不切断伸手、掌击、抓握、转身、递物、转屏等连续动作；关键刺激已获得至少一个直接回应，高潮没有只留下准备；人物位置、头眼方向、手位、接触、道具和衣装已经落稳；下一段能够明确选择源视频继承或用原始资产重建。任一项不满足，就移动切点，不用“后面再补反应”掩盖不完整段落。

整集定稿前必须同时看一遍3段与4段候选，并问：这一段如果抽坏，究竟要重抽哪个情绪单元？回答不出，说明任务仍太杂。比较的是首抽加返抽的预计总成本和返工波及范围，不对平台积分作未核实的固定换算。

成片时长通常比正文多约1秒，作为动作完成后的反应或剪辑余量；达到当次已确认时长上限时不再自动增加。这一余量与主高点有意增加的有效画面时间分开计算，不放在慢开场里，也不累加进后段对白偏移。

提示词骨架可以提前批量设计。上一段结尾与本段开场换场、无素材依赖的片段可以并发生成；同一具体空间且站位、接触复杂的片段优先等前段合格成片再延长，跨集也按此判断。分成4段不等于四段全部串行：不依赖主角未知末态的群众或功能视点可独立准备，真正依赖接触与持物结果的段落等待源片。并发组、依赖关系和模型放在文件顶部制作设置，不写入可复制正文。

整集拆段后再画一次最短生成依赖图：换场、跳时或稳定重建段作为可并发的原生源片；只有必须继承其实际接触、持物或连续运动的后段成为单次延长子片段。延长结果不能继续充当下一次延长源，因此拆段时要提前安排新的稳定重建点。效率同时看两个指标：一段失败会波及多少已合格内容，以及最长串行依赖有多深；不能只看总段数或一次能提交几段。

## 3. 区分不能改与可以设计

不能擅自改变：

- 关键事件与结果。
- 主要台词与人物动机。
- 用户明确指定的动作顺序和画面。
- 已经建立的角色、道具与空间连续性。

可以设计：

- 景别、角度、焦点和切点。
- 人物反应、呼吸、视线，以及剧情支持的轻微或较大幅度动作；不把大动作自动视为违和。
- 已建立或已获准群演的前后景关系、密度和环境反馈。
- 有动机的转场、声音承接和结束构图。

用户的解读主导剧情方向与审美目标，但不是Codex主动导演的开关。对于用户尚未锁定的画面空间，只要不改变上述固定事实，Codex就直接在现有剧情、人物、场景与道具范围内选择表演、反应、互动、走位、镜头、转场与声音，并在内部检查：“这里由Codex主动贡献的导演选择是什么，它怎样让剧情更清楚、更有情绪或更值得看？”答案可以是一项简单但有效的关系构图或动作；若用户已明确锁定全部动作与画面，不为完成此项强加技巧。

需要新增场景、人物、剧情性道具、改变剧情因果或后续状态的行为、剧本未建立的回忆或小插曲时，可以先在Markdown拆解稿的导演补充中写出具体方案、用途及连续性影响，并标出素材缺口；用户确认或补齐所需素材后，才把它写进可执行提示词。既有情境内不改变剧情事实的表演和局部动作直接设计，不为每次翻身、停步或回看重复请示。不得用“大胆设计”改写关键事件结果、人物动机、台词对象、信息知情顺序或已经成立的连续状态。

正式落稿采用两遍判断：先做开放导演遍，在用户未锁定的空间内形成一个最有效的可拍方案；只有高点、长时间单一事件或存在明显更好拍法时，再快速比较第二方案。随后做连续性否决遍，逐切点核对轴线、画面左右、位置与道具怎样形成、动作是否接住以及镜头是否重复；同一项目连续制作时，再快速扫一遍最近2—3集已经高频使用的签字、门禁、证件、遮挡等视觉语法。方案若被否决或只是跨集换角色复用旧拍法，重新设计具有同等表现力的方案，不默认退回静止中景。

## 4. 什么时候问用户

- 用户画面想法明确：直接转译，不另造方案。
- 只有一种自然拍法：直接完成。
- 不同拍法会实质改变用户尚未明确的叙事意图或审美方向：先简短确认。意图明确后的运镜、转场与细节由Codex综合判断，直接形成一版正式设计，不为每项技巧再次询问或另出试拍版。
- 缺少本段必需角色、场景、道具或屏幕内容素材：先说明缺什么、用于哪段哪一动作，等用户补齐后再绑定；明确获准直接描述的例外才执行，不把复杂资产依赖藏在正文中。
- 用户要求与场景空间或物理连续性冲突：先说明冲突和最小修正。

询问只为对齐结果，不把导演判断重新推给用户。

## 5. 先选功能场景，再把场景图读成真实空间

整集先规划场景图所承载的演绎区域，再拆生成片段。仿真人与拟人动物共用制作上限：同一场景图下固定区域的持续演绎按约55秒预留转换，不超过60秒，通常由一条原生与一次延长承载。例如众人一直坐在客厅茶几旁，到这一时长应安排新的画面演绎。允许继续留在同一空间，利用拓展区域／场景视角推进，如从客厅沙发区走到客厅与厨房连接处，让人物位置、互动与画面关系随剧情改变。普通正反打、换图片文件名、片段／集号变化、同一区域重新原生及短暂空镜或回忆都不重置该区域的累计时间。此为用户的制作约束，生成连续性另按源片实际状态判断。

相邻区域的连续转移由人物当下目的推动，交代谁从哪里离开、怎样移动、谁跟随或留下，以及新的到位关系；需要坐下或接触时，再拍清相应动作。可以省略无事件的中间路程，但留下可读的起步与到达依据。例如女主正面逼近母亲、母亲面对女主倒退，由这个互动把冲突带到另一处；一楼转二楼则给楼梯来路或上下楼的动作依据。医院回家等不同大地点转换，可直接硬切或用一个空境过渡。转换时间纳入设计，在完整对白与关键动作落稳处选切点；若必要的拓展场景素材未齐，先列用途与缺口，若剧情无法合理转移则提出具体方案请用户决定。此约束从后续新设计执行，不自动返工已采用成片。

先问这处场景要为本段完成哪一项主要叙事或视觉任务。人物场景可以承担进入、交付、共看、阻拦、私谈、公开表态或等待；空镜可以承担地点、时间、气氛、运动方向或转场。优先选择能自然提供所需入口、锚点、道具和路线的简单功能场景。场景数量可随剧情增加；单张场景图优先承载一个主要功能、清楚的主关系或主体和一条主要行动路线。剧情必须在同一连续空间完成时可以保留多个功能或多人关系，但应压低次要路线。连续多集共享的大地点可按实际动作拆成拍摄区，不为普通反打新增资产。不可逆状态确实会反复入镜时，再准备对应状态变体。

在内部建立一张简图：

```text
剧情功能：这处空间让本段完成哪一项主要叙事或视觉任务
固定锚点：门、桌、窗、栏杆、道路、楼梯、柱子
入口与来路：人物开场已在哪里、正在做什么；若需要入镜，从哪里进入
人物主轴（涉及对话或对峙时）：主关系建立时谁在画面左/右、彼此视线方向、摄影机保持在哪一侧
行动与互动：人物在什么锚点，通过什么行动影响谁，对方怎样回应；需要移动时写清路线和最终停点
道具归属：如使用道具，它从哪里来、由谁持有、是否交接、动作后停在哪里
世界条件：时间、天气、光源、环境声
```

场景图负责空间、透视和尺度，时段服从用户当次指定和剧本；在【空间与道具状态】开头单列时间、窗外状态与主光源。同场复杂关系优先视频延长，大地点转换与明确跳时优先用原始资产独立生成；相邻区域先拍清移动与到位，能由原始资产可靠重建时才独立衔接。不上传首尾帧或成片截图。源视频终态是开场依据，不是整段禁止移动；可用场景明显标志物指明行动目的地，拍清途中与到位关系。集号本身不决定衔接方式，画外空间不能凭单张截图猜测。

这些判断主要留在 Codex 内部。提示词只写本段执行必需的站位和方向。

### 人物目的先于表情

先在内部判断：人物想对谁或自己达成什么 → 用什么行动或说话方式 → 对方如何回应 → 是否需要调整。再挑可读的脸、身体、距离和声音表现，不先给每人分配皱眉、眨眼或攥手。

有人物关系的段落，应让主关系通过有因果的行动和回应被看见。优先从剧本已有动作、当前道具和场景设施中选择一个主要行为，写清触发或来路、人物行动、对方回应，以及人物和道具的落点；没有合适道具时，用距离、占位、视线或阻挡完成互动。动作必须推进人物目的，不为“有事做”另加装饰性小动作。

候选肢体动作再过一次“删掉会损失什么”的检查：它应当改变人物距离、接触、道具、空间通路、对方判断或角色暴露出的态度。删掉后信息、关系和情绪都不变的摊手、摸衣服、悬手、反复整理和抽象比划直接取消。需要力度时，把力量集中在一次明确动作及其结果，例如拍证件、压章、合夹、推回资料或拉走物件；必要时在接触瞬间给短促局部特写和同步动作声，再切承受者反应，不让人物连续挥舞肢体表示情绪。

主动作发生时，重要非说话者仍在察觉、判断、试图影响或主动忍住；同镜只保留一个主焦点，其他反应错开且有因果。不是人人同时夸张，也不是轮到台词才开始表演。强度和泪光层级按`execution_rules.md`，不从柔和影调推导全员情绪寡淡。

让每个重要关系人经历“原有态度→察觉线索→为了自己的目的行动或忍住→得到回应后改变”。为变化找到实际镜头：可以在关键动作同框被看见，也可以在别人对白画外继续时给独立反应；只有人物状态描述、没有可读画面不算设计完成。配角按其事件职责出现，不因素材可用就反复安排特写或挤到主角身旁。

先选择适合情绪强度的表演，再减少同时发生的任务。紧急保护可以快速接近并明确截住对方，难堪可以明显停住、退让或转头，亲密可以改变距离与呼吸；不是统一放轻。需要人物忍住时，拍清压住什么冲动，不用冷脸或无目标悬手代替。

### 关键对白与冲突先排“表演接力”

每个关键对白或冲突先在内部完成一条短链，再编号镜头：

```text
触发
→ 说话者或行动者想让谁怎样
→ 台词或动作进行中态度怎样升级、转向或破防
→ 直接承受者如何即时回应
→ 最受影响的关系人支持、阻止、争取、拒绝或忍住
→ 事件留下什么新状态
```

长台词按语意变化拆成2至3个表演拍，不按标点平均切。每拍只选一个主导意图，例如辩解、逼迫、求证、嘲讽或遮掩；在重音或自然换气处，用一次可见的视线、面部、呼吸、手势、距离或声音变化兑现。只写“愤怒地说”“冷冷看着”不算完成，说话者不能在开口前做完情绪、随后平直念词。

冲突高点按“前摇→爆发或接触→受力结果→余波”播放。行动者、直接承受者和关系最受影响者不必同镜或同时夸张，但三者都要在必要时刻获得可读画面。无台词主角若正在被事件改变，必须作出有剧情作用的选择；只站在后方、只留肩膀或只写“关注”不算参与。详细拍法见`director_patterns.md`第22节。

短剧主要角色的反应速度、动作幅度与表情落点应在竖屏近景里一眼可读；普通桥段正常推进，高潮进一步采用中到强、必要时更外放的幅度，除非人物此刻的目的正是掩饰、压住或伪装。放大的是人物目的，不是让所有人持续激动；每镜一个主表演焦点，最多一个次反应，其他动作按察觉先后错开。

内部可用三级强度校准，而不把等级文字投喂模型：一级是压住或隐藏的情绪，二级是短剧中清楚外放，三级是反转、公开羞辱、强势保护或身体动作的兑现高点。普通冲突对白原则上至少达到二级；真正的爽点通常达到三级。沉稳人物可以不喊叫，但出手速度、距离变化、目光控制、咬字和句尾压迫仍要达到相同叙事强度，不能把“沉稳”误写成“没有反应”。

情绪通常沿触发逐级显形，而不是在一个切点突然换成另一张表情：先由视线、眼睑、嘴角或呼吸泄露，再传到手指、肩颈、重心和距离，最后通过一次选择、动作结果或环境反馈完成兑现。正式镜头只挑当前人物与景别最有效的两三层，不机械写全；真正的高潮可让物件重响、门被关上、旁人停手或空间骤静放大后果，但环境必须被真实动作或声音触发。若删掉某个肢体动作后，人物距离、道具状态、对方判断和环境结果全部不变，该动作通常只是无意义表演，应删除或换成真正产生结果的一次动作。

这条表演链用于内部选镜，不整段复制成每个角色的状态说明。落稿时，每个人只保留真正被选中的可见变化，并把它写在发生的那一镜；【空间与道具状态】只保留时间、空间、开场关系和跨镜事实。若一个修订没有新增剧情、素材或镜头，却因防错而明显变长，先删除旧触发词和重复限制，再判断是否仍需补充。

## 6. 先在脑中播放，再编号镜头

审核通过的拆解稿就是本段导演蓝图。进入提示词阶段后，先做一次精简的转译分析：从开场到结尾播放人物为何行动、对方怎样回应、留下什么结果，核对空间与实际资产；再按动作进度、语意转折和情绪落点选择切点、机位与编号，最后检查镜长与最低真实镜头数。不省略这次分析，也不扩张成多层导演卡、重做剧本解读或比较大量备选。用户直接给出完整画面要求时，同样分析并转译。

编号完成后只从第一帧顺读到最后一帧一次：每个拆解节拍是否有承载镜头，连续几镜合起来是否推进了行动、信息、情绪或关系；人物为何行动及其结果是否清楚；相邻镜头的位置、朝向、持物和动作阶段是连续承接还是明确重建；最后状态是否成立。有任务的停顿、情绪读清和视觉联想也可以推进观看，不要求每镜新增剧情。发现问题只调整对应镜头，不推翻已经确认且没有问题的部分。

只有时空、视角、信息焦点或情绪落点改变时才切镜。同一动作被错误切开，会让模型在新镜头重新摆位。海外旁白短剧还要主动寻找这些变化，不能因为空间和人物没变就让一个普通中景长时间承担多句旁白。

顺读时快速删除没有新信息、动作结果、人物选择、关系变化或情绪作用的镜头，不另写逐镜问答。多人中景只有在建立新站位、显出权力倾斜、拍清共同刺激或完成复杂接触时保留，不能作为等待台词的默认底图。

若通话、亲吻、等待、阅读或工作等一个表面动作跨过多个旁白意义或情绪节拍，不能只靠换机位冒充推进。先标出每个阶段新增的信息、关系、情绪、行动或环境结果，再按`director_patterns.md`第19节比较有依据的听者反应与后果、回忆或平行场面、真实空间迁移及用户已经采用的小插曲。切出和切回都要接住主事件的声音、持物、接触与情绪进度；不为“有趣”擅增人物、场景、道具或支线。

顺读长段时抽查连续约10—15秒的窗口：若人物仍维持同一姿态、接触和表面动作，只靠没有新变化的正反打撑时长，即使镜头数达标也要重排。先让当前人物的主动行为、直接回应或动作结果进入新阶段，再比较有任务的场景局部、已确立且有素材的回忆、状态蒙太奇或视觉转接；插入画面须由当下台词、感知或动作触发，切回仍接住原场景状态。这个窗口用于发现停滞，不是每10秒必须加动作或转场的配额。

## 7. 先选择节奏模式

### 海外旁白短剧

当前默认使用高密度真实切镜。先让观众读到动作进展、新信息、听者回应、情绪变化、关系或有意义的视觉联想，再选择能看清它的主体、机位和景别，最后按下表核对密度。单独换人物、角度或景别不算完成推进；镜数达标仍需检查画面是否停滞。

| 成片时长 | 默认真实镜头数 |
|---|---|
| 16秒 | 至少6镜 |
| 20至21秒 | 至少7镜 |
| 22至24秒 | 至少8镜 |
| 25至26秒 | 至少9镜 |
| 30秒 | 至少10镜 |

其他时长按“总时长除以3后向上取整”计算最低真实镜头数。

- 普通编号镜头原则上不超过3秒。表情变化、情绪停顿和镜内动作通常应在3秒内形成清楚落点；泪点、认知击穿或关系余波需要完整读清时，可以使用约3至4秒的动态情绪镜头，期间由缓慢推近、轻微横移、弧线调整、移焦或人物内部变化持续推进，不能用静止机位和同一表情耗时。
- “总时长除以3”只是最低镜头数，不是目标平均镜长。高情绪争辩、公开羞辱、危险启动和动作兑现若同时包含多个可分离焦点，应主动设计一组爆发链：可用连续3至5个约0.6至1.2秒的真实快切，在发令者、启动动作、承受者即时察觉、接触与结果之间换手，再用稍长镜头读清余波。若高潮依赖一句不可打断的对白、连续接触或单人表演，则用较少镜头在镜内完成声音与身体变化。高压段落连续两个超过2秒的镜头若都没有完整对白、必要情绪落点或新状态，必须重排节奏。
- 普通叙事与时间蒙太奇以约1.2秒一镜作为观看起点，再按新状态的阅读量加长。人物重要表情、可读文字或动作结果不能被更短的均匀闪切吞掉；0.6至1.2秒的爆发快切只在当前剧情确有多个可分离焦点时使用。
- 高压段落至少比较一次快速变焦、快速推近、快速拉远、短促跟落或人物间快速摇摄能否增强“发现、逼近、破防、受力”中的一个节点；合适便直接采用。快速摇摄到新的关系人或已建立在场者时，落稳后必须读清其即时反应。
- 只有真实剪辑切点才计入最低真实镜头数，默认硬切；明确的遮挡或甩镜隐藏剪辑也可计入。为了把执行节拍写清，一次有动机的快速摇摄从一个主体迅速落到另一主体时，可以将落到新主体后的部分另列镜头号，并标明“连续快速运镜、无剪辑”；它仍属于同一条连续实拍，不替代真实快切。普通推近、拉远、横移、变焦、移焦和一镜到底仍只列一个镜头号。
- 同一连续动作优先设计到3秒内完成。例如人物走出电梯并越过另一人，应在当前镜头内拍到动作落稳；确实装不下时先简化动作，或只在人物到位、接触完成等稳定因果节点切开，不能从行走中途切成瞬移。
- 旁白先按语意与行动变化拆节拍，再以约2至3秒检查可读性，不平均切字数或时长。每个镜头承接当前信息、证据、反应或反差，不能让旁白已经进入下一层，画面仍停留在上一件事。
- 每个意义节拍再标一个“第一可读帧”：观众第一次能看懂该句所指的人、证据或结果。第一可读帧原则上落在该节拍开始处或略早，不等人物走完、拿完、整理完才出现。若模型可能把多步动作演慢，删减准备步骤、从已经开始的动作进入，或硬切到证据与直接反应；不单靠增加镜数或后期整体加速修正。

### 真人大量对白剧

真人大量对白剧暂不套用上述镜头数量表，等待真实项目后建立独立规则，见 `live_action_dialogue_drama.md`。

## 8. 快节奏仍要有层级

短剧可以快，但要有层级：

- 开场快速进入异常、人物关系或关键问题。
- 过程持续改变状态，不用静态中景等台词。
- 关键证据、接触动作和反转台词必须清楚。
- 高潮后至少给一个可读反应。
- 留人点来自信息差、危险、决定、情绪变化或未完成动作；镜头密度负责持续更新注意力，不能单独制造留人点。
- 切镜不只检查是否换了脸或角度，还问新增了什么证据、谁的目的受阻、哪种关系改变。道具展示应让需要看见它的人真正看见，不只是对摄影机展示。

短剧的“爽”也不是所有人物持续高强度表演。更有效的片段通常包含：清楚刺激或异常 → 压力累积 → 可见的权力或关系反转 → 主角、对手与旁观者的余震。一次关键行为最好同时改变人物关系，并让不同人物以不同微反应确认它的影响。

判断节奏时先对照旁白信息是否已经落画。例如旁白已经说到“所有人站在她那边”，画面就应及时出现人群靠向一方、另一人被孤立的可见证据，而不是仍停留在人物缓慢走近。镜头速度服从信息速度。

### 将情绪、动作与视觉创意落实为记忆画面

每段先找本来就值得看的变化：误解被戳穿、关系被公开否认、危险逼近、保护发生、亲密被接受等；不制造剧本没有的反转。强度来自前后差别，不要求每段吼叫、流泪或打人，铺垫段也可以留下明确期待。

同时扫描三类已有材料：人物目的造成的距离、前后景和权力构图变化；本来就会发生的动作与道具；入口、通道、门窗、遮挡、反射、天气和环境运动。它们都可成为具体画面或前后镜头的视觉接力。记忆点也可以是动作与镜头配合的巧思、一次流畅的视觉连接或新的观看角度，不必每次先证明人物情绪发生反转。情绪表演和视觉创意都是主动设计任务，不能把后者长期放到“实在有必要才考虑”。

先想开场画面经过本段事件或环境运动后会落成什么画面，以及观众会记住哪一帧，而非先想技巧名称，例如“先前逼迫人的人失去回应，站在关系构图之外”“证据稳定露出，对手笑容停住”。再按当前空间与时码比较拍法：

同时比较一项能因剧情而改变的视觉变量：人物距离、是否同框、中心与边缘、前后景、入口与出口、门或道具状态、相机与人物的距离。变化必须由人物目的和动作结果造成；没有收益时不为完成检查强行走位。跨集反复出现的门槛、窗、餐桌、动作或道具，只有在意义随关系推进而变化时才可作为视觉母题，不能用同一构图机械复刻。

1. 用清楚的表演、构图和切点，能否直接兑现？
2. 快速变焦、动作擦除、物件旋转遮挡、图形/动作匹配、反射揭示或声音跨切，哪一种更能兑现这次情绪、视觉趣味或场景连接？新设计时读 `director_patterns.md` 第19—21节及对应方法，不能只写“有动机才用”就跳过选择。
3. 选中的拍法是否提供了新信息、态度、反差、动作触感、节奏变化或视觉联想？只剩无目的运动、遮掉必要表情或挤占对白时调整；不要把“没有新增剧情信息”直接等同于“没有价值”。若普通硬切更有力就用硬切，同样写清具体切点。
4. 把选定设计写进对应镜头：触发是什么，画面从哪里到哪里，剪辑发生在哪里，下一镜怎样接住，观众最后看清什么；状态与声音窗口保持。不能只在设计说明里称“有记忆点”，正文仍全是近似中景。

快速变焦适合注意力突然收紧的瞬间，譬如证据出现后的破防；慢慢动摇的信任可能更适合表演递进、移焦或有节制的推近；同场对峙可用有态度的切镜和构图，日常动作或换场也可由一次巧妙视觉设计留下记忆。技术服务本次画面表达，不一律用变焦，也不一律禁用。

单段25秒及以上、或约一分钟以上的整集，定稿前主动提出至少一个具体特殊转场或镜内视觉设计候选，比较放置时点、前后画面、现有资产和观看收益。适合便写入正式提示词，不默认退回硬切；未采用时内部说明具体原因。整集通常选择约2处最有价值的特殊转场，明显更长时最多约3处，其余使用干净硬切；这是默认密度而非必须凑满的配额。先成对设计切出/切入，优先把相互依赖的两端放在同一次生成任务，再处理并发依赖；短段遇到真正合适的机会也可采用。

整段按刺激、升级、兑现、余震或悬念组织，不机械要求每段都含同一套步骤。高潮前压住准备时间，动作正常速度及时完成；高点到来后留下能读到表情或证据的窗口，再把注意力交给受影响者。减少重复信息镜头，不靠缩短所有表情或加快所有对白制造快节奏。

依赖时效的梗才联网核对语境；不为追新意硬塞与人物、资产或剧情无关的流行表达。

## 9. 9:16 与旁白型内容

竖屏优先使用纵深和高度：前景局部、中景人物、后景目标；门、走廊、楼梯、窗和建筑高度都可以建立关系。

过肩镜头不仅交代说听关系，也可以通过摄影机高度改变观众对权力的感受。表现强者压迫时，可从强者肩后俯拍弱者，或从弱者肩后仰拍强者；提示词必须同时写清肩膀属于谁、镜头拍谁、俯拍或仰拍，不能只写“过肩”。

对峙、压迫与反抗段主动选择适合当前权力关系的俯／仰过肩，并把关键情绪落到可读的小特写，如爪抓紧衣料、伸到一半后停住、耳朵在刺激后短抖。机位高度须服从实际距离、身高和主轴；局部动作须由具体刺激触发，并接到听者或关系人的选择。不能只换高度、加表情形容词就算完成镜头设计。

旁白承担信息时，画面承担：

- 证据。
- 被评价者的反应。
- 道具或空间伏笔。
- 人物未说出口的欲望。
- 与旁白形成互补的反差。

场景局部、陈设与道具特写可以成为短促的新观看入口，但必须承担空间确认、动作后果、关键词呼应、情绪转折或转场中的至少一项任务。删掉后毫无影响的装饰性空镜不加入。

旁白不要求一直拍说话者，也不按每一句机械配图。旁白节奏与镜头的对应由Codex内部完成，不将旁白原文或校准关系写进Seedance正文；当前只输出需要模型生成的画面和声音。真正的现场冲突尽量保留关键对白，让声音从“讲述”回到“正在发生”。

旁白首先表达人物如何感受、关系如何变化或观众此刻应理解什么，不一定是逐字执行的动作清单。把旁白转成画面时，先提取心理含义，再比较哪些身体行为、外界刺激、直接反应和下一步行动能把状态拍成一个小的因果过程。例如“饿”不只对应摸肚子，也可能让人物辗转难眠、听到门外动静后改变注意力；具体行动仍要符合当集人物、空间与剧情。既有情境内的表演可直接设计；若这个过程需要新增剧情事件、道具或换场，先写在拆解稿供用户审核，不把候选直接变成正式剧情。情绪词与动作词都不能机械照字面或一律缩小幅度。

关键情绪节点至少检查三层可见证据：

- 面部：视线、眼睑、嘴唇、下颌、泪膜、肌肉紧张或吞咽；肤色保持参考图与环境光下的自然状态。
- 身体：手指、肩颈、重心、距离、接触力度或衣料反馈。
- 节奏：呼吸、停顿、动作速度以及何时真正放松或失控。

不是每层都要写很多，但高潮、亲密、恐惧、羞耻和决定不能只靠“紧张、期待、欲望强烈”等标签。2.5能执行细微表演，前提是提示词把变化过程说清楚。

## 10. 落稿前核对生成依赖与摄影实现

空间检查时已初步判断源片依赖；镜头设计后核对能否按计划实现，不能到此才发现核心接触无源片。先保护剧情与表演，再判断：

- 当前默认2.5的全能参考或视频延长如何执行，是否有具体能力风险。
- 是否确有必要另选模型或调整方法，而非默认先做Fast测试。
- 剧情手机消息、文件短句如何由Seedance直接生成：具体内容、可读机位与停留时间是否清楚。
- 倒放或标题等是否需要后期；当前禁止生成或主动添加BGM，允许明确设计的短促非旋律音效；不默认把剧情文字交给后期贴图，确有生成问题再讨论局部方案。

不因为Fast便宜就把高潮拍平，也不因为2.5更强就让一个镜头承担过多任务。

### 正式交付前分别看三件事

- **剧情与表现力**：能否从具体镜头读到人物目的、关键变化与应有强度？每个旁白意义节拍的第一可读帧是否及时出现？还有哪次动作、视觉揭示或转场连接值得记住？长段和整集是否已主动检查特殊转场机会，并避免和最近2—3集高频视觉语法撞车？全段若只是走来、站定、重复同一表面动作、轮流说话和皱眉，即使不穿帮也要回到表演与镜头设计。
- **静音表演复核**：先不看情绪形容词，只看动作、视线、表情与切点，能否认出人物是在逼迫、辩解、求证、嫌弃、保护还是争取？直接听者是否及时回应，无台词主角是否贡献关系变化，高点的前摇、结果和余波是否齐全？若答案依赖“愤怒、震惊、沉稳”等标签，表演还没有真正落画。
- **可拍性与连续性**：功能场景是否支持本段入口、行动与落点；沿时间追踪位置、对象、视线、关系轴、手部、接触、道具、受力和实际终态。用新构图表达关系，不能靠偷偷重排人物。
- **文本与固定要求**：按 `prompt_template.md` 复核对白原文一次、时码、真实切点、素材绑定、完整摄影和禁BGM；删除旁白对应说明、抽象主题总结、导演意图与因果解释，只留下模型能拍到或听到的内容。形式检查不能代替前两项。

完成后交付一份自包含正式提示词。用户无须看内部备选比较，也不要求先批准每个镜头技巧。

## 11. 成片反馈

用户已经用文字说明结果与修改方向时，直接据此修提示词；除非用户明确要求审片、逐帧定位，或文字反馈无法确定具体时空状态，否则不主动寻找、打开或分析视频。审片是解决信息缺口的工具，不是每次返修的固定步骤。

拿到结果后先分类：剧情、节奏、表演、空间、动作、道具、画质、声音、审核或模型上限。

不要立即同词重抽。先判断：

- 是提示词把错误拍法写得很清楚？
- 是素材材质、角度或清晰度不够？
- 是模型理解力不足？
- 是视频生成正确但剪辑和观看节奏不对？

保留失败版本。只有经过相近任务再次验证的结论，才进入核心规则。
