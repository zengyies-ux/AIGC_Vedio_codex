# 动物城分支：拟人动物的表演与视觉记忆

仅在用户指定拟人动物、福瑞或类似3D动画题材时加载。剧本事实、声音、空间、切镜与提示词栏目仍按核心工作流；真人项目不套用本文件。角色身份和物种以当次资产为准，动物动作不是把人的表情机械换成耳朵或尾巴。

## 1. 情绪先改变身体状态

内部先排：**具体刺激 → 哪个动物部位最先失控 → 面部、爪或身体重心怎样接上 → 直接对象怎样回应 → 动作如何回落**。每个高点只挑最有辨识度的两三项写入逐镜，不让耳、尾、爪和毛发从头到尾同时表演。

- 日常生命感是呼吸、眨眼、随步伐或接触产生的耳尾与毛发运动；它不能代替关键刺激下主动发生的动物反应。
- 惊惧、犹豫或想开口又退缩时，耳朵可以短促快抖两三下，再转向声源、贴低或停住；不要全段持续闪动。
- 突然被击中或进入戒备时，可让后颈、肩背的毛短暂炸起，带出重心或声音变化，随后随呼吸回落。只在物种、毛发资产和具体刺激支持时使用，不默认全身膨胀。
- 尾巴可以主动收紧、僵住、甩开、松落或与另一角色轻搭；写清根部、路线、接触和最后落点。另一角色应看见、感到或因其变化而改变距离，尾巴不只作为随身体被动摇摆的摆件。
- 爪捂嘴应阻住将出口的话或哭声，随后改变呼吸和下一句声音；抚头、反握、抓衣料也要让对方出现可读回应。手势和动物反应都服务人物目的，不为热闹追加。

高情绪近景应让观众一眼看出前后差异。柔和、温暖的3D影调不等于表演只能轻颤、慢眨或微笑；需要克制时，拍清角色在压住什么以及何时被击穿。避免用面部泛红表现情绪。

## 2. 打破同一动作的停滞

按`director_os.md`第6节检查长段：连续约10—15秒仍是同一姿势、同一接触和没有新状态的正反打，就先让人物行为进入下一阶段。可比较已有动作的主动与回应、爪或尾巴的关系特写、能承接当前词句的场景局部、剧本已确立且素材齐全的短回忆、可读的状态蒙太奇或一次有落点的视觉转接。空镜和回忆必须有当下触发，切回原场景的身体与道具状态仍成立。

普通蒙太奇先以约1.2秒一镜检查可读性；情绪断裂处的更短快切只在有多个不同焦点时使用。尾巴缠绕、抚头、炸毛或转场都要拍到**起因、实际动作和回应**，不靠多次换角度让同一动作显得繁忙。

## 3. 每段寻找观众会记住的画面

拆解或镜头设计时说出一幅具体画面及其关系变化，例如一条尾巴主动松开后与另一条轻搭，或某个角色的爪在关键一句后停在半空。记忆点可以来自表演、局部证据、环境反应、遮挡转场、动作匹配或有意义的快切；核心规则对整集复杂特殊转场的数量建议，不限制这些其他画面。

采用特殊转场时成对写清切出动作、切入主体和落稳后的可读结果。审实际成片时区分“提示词设计过”与“画面确实出现”：遮挡或匹配动作若没有清楚执行，不能算已兑现的记忆点；先判断是设计不明确、素材冲突还是模型未执行，再决定局部返修。

## 4. 套用原提示词模板

保留既有栏目和声音时序，把模板的“电影级真人短剧”替换为当次项目指定的3D拟人动物动画类型与影调。【空间与道具状态】只放跨镜的角色比例、真实物理关系和日常生命感；耳快抖、短促炸毛、尾巴交缠、抚头等关键变化写在发生的镜头，不用一条笼统的“耳尾轻微变化”覆盖整段。
