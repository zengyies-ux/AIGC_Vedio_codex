# 核心学习包发行目录

这里保存用户明确要求发布的干净核心学习包。

- `latest.json`记录当前版本、文件名、文件数、体积和SHA-256。
- 同名`.zip.sha256`用于校验压缩包完整性。
- 不自动重新打包；只有用户明确要求更新时，才通过`packaging/build_core_package.py`发布新版本。
- 历史项目、素材、审片、旧提示词、旧2.0 Skill和团队SOP不会进入核心包。

1.1.2（2026-10-10，V3.1）包含有效互动、项目节奏／返修力度、声音短格式与镜头开口一致性的核心修补。规则与文本检查完成，实际生成改善待下一次正常制作；用户认可后再将`core-v1.1.2`所指提交作为网页扩展稳定基础，本轮不操作平台。原配音2秒采用与无时码一次确认继续使用，不等于生成成片同步验收。ZIP不含项目、音视频、模型、缓存或会话，旧1.0.0／1.1.0／1.1.1及标签原样保留；默认main仍是旧备份点。
