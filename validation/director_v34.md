## 短入口与未来网页交接的文字演练

[通用短入口](../NEW_PROJECT_CONVERSATION_PROMPT.md)只需材料、范围、摄影依据与一句明确冲突职责；AGENTS能进入场面／执行／模板及[交付与续做](../memories/seedance_workflow/continuity_and_review.md#execution-handoff)，不依赖用户额外导演卡。两位复核及相对链接检查属于静态入口验收，没有另开制作窗口，不能称冷启动通过。

匿名演练：甲段原生21秒；乙段拟对甲的实际合格原生结果延长新增18秒。甲已有长度21与乙新增18分列，提交预算39；不把延长输出39误填为新增。只用现有制作设置、状态与提示索引，按以下事实顺读执行条件：

| 模拟事实 | 文字交接能确定的下一步 |
|---|---|
| 只有乙预排，甲未生成 | 等甲实际合格结果，乙不能提交 |
| 甲已生成，尚无认可或使用证据 | 不把生成成功当合格源 |
| 甲认可、可定位且尚未延长，必要状态足够 | 完成乙接续正式稿，正确入口提交新增18秒 |
| 甲是否已延长未知或源标识不明 | 仅暂缓该次提交，核具体事实，不猜最新结果 |
| 正文计划图号与实际上传编号不同 | 回读语义绑定，只同步角色映射／参考区，不替图或改台词 |
| 已有实际提交回执，任务运行中 | 续做查原任务，避免重复提交 |
| 已生成但未评价 | 记录生成事实，等真实评价；不自动记可继续延长 |
| 源是延长结果或区域累计将超限 | 不再次延长、不以改名或新原生归零；返回具体依赖冲突 |

此为匿名文字演练，无实际平台上传、源片选择、视频延长、绑定回读、回执或恢复成功。后续网页层只消费GPT可靠前置结果；用户认可实际画面、节奏与情绪后，仍须实测普通生成、一次真实延长、实际回执和中断续做。
