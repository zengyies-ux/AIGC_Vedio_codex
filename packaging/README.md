# 核心学习包维护

此目录维护干净核心学习包的白名单、专用说明和手动构建脚本。它不会自动同步或定时打包；只有用户明确要求发布新版本时才运行。

## 当前发布流程

1. 先完成本次规则修改及受影响范围的必要检查。
2. 更新`package_config.json`中的版本、发布日期和变更摘要。
3. 更新`CHANGELOG.md`。
4. 手动运行：`python3 packaging/build_core_package.py`
5. 从脚本输出确认文件数、断链、绝对路径和SHA-256。

发行文件写入根目录`releases/`。历史项目、资产、审片、旧Skill和团队SOP不在白名单内，不能因为新增文件而自动进入压缩包。

1.5.0沿用显式白名单，增加匿名`validation/director_v35.md`及`extensions/seedance-jumeng-operator/`的唯一SKILL和三份必要参考。真实剧本、项目、素材、网址、节点截图、账户、会话、词表、模型、缓存和本机实施文件均排除；清洁项目索引只在ZIP生成，不覆盖活动索引。

V3.5以`core-v1.5.0` prerelease发布，配置、日期、ZIP／SHA一致；准确列工具／文本与真实填稿范围，模型／时长重访未通过、新实片和完整延长待验，不声称全部跑通。公开提交逐项暂存核查白名单，不整仓暂存，保留旧包／标签／main。
