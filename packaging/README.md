# 核心学习包维护

此目录维护干净核心学习包的白名单、专用说明和手动构建脚本。它不会自动同步或定时打包；只有用户明确要求发布新版本时才运行。

## 当前发布流程

1. 先完成本次规则修改及受影响范围的必要检查。
2. 更新`package_config.json`中的版本、发布日期和变更摘要。
3. 更新`CHANGELOG.md`。
4. 手动运行：`python3 packaging/build_core_package.py`
5. 从脚本输出确认文件数、断链、绝对路径和SHA-256。

发行文件写入根目录`releases/`。历史项目、资产、审片、旧Skill和团队SOP不在白名单内，不能因为新增文件而自动进入压缩包。

1.4.0沿用显式白名单，新增匿名`validation/director_v34.md`；真实剧本、项目、素材、词表、模型、缓存、会话及含本机路径的实施文件／启动词排除。构建的空白项目索引只在包内，不覆盖活动索引。

V3.4发布为试制版，配置、日期、ZIP、SHA与`core-v1.4.0`一致，GitHub设prerelease。必要规则／工具／文本验收后可发布，实际新窗口、实片与网页仍待验证；发布不启用常规模式。公开提交逐项暂存核查过的白名单，不使用整仓暂存；保留旧包、标签与main。
