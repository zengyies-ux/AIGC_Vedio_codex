# 核心学习包维护

此目录维护干净核心学习包的白名单、专用说明和手动构建脚本。它不会自动同步或定时打包；只有用户明确要求发布新版本时才运行。

## 当前发布流程

1. 先完成本次规则修改及受影响范围的必要检查。
2. 更新`package_config.json`中的版本、发布日期和变更摘要。
3. 更新`CHANGELOG.md`。
4. 手动运行：`python3 packaging/build_core_package.py`
5. 从脚本输出确认文件数、断链、绝对路径和SHA-256。

发行文件写入根目录`releases/`。历史项目、资产、审片、旧Skill和团队SOP不在白名单内，不能因为新增文件而自动进入压缩包。

1.6.0使用全新候选文件名，保留旧1.5.0／1.5.1；显式白名单新增匿名`validation/director_v36.md`，更新唯一扩展及必要入口，不收真实剧本、网址、资源ID、媒体、截图、账户、会话或缓存。清洁项目索引只在ZIP生成，不覆盖本地活动索引。

本轮只开发和现场验证视频延长准备，按指南准备本地候选包，release_status为local_candidate；没有新的GitHub发布授权，不推分支／标签或创建Release。以后获明确发布授权再核版本占用并沿ZIP／MANIFEST／SHA及远端回读流程，旧标签和main保留。
