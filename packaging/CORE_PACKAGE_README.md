# Seedance Codex Workflow Core

供Codex执行Seedance短剧导演、原生填稿及视频延长准备的干净核心包，不含项目剧本、素材、操作记录或成片。当前Core1.7.0为V3.7分支候选，未创建该版本tag／Release，完整自动执行链与Windows真机待验；旧公开Core1.5.1也为prerelease，保留原样。

将仓库地址与“请按指定版本部署到本机”交给Codex，依[唯一部署说明](DEPLOYMENT.md)完成获取、版本／SHA／MANIFEST校验、独立环境准备和核心／音频／浏览器自检。已持有本包仍先校验来源和清单，升级保护用户项目与缓存。此包内README仅为地图，部署步骤不另写一套。

- 日常唯一规则入口：[AGENTS.md](AGENTS.md)。默认验证模式保留；本次明确自主授权按其范围内部采用，不推成全局常规模式。
- 制作入口：[通用基线与短续做词](NEW_PROJECT_CONVERSATION_PROMPT.md)。从材料、采用解读／分段或正式稿自然接入；只补所需事实。资产核身份及阶段状态，主线最终定稿启动词。
- 核心规则：[工作流导航](memories/seedance_workflow/README.md)；素材适配与时间政策各保单一出处，保原句、有效情绪／肢体因果、声音跨镜、七栏、摄影和整集额外6—10秒可剪素材。
- 项目结构：[空项目索引](memories/seedance_workflow/projects/INDEX.md)与[项目模板](memories/seedance_workflow/projects/PROJECT_TEMPLATE.md)。空索引仅供新安装，不覆盖升级中的个人索引。
- 网页按任务才读[唯一技能](extensions/seedance-jumeng-operator/SKILL.md)：默认只准备；当前正确模式不重选、填后不切模式，不反复设置／重访秒数。明确本集完整生成授权后，依[执行链](extensions/seedance-jumeng-operator/references/generation-execution.md)同页设秒并提交一次、活动内等待、核源后同集一次延长，回执未知只查不重试。
- 已验与边界：[匿名V3.7说明](validation/director_v37.md)。历史待源恢复／手动微裁／真实节点和授权单次提交已有证据，完整自动链在本轮受控模拟；不冒充Windows真机或修复实片已通过。

Mac保已验英文MLX，新增Windows x64 CPU英文候选和自动环境／自检入口，Windows真机待验；安装与自检由Codex执行，细节沿[部署说明](DEPLOYMENT.md)及[音频工具](tools/local_audio/README.md)。下载技能文本不等于浏览器已连接。

包内PACKAGE_INFO.md记录版本和候选状态，MANIFEST.sha256列文件哈希；ROADMAP.md只记能力与待验，不添加制作步骤。历史项目、剧本、原音频、角色／场景图、成片、截图、真实网址／ID、缓存、旧社区Skill及团队SOP均不在本包内。只按用户明确要求手动更新，不自动同步或改旧标签。
