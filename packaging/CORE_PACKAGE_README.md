- **组员：**[三步上手SOP](QUICK_START.md)，按Windows路径示例准备材料。

- **让Codex部署／升级：**[唯一部署说明](DEPLOYMENT.md)，获取校验、环境准备、自检及个人资料保护均由Codex执行。

默认只准备；明确本集生成及付费授权后，执行原生提交、活动任务内等待、必要局部核源与一次延长。未知回执先查，不重复提交；正确模式不重选，秒数留提交前设置。本流程不出图，不自动充值或失败返抽。
