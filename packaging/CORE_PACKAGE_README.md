# Seedance Codex Workflow Core 2.0.0 Candidate

Core2.0.0本地候选，GitHub正式版仍为Core1.9.6。读取剧本、音频与真实资产，完成导演设计、提示词和授权范围内的网页制作。先核本集需要及本地资产，缺少时从用户提供的只读在线来源取原图，最终归档到材料根“资产文件夹”三类目录；角色优先适配三视／阶段造型，不收独立面部高清图。通常一聊天一集；用户明确指定连续2—3集可共用依据并分集维护，由主控依就绪状态在授权内提交无依赖任务。

- **组员：**[上手SOP](QUICK_START.md)。

- **只收集资产：**[独立资产收集词](ASSET_DOWNLOAD_PROMPT.txt)，不需音频，不进入视频制作。
- **部署／升级：**[部署说明](DEPLOYMENT.md)，由Codex处理校验、环境、自检及个人资料保护。
- **AI规则：**[AGENTS.md](AGENTS.md)，沿已有采用内容只补剩余工作。

已明确要求网页任务但未授权生成时只准备；明确本集生成及付费授权后，执行原生提交、活动任务内等待、必要局部核源与一次延长。未知回执先查，不重复提交；正确模式不重选，秒数在提交前设置。不生成资产图，不自动充值；明确审修授权下实际查看结果，关键问题同段最多3次修正，轻微可剪保留，第三次仍失败请用户核查。
