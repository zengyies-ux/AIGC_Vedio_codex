## GitHub备份方式

2026-10-10核对本仓库为公开仓库。日常小修改在本地进行；仅在用户要求的大重构或里程碑备份时手动提交、推送，不设置自动同步。

- `pre-refactor-2026-10-03`：重构前原样基线，包含原README和原规则。
- `backup-v1.0.0`：基线加简短README、版本说明及临时文件忽略配置；尚未重构。
- 完整原目录快照与SHA-256校验文件保存在对应GitHub Release中；快照在初始化Git及修改说明文件之前生成。

此前完整备份版本保留当时的规则、历史项目、正式素材、旧提示词和发行包；此为历史范围，现行V3公开提交仅限下文的核心白名单，不追加私有项目。临时渲染与缓存只在历史完整快照，目录外素材、其他聊天和账号配置不在该备份范围。

本地重构在 `codex/seedance-workflow-refactor` 分支分阶段提交，原标签保留；验收记录见 [CHANGELOG.md](CHANGELOG.md)。需要恢复时，从相应标签或Release下载到新目录核对，保留现有工作目录。核心学习包的版本独立于本仓库备份版本。

V2前的恢复点为 `pre-refactor-v2-2026-10-03`，保留V1三次重构提交。V2按六步制作流程完善交接、导演权限、声音替换与时间对应；本轮备份使用工作分支及 `workflow-refactor-v2-2026-10-03`里程碑，不为备份合并主分支。临时验收样稿仅本机保存，核心结论进入CHANGELOG。


## 当前V3.4试制版入口

日常目录为`AIGC_Vedio_codex_V3`、分支`codex/director-v3-4`，从此开Local聊天，以[AGENTS.md](AGENTS.md)为唯一规则入口。原目录及V3.2／V3.3恢复依据保留，不双向同步、不合并main。当前采用关系由项目状态和提示索引确定，新聊天不继承未落盘对话；本次没有改正在制作的项目稿件或入口。

GPT据完整剧本、目标集音轨、真实资产和可选想法连续完成提取、定位、导演设计、拆段与提示词。明确冲突先设计有力度的身体交锋及对手、在场者和环境的因果反应；声音与镜头独立，不为句首强迫回到说者。导演决定场面与力度，执行层拍清，模板交付，工具只定位／排版／核数字。音频算法、缓存、完整原句、三时轴、预算、七栏、摄影及接续约束保留。

默认验证模式一次集中采用；常规模式仍须用户认可正常流程及实际效果并落盘。子智能体只在用户授权后可选，通用启动词已附短要求。制作设置、状态和提示索引直接提供当前稿、真实素材、整数时长、真实源片和可执行条件，未来网页层消费这些结果并回读绑定、回执和续做事实，不另写导演稿。

发布点：[Core 1.4.0 / V3.4试制版](https://github.com/zengyies-ux/AIGC_Vedio_codex/releases/tag/core-v1.4.0)，[匿名验收与限制](validation/director_v34.md)。规则、工具回归及文本验收不等于独立新窗口或实片通过；用户对V3.3的评价是“能用”，声音／后期对接获认可，画面新意、冲突和张力仍需改善。网页技能未合入，本轮未操作网页；实际表现力认可后再实测普通生成、一次真实延长、绑定回读及中断续做。

公开提交和ZIP仅纳入核查过的核心、必要工具、通用启动词、匿名验收及发行物；私有项目、真实媒体、音频环境、会话和含本机路径的专用启动词留本地。旧发布与标签保留，发行记录见[releases/README.md](releases/README.md)。
