## GitHub备份方式

2026-10-10核对本仓库为公开仓库。日常小修改在本地进行；仅在用户要求的大重构或里程碑备份时手动提交、推送，不设置自动同步。

- `pre-refactor-2026-10-03`：重构前原样基线，包含原README和原规则。
- `backup-v1.0.0`：基线加简短README、版本说明及临时文件忽略配置；尚未重构。
- 完整原目录快照与SHA-256校验文件保存在对应GitHub Release中；快照在初始化Git及修改说明文件之前生成。

此前完整备份版本保留当时的规则、历史项目、正式素材、旧提示词和发行包；此为历史范围，现行V3公开提交仅限下文的核心白名单，不追加私有项目。临时渲染与缓存只在历史完整快照，目录外素材、其他聊天和账号配置不在该备份范围。

本地重构在 `codex/seedance-workflow-refactor` 分支分阶段提交，原标签保留；验收记录见 [CHANGELOG.md](CHANGELOG.md)。需要恢复时，从相应标签或Release下载到新目录核对，保留现有工作目录。核心学习包的版本独立于本仓库备份版本。

V2前的恢复点为 `pre-refactor-v2-2026-10-03`，保留V1三次重构提交。V2按六步制作流程完善交接、导演权限、声音替换与时间对应；本轮备份使用工作分支及 `workflow-refactor-v2-2026-10-03`里程碑，不为备份合并主分支。临时验收样稿仅本机保存，核心结论进入CHANGELOG。


## 当前V3.5试制版入口

日常目录`AIGC_Vedio_codex_V3`、分支`codex/director-v3-5`，从此开Local聊天，以[AGENTS.md](AGENTS.md)为唯一规则入口。当前采用关系由项目状态和提示索引确定；V2、旧分支、标签、稿件与私有素材保留，不同步或合并main。

GPT根据完整剧本、目标集音轨、真实资产和可选想法连续完成提取、定位、导演设计、拆段和正式稿。保住有效情绪、肢体交锋、完整台词与声音对接；整集生成素材额外预留6—10秒可剪画面，取整计入，按[唯一时间政策](memories/seedance_workflow/execution_rules.md#sound-and-time)分配并映射。A＝70秒可提交76—80秒；不是每段额外加，也不要求最终成片加长。

同类完整单集默认A剧本／冲突、B声音／时间、C资产／空间三名GPT-6.1-sol high协作，主控统一设计和采用，小修不凑代理。新任务默认验证模式；已有明确的当集自主授权继续有效，不因升级失效，也不冒称已启用长期常规模式或成片满意。[短启动词](NEW_PROJECT_CONVERSATION_PROMPT.md)只填材料、范围与授权即可。

固定接令、回应、接触或跨段识别的配角逐一匹配身份；姿态高度、承重和世界坐标到机位的映射明确，修遮挡优先构图而非附加搭手。上游源或稿改变核全部相关下游镜头，延长正文必须有固定源名视频引用；正文完成、真实源确定、真实绑定及可执行分别记。

[剧梦填稿扩展](extensions/seedance-jumeng-operator/SKILL.md)已集成，普通提示词任务不加载。V3.5仅指定URL填稿、真实图片／已就绪视频节点与参数回读，不点击生成、不付费、不实操完整延长选源／区间；V3.6再验证后者。1.5.1补验保留19秒／六节点原生卡，为另一26秒／七节点原生段正常新建独立卡，复用已有站位图。两卡全文及节点跨卡／重访保留，未覆盖前卡或重复建卡／上传；本次模型2.5Pro和480P保持，但两卡返回均需将4秒恢复为各段19／26秒，仅恢复后的当前同页正确。首轮还观察过720P／2.0Pro回退，完整延长和参数持久性仍未通过或未验。

发布点：[Core 1.5.1 / V3.5多卡补验试制版](https://github.com/zengyies-ux/AIGC_Vedio_codex/releases/tag/core-v1.5.1)，[匿名验收与限制](validation/director_v35.md)。音频算法和缓存、七栏、完整摄影、无BGM及当前镜长边界保留；新实片、空间修正和余量实际可用性仍待正常制作评价。公开提交与ZIP仅核心、必要工具、通用启动词、扩展、匿名验收及发行物，不含私有项目、网址、媒体、账户、会话、缓存和本机专用文件。
